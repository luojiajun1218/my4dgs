# 核心方案草案：由真实树码率导出的自适应层级损失

2026-09-20。研究候选，不是已完成论文或已胜过 ReCon-GS 的结论。

## 一句话

**不是先定层数再压缩，而是在训练中让可编码运动树决定：哪里继续共享
父运动，哪里值得付出额外 bit 获得细粒度运动。**

当前建议以“树码率包络损失”作为主线研究，真实 RD 接受的多提案方法作为
诊断工具，暂不同时堆进主方法。attribute gate、重叠混合均不是本轮核心。

## 1. 表示：共同运动与差异，而非多层重复运动

在父区域内部建立有限候选子分组，实际启用哪些分叉由优化决定。候选可以
来自确定性几何二聚类；本轮数学基线使用中位数二分。子分组不跨越父区域。
在固定 Gaussian 集合上即可调整运动层级，不依赖 Gaussian 的 clone/split。

父区域有 nL、nR 个点的两个子区域，共同运动为 p，差异为 d：

    u_left  = p + nR/(nL+nR) * d
    u_right = p - nL/(nL+nR) * d

递归应用即可。K个最终叶组只需1个根运动和K-1个差异，没有父、左、右
三份自由参数的重复。停止分叉时，整个该区域共享祖先累计运动。

这里自适应的是**已发出树的局部深度与运动自由度**。候选分组由几何决定，
不能说已学习任意运动边界；软重叠也不包含在当前精确求解里。

## 2. 细分 loss 与 bit loss 如何统一

设 x 为编码端的连续运动 latent；z(T,q) 为树 T 和整数系数 q 解码的运动。
定义一个损失，而不是额外拼一个经验分裂分数：

    E_tree(x) = min_(T,q) { rho/2 * ||x-z(T,q)||² + lambda * R(T,q) }

R采用实际编码器的有效bit：根系数、被访问节点的结构位、被保留的差异
系数均计入。当前原型为有符号Exp-Golomb码；固定头部与尾部填充另外报告。
它不是节点数L0，也不是量化之后才统计的存储数字。

该最小化回答了用户的“哪里该细分”：

- 若更深的运动差异不足以抵消新增bit，就停止并共享父运动。
- 若整棵后代子树有价值，可以同时保留通路与深层差异。
- 因而父层差异恰好抵消为零，不会自动挡住有用的深层差异。
- 每次重新求解允许收回已有分叉，不是只能长、不能合并。

在最优离散解唯一、未跨决策边界的位置，损失有简单的精确梯度：

    dE_tree/dx = rho * (x-z*)

不需要对“创建节点”这个离散动作直接求导。真实bit通过决定最优z*影响
梯度与下一步结构；不能单看分支内部的bit常数，就误认为bit没有作用。
不同最优分支相交处不可微，实现取被选分支梯度。

## 3. 图像反传如何教会它细分

训练渲染的是已解码运动 z*，不是未压缩的 x，以免拿无法发送的精细运动
取得图像分数。使用 straight-through estimator (STE)：

    z_ST = x + stop_gradient(z* - x)
    L_train = D_render(z_ST) + E_tree(x)

于是更新信号为：

    g_x = g_render(z*) + rho * (x-z*)

第一项来自逐Gaussian的图像梯度，包含当前尚未激活的细粒度自由度信号；
第二项把latent拉向当前值得编码的树，防止无约束积累后强开昂贵细节。
两者共同决定下一次投影是否分裂。没有独立的细分标签，也不需先把每个
候选子模型各训练几步。

rho是编码损失的度量，不必强制将训练步长绑定为1/rho。可以对上述梯度
使用常规优化器；例如Adam的逐点预条件位于latent更新中，不改变树投影
的共享通道度量，因此不破坏该投影的正交分解。稳定性仍须实测。

重要限定：E_tree的梯度几乎处处正确，**图像项的STE仍是有偏估计**。这不
构成整个训练目标精确可微或单调收敛的证明。实际已发现激进步长震荡。

## 4. 为什么能求解，不是穷举所有树

硬嵌套的加权共同/差异基，在等点权重下正交。子节点局部失真与系数码长
可分解，故自底向上比较：

    C_stop(n)  = 区域内共享误差 + 停止位
    C_split(n) = 最佳量化差异的误差和码长 + 分叉位 + C_left + C_right
    C(n)       = min(C_stop(n), C_split(n))

根共同运动另做率失真量化。各深度在同一递推内竞争，而不是“父层先过
阈值才准尝试下一层”，也不是两层lookahead补丁。

精确性仅针对固定候选字典、二次运动距离、当前可分离编码器；真实渲染
误差并未被DP精确优化。任意软重叠、上下文耦合熵模型需要另推求解器。

## 5. 目前的证据与失败

详细配置、来源与失败记录见 `rd_structure_search_20260920.md`。

- 数学：精确量化/全部树剪枝穷举对照、局部深度、零父差异下深层激活、
  可合并、真实码流解码、包络梯度检查均通过。
- 反例：朴素gate有幅度套利；无约束shadow会绕过码率；硬投影会量化停滞。
  这些路线没有因某个成功例而被保留为主方法。
- 真实渲染：frame0到frame1、固定233,665个Gaussian、只优化平移。
  4训练相机反传，另4训练相机检查，cam00从未用于方法选择。
- 16个记录状态、相同rho=.001、相同步长下，lambda从0到1e-4/N再到1e-3/N：

| bit权重 | 最终分叉 | 运动包字节 | 检查视角PSNR |
| --- | ---: | ---: | ---: |
| 0 | 7760 | 22543 | 36.1947 |
| 1e-4/N | 4515 | 12246 | 36.1622 |
| 1e-3/N | 1375 | 3192 | 36.0531 |

这支持“bit loss控制实际结构和码流”的机制，不证明完整视频的压缩优势。
rho=.0003的激进配置反而震荡，检查PSNR最终35.2689，低于零运动35.6676。
不得只报告上表而省略该失败。

父内几何二聚类也已验证同类现象：同字典内，无bit/有bit项最终运动包
11,493/7,058字节，检查PSNR36.0930/36.0899。该字典有4,272候选叶，
而上表中位数字典有8,192，不能跨字典直接作等容量优劣比较。

六维平移＋轴角通路和真实码流已跑通，但旋转长尾梯度带来新的稳定性
问题：过大的旋转步长严重发散；减小步长可保持有界、非零旋转，目前
并未显示独立检查视角的额外收益。尚不因此宣布完整6D方法成功。

后续又完成16训练视角轮换、frame11/51暖起点检查与frame1另一分组种子的
短验证：同字典有/无bit项，运动包减少约40–57%，检查PSNR差异在约-.012到
+.016dB之间。后续帧起点来自历史ReCon-GS，并非本方法连续滚动；不能据此
宣称视频压缩或误差积累已经验证。详细结果与协议见研究记录第五轮。

现已接入独立`rd_tree`训练模式，完成共享首帧后的2个动态帧、每帧240次
反传的两阶段流程及独立连续解码。两帧编码结果逐元素复现训练Gaussian，
但cam00质量一降一升，完整墙钟约23秒/帧，高于同帧强参考约16秒。
因此目前是可运行、可核查的研究原型，不是达到完整质量/预算目标的成品。

## 6. 创新主张应该落在哪，不能落在哪

加权Haar、率失真树剪枝、量化近端优化、STE、可微码率训练分别都有先例。
甚至经典视频编码已研究变深度运动场的RD剪枝，不能把二者组合写成首创。

值得验证的具体主张是：**在在线4DGS重建中，将未激活运动自由度的渲染
梯度、全深度可逆层级选择和真实可解码运动码率结合为一个训练机制；运动
细分独立于Gaussian densification，且不需要逐候选额外训练。**

参考核对：[经典运动场RD剪枝](https://doi.org/10.1109/76.660825)、
[TreeSplat](https://papers.nips.cc/paper_files/paper/2025/hash/c868aa7437dc9b29e674cd2e25689021-Abstract-Conference.html)、
[HEIR](https://arxiv.org/html/2510.26786v1)、
[DeepRAHT](https://arxiv.org/html/2601.12255v1)、
[ProxQuant](https://arxiv.org/abs/1810.00861)。
这些区别是研究定位，不能替代充分的相关工作检索或实验贡献证明。

## 7. 进入完整实现前的必要条件

1. 已初步验证父内几何聚类；若比较分组方式，需要控制不同字典的候选容量。
2. 已接通三维旋转参数，需进一步稳定训练；轴角相加不是逐层SE(3)复合。
3. 明确稳定的步长/曲率与视角采样；不可用测试相机挑参数。
4. 已新增向量化统计/量化/重建路径。保存的六维真实梯度对照中，聚类字典
   投影从约.590降到.077秒，包逐字节一致；真实渲染轨迹中包络调用约.1秒。
   仍需控制候选自由度和调用次数，不能直接承诺完整训练为16.6秒/帧。
5. 解码端由上一帧已解码几何与固定规则重建字典；规范坐标精度、排序与
   平局规则。packet里的hash只查错，不能代替发送任意分组。

上述是进入完整实验前的检查清单；该最小闭环现已完成，完整实验进展见下节。

新的诊断在frame10/50/99固定latent，仅切换树剪枝，用20训练相机检查，
不使用测试相机选参数。对A的末态展开完整深度几乎不改变图像；反过来，
对D的末态自适应剪枝可减少约40–45%运动packet字节，20训练视角平均图像

这仅是三个冻结状态的结果，不可拼接为完整视频的压缩收益。

因此下一项受控假设是“先优化候选运动，再选择实际编码层级”：20次运动
更新期间保留完整候选结构，最后一次更新后进行全深度自适应选择，然后
应用该场并训练增量高斯。量化、真实bit及其他参数不变；它是训练顺序
诊断，不是新核心贡献。两动态帧已验证最终场与独立解码一致；完整100帧
实验已得到分段恢复结果：PSNR31.833521、SSIM.955320、总字节38074.06/帧，
wall17.3580秒/帧。原进程中断后从60恢复，重算61不完全复现原轨迹，因此
必须保留分段限制。99包独立连续解码及所有已存checkpoint核查通过。
相对A约+.083dB，但仍低于D约.163dB，不能说延迟选择保持了D的画质。

这仍仅是三个冻结状态。该对照不是新贡献，必须用于限制压缩收益的归因。
