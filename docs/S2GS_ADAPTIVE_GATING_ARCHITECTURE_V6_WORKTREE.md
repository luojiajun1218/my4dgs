# S²GS 自适应层级更新

## 核心目标

沿用 S²GS 的首帧、Gaussian 表示、动态线索和 residual decoder。后续帧用隐式空间层级决定哪些 Gaussian 可以接受**共享运动**；只有终止于 `UPDATE` 的区域，才进一步学习逐点 offset residual gate。颜色、尺度、旋转、透明度等仍按 S²GS 的 residual decoder 路径优化。共享运动与 gate 不竞争：前者解释区域的共同变化，后者只补偿仍解释不了的逐点位置差异。

方法遵循一条规则：已有动态线索和图像变化先筛出可能变化的一级区域；只在这些区域拟合共享运动；有剩余图像误差的区域先试拆，只有子区域运动在相同视角、相同像素位置上降低局部图像误差才保留 SPLIT，最多四层。静态区域终止在 OFF，不为了凑层数继续展开。每帧都重新建立状态；上一帧 OFF 不锁定下一帧。

## 节点状态

每个被访问区域只有三种状态：

- `OFF`：终止状态。区域内 Gaussian 的共享运动和逐点 offset residual 关闭；其他属性仍按 S²GS 更新。
- `UPDATE`：终止状态。区域内 Gaussian 接受共享位置/旋转；每个 Gaussian 的逐点 offset residual 由可学习 gate 独立决定，并非整区全开。其他属性与 OFF 一样，按 S²GS 更新。
- `SPLIT`：中间状态。该区域继续划分，最终更新与否由更细区域的 `OFF/UPDATE` 决定。

层级最终产生一个布尔的区域运动许可；`SPLIT` 不直接产生最终运动 mask。在 `UPDATE` 区域内，逐点 gate 还可取 0、0.1、…、1 的多级值。注意 S²GS 的 anchor 仍可按原代码优化，因此 OFF 的严格含义是“不使用这一层级的共享运动和 offset residual”，不是冻结该 Gaussian 的所有几何与外观属性。

## 逐层判断

第一层体素边长设为 S²GS 根体素的 2 倍（本数据约 0.255），不再采用旧版的 8 倍（约 1.021）。四层边长依次约为 0.255、0.128、0.064、0.032；第二层与 S²GS 根体素对齐，最细层与其最小体素对齐。每帧前 100 step 用于层级判断和共享运动拟合，四层默认各获得 25 step：

1. S²GS 的 view-space gradient difference 保留为 per-Gaussian 动态线索；再从相邻帧 GT 差异及当前/上一帧重投影误差增量中取图像变化线索。任一线索明显的区域先设为 `UPDATE` 候选，其他区域 `OFF`。
2. 在一级区域拟合共享运动。每层前 18 step 训练当前层运动，并从投影 Gaussian 周围的图像误差聚合节点残差。
3. 对有明显残差、动态性混杂或子区域误差不均匀的节点，临时开放子节点；子节点以父运动为零修正起点，继续训练 7 step。
4. 用两台固定训练相机比较试拆前后同一批投影像素的平均图像误差。局部误差同时超过绝对和相对收益阈值才保留 SPLIT；否则回到父节点 UPDATE。试拆失败不会强制继续开层。
5. 子节点里的 OFF/UPDATE 根据本帧动态证据重新判定；第四层不再 SPLIT。

这里的 `split_residual_ratio=0.008` 现在表示图像绝对误差预筛选阈值，而非旧版“高梯度点比例”；最终 SPLIT 必须有图像误差收益（默认绝对增益 `0.0003`，相对增益 `2%`）。局部收益来自投影点附近的像素采样，是低成本近似，不是严格互不重叠的区域重渲染。阈值是初始实验设置，不引入额外 bit-rate loss。

## 父级继承

代码不保存显式父子关系表。每层只保存 Gaussian 到该层空间格子的映射，父子归属由同一个 Gaussian 在相邻层的格子索引隐式确定。

层级判断的 100 step 内使用父级公共运动加子级修正：

```text
训练时子区域运动 = 父区域公共运动 + 子区域修正
```

这样子区域从零修正开始，父级已经拟合的公共运动可以继续帮助细层收敛。第 100 step 结束时，代码把每条完整运动路径折叠进终止 `UPDATE` 区域；后续逐点优化不再遍历父级路径。增点阶段开始前把共享平移和旋转提交进顺序 Gaussian 状态，避免新增点导致旧层级索引失效。若子区域最终为 `OFF`，整条共享运动路径及逐点 offset residual 都被屏蔽；其他属性继续沿用 S²GS 的更新逻辑。

## 每帧训练

首帧保持现有 S²GS 训练流程。后续帧固定为 400 step：

1. 前 100 step：冻结逐点 Gaussian 属性，逐层拟合共享运动并完成 `OFF/UPDATE/SPLIT` 判断。
2. 中间 200 step：固定层级和共享运动，优化所有 Gaussian 的 S²GS 常规属性；在 `UPDATE` 区域内使用逐点 offset gate，关掉的点不产生逐点 offset residual。前 100 step 固定证据初始化的 gate，让 offset 先拟合图像；后 100 step 再训练 gate。前向采用 0.1 多级值。gate 独立使用较小学习率与稀疏权重，不直接照搬 S²GS 的根节点 gate 超参到逐点 gate。
3. 最后 100 step：继续训练 gate 与上述属性，并在中点使用 S²GS 的 anchor growing 从已有 UPDATE 点增点；每帧最多从 32 个高梯度来源点提出新点，新增点继承来源点的属性基线，默认允许其 offset 训练。动态帧暂不修剪旧点，因为删点会使本帧层级索引失效。

所有状态均在每帧重新估计；旧帧 OFF 区域在新帧有图像变化时可重新打开。

## 存储与执行

每帧估算被访问区域的两比特状态、终止 UPDATE 区域的非零共享平移/旋转，以及**gate 非零的 Gaussian** 的逐点 offset；gate 模式和非零多级值另行计入估算。其他属性按 S²GS 原有量化 residual 估算。SPLIT 父区域的运动只用于初始化子区域，不进入最终 payload；OFF 区域不保存 offset residual，但可以有外观等属性 residual。输出中不包含显式父子表。存储数字仍是估算，不等于实际编码后的文件大小。

推理时根据空间格子映射还原终止状态。OFF Gaussian 不执行层级共享运动或逐点 offset residual；UPDATE 区域先执行共享运动，再仅对 gate 非零的点应用 offset residual；其他属性仍从 S²GS residual decoder 读取。

## 代码入口

- `scripts/adaptive_hierarchy.py`：隐式四层区域、状态判断、父运动继承，以及只作用于 UPDATE 区域的逐点 offset gate。
- `scene/gaussian_model.py`：先用 hierarchy mask 约束共享运动，再用 gate 约束逐点 offset residual；其他属性沿用 S²GS。
- `train.py`：100/200/100 step 三阶段和逐帧状态日志。
- `scripts/run_adaptive_gate_v6_300.sh`：当前 gate 版本的训练入口，默认 300 帧输出到 `output/v6_300`；可传入帧数和结果目录名用于短跑。`v5_300` 是 gate 塌缩后中止的旧版，不覆盖。

首帧沿用 S²GS 的数据目录、配置、3600-step 训练与增密逻辑。曾经额外插入的首帧阶段探测渲染已移除；它不是数据预处理。重复首帧训练的测试 PSNR 波动较大，因此对比时必须单列首帧结果，不能将其差异直接归因于动态帧方法或数据处理。

## 当前 10 帧试跑（v6；尚非 300 帧结论）

同一数据和 `max_frames=10` 设置下，`output/v6_pilot_10` 首帧 33.47 dB；本工作树关闭 adaptive hierarchy 的 S²GS 对照 `output/s2gs_control_10` 首帧 33.91 dB。第 2–10 帧平均测试 PSNR 分别约为 33.95 dB 和 33.46 dB，方法在首帧低 0.44 dB 的情况下动态帧高约 0.49 dB。第 10 帧 7579 / 17032 个 UPDATE Gaussian 的 offset gate 非零，未再发生 v5 的几乎全关现象。

代价是第 2–10 帧估算存储约 0.27 MB/帧，对照约 0.03–0.05 MB/帧；这说明 v6 目前只有短跑画质信号，**不是整体优于 S²GS**。继续跑满 300 帧，评估长序列 PSNR、存储、FPS 与时间。

## 上一版 300 帧实测（2026-09-25；不是当前 100/200/100 配置的结果）

数据：`standard_flame_steak_300`。旧版结果在 `output/v3_revised_300`，S²GS 对照为 `/home/gamer-02/Documents/DeepLearning/S2GS/output/standard_flame_steak_300`。下表是各自 `avg_metrics.json` 的 300 帧均值；**不能视为当前改动后的成绩**。存储为仓库内估算值，不是实际熵编码后的文件大小。

第 300 帧当前版本为 34.15 dB、36,313 个 UPDATE Gaussian、总点数 61,252；S²GS 为 34.35 dB、59,745 个点。首帧当前版本 34.18 dB，S²GS 35.15 dB；虽然代码仍沿用 S²GS 首帧训练路径，数值没有对齐，需另行核查随机性和设置，不能把动态帧的全部 PSNR 差距归因于层级方法。

动态帧平均约 36,189 个 Gaussian 被 UPDATE，平均每帧试拆约 790 个节点、接受约 71 个；300 帧共新增 1,419 个点。树状态与共享运动的估算开销平均约 0.025 MB/动态帧，**主要存储问题是过多点的逐点 residual**，不是每帧保存树状态。试拆严格要求局部图像误差下降，导致多数混合区域仍在粗层 UPDATE；这一规则保护了画质，但没有充分实现“只让该动的点动”。

因此本版达成了训练时间优势，并避免旧版后半段 UPDATE 点归零/PSNR 塌缩，但画质、存储、FPS 尚未超过 S²GS。后续应优先验证更小的 UPDATE 集合与几乎无画质损失的 SPLIT 判据，同时核查首帧数值差异；不要把当前结果表述成整体胜出。
