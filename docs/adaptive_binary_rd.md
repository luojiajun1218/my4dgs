# 自适应运动层级：当前实现与实验边界

这是可运行的研究原型，不是最终论文方法。当前只做运动层级和码率，
不做 attribute gate；所有运动系数都包含三维平移和三维旋转向量。

## 1. anchor 如何成为一棵树

先从已有高斯的位置采样 root anchors，把高斯分给最近的 anchor。
一个 root 管理一个区域。需要更多自由度时，只把这个区域里的高斯
聚成两组，不要求沿坐标轴切割，也不要求两边人数相等。

聚类特征可以是位置，也可以拼接累计的平移梯度。两种特征各自在
父区域内归一化，梯度权重写在配置里。没观测到的梯度不当作真实
零梯度，而是使用区域已观测梯度均值。当前不使用旋转梯度聚类。

这里的树是运动自由度的层级，不是固定八叉空间网格。初始 anchor
密度仍是一个超参数，并没有宣称把所有空间划分都自动学出来。

## 2. 一次分叉只增加一份差异

设父运动为 p，左右子组人数为 nL、nR，新学一个六维差异 d：

    left  = p + nR / (nL + nR) * d
    right = p - nL / (nL + nR) * d

于是左右运动差正好为 d，人数加权的平均仍为 p。初始 d=0，
所以添加结构的那一刻图像完全不变，不会因新建层级而突然跳动。
更深层就是沿路径继续累加差异。平移和旋转向量先相加，后者再
转换为单位四元数；这不等于按层级复合刚体 SE(3) 变换。

## 3. 谁获得下一次分叉机会

每次搜索收集所有当前叶子，无论深度。一层叶子和三层叶子可在
同一轮参与竞争，不是先把某一层分完，也不是深度优先遍历。

先假想二分，再看两组平均梯度的差异，并结合各组观测数打分。
直觉是：如果两组都想朝同一方向动，父运动已经能满足；如果
两组想朝不同方向动，新增一份差异可能更有价值。

梯度分数只负责筛选候选，不直接决定分叉。当前选出一个候选批次，
整体试验、整体接受或拒绝；还没有逐节点独立评估收益。因此大批次
可能把少数有益和有害分叉混在一起，这是明确保留的局限。

## 4. 为什么试验要从相同状态开始

保存当前运动参数和 Adam 状态，做两条短训练分支：

- A：不新增结构，训练 k 步。
- B：增加候选结构，使用相同训练相机训练 k 步。

如果只训练 B 而不训练 A，就无法判断提升来自新结构，还是单纯
多训练了 k 步。两边对齐是在控制这个变量，不是要求左右子组
运动一致。接受 B 时保留 B；拒绝时保留 A，所有试验反向传播
都算额外计算，不能当作免费搜索。

## 5. bit rate loss 到底约束什么

运动量先按步长 Q 量化，渲染时也使用量化后的运动。训练通过
straight-through 梯度更新浮点参数。以分层、分通道的 Laplace
分布计算整数符号概率：

    probability = CDF(symbol + 0.5) - CDF(symbol - 0.5)
    coefficient_bits = -log2(probability)

越不常见的符号通常越费 bit。训练目标包含图像误差、运动正则项
以及 lambda_rate * estimated_bits / 当前固定基础高斯数。

分叉决策比较 J = 图像误差 + lambda_rate * estimated_bits / N。
如果新增结构改善很小、编码成本却很高，就不接受。这里的码率
不仅计算运动系数，还计入成员归属、树结构和概率表等旁信息。
估计值不是文件实际字节数，最终另外输出真实 arithmetic-coded
motion npz，并立即解码核对渲染所用的运动。

当前熵分布尺度由符号统计拟合，不是神经网络学习的上下文模型。
传输精确整数 CDF；极大符号范围使用明确记录的原始符号回退。

## 6. 相机、时间和评估约定

所有聚类、候选训练、分叉决策只使用训练相机；cam00 只评估。
默认把已缓存训练相机分成短试验训练子集和决策子集；可选使用
全部训练相机计算决策误差，后者不是独立验证集。

每帧重新建立树，上一帧的叶子运动为新 root 提供动量初始化。
细层结构目前不跨帧保留，因此连续细节可能被平滑掉。当前也
没有合并节点、前瞻多层搜索或全局最优树保证。

100 帧实验指索引 0–99；0 是双方共享的静态 checkpoint，主指标
统计 1–99 共 99 个动态帧。参考每帧 100 运动步＋100 增量步；
默认本方法另有最多 40 次候选反向传播。短序列调参不能替代完整
序列，也不能据单次单场景结果声称普遍优越。

实际存储统计为 motion npz＋增量 PLY，不含双方共享首帧。原方法
使用记录的 lossless float npz，而非为其另做的最优压缩实现。
当前码流验证覆盖给定高斯顺序下的运动恢复，不是完整独立视频
解码器。用这些结果写论文前仍需匹配计算预算的对照、多场景、
消融和独立复现。
