# 动态场景逐帧优化与压缩：实现逻辑说明

本文介绍动态场景重建与压缩的实现，供论文撰写者理解方法和训练流程。文中采用描述性的通用术语，方法名称和叙述方式可在论文写作时确定。

本文以一套每个动态帧训练 200 步的全属性配置为例，参数数值对应这套配置。

## 1. 问题和整体思路

项目研究动态三维场景的重建与压缩。目标是在保持或提高多视角重建画质的同时，降低动态帧的存储和传输成本。基础表示是三维高斯：每个高斯具有三维位置、空间方向、尺度、透明度和颜色表示，能够通过高斯渲染生成指定相机视角的图像。

系统从一个已经训练完成的首帧模型开始，后续时间点基于上一时间点解码出的高斯状态，优化和编码当前时间点的变化。接收端从首帧出发，按顺序解码各帧增量，逐帧还原场景。

核心思想是让空间位置相近、运动相似的高斯共享一部分变化，同时允许每个高斯保留独立修正：

1. 在首帧构建一个固定的候选空间层级。
2. 对每个动态帧，在候选层级中选择当前使用的区域粒度。
3. 同一区域内的高斯共享一组运动更新；逐点残差表示共享运动无法解释的细节。
4. 尺度、颜色和透明度也允许同时具有区域共享更新和逐点更新。
5. 在图像重建质量和预计编码开销之间优化，最后量化、编码并解码核验。

背后的研究假设是：不同位置所需的运动细节不同。区域太大时，共享运动可能不足以表达局部变化，逐点残差随之增大；区域太小时，区域参数和结构本身可能需要更多字节。选择合适的共享粒度有望改善画质与存储的权衡。这一假设可通过控制变量的码率–画质实验进行检验。

```text
训练好的首帧和候选空间层级
             │
             ▼
     上一帧的解码结果
             │
       确定当前候选路径
             │
   选择区域粒度并联合优化
   ├─ 区域运动 + 逐点运动修正
   ├─ 区域尺度与颜色 + 逐点尺度与颜色修正
   └─ 区域透明度修正 + 逐点透明度修正
             │
    多视角图像监督 + 存储约束
             │
       量化、编码、独立解码
             │
      解码结果作为下一帧参考
```

## 2. 数据、视角和时间组织

数据由多个时间点的多相机图像以及对应相机标定信息组成。首帧是时间点 0，之后的每个时间点是一个动态帧。举例来说，包含 300 个时间点的序列由 1 个首帧和 299 个动态帧组成；时间点数与每帧的训练步数是两个不同概念。

本例每个动态帧训练 200 步。每一步只使用一个训练相机：对训练相机生成随机排列，依次取用；一个相机周期结束后再重新打乱。采样使用由随机种子和当前帧决定的规则，便于复现。评估相机不参与这些优化步骤。

示例场景使用 16 个训练相机和 1 个留出相机；留出相机也曾用于开发选型。不同场景使用各自的数据划分、图像分辨率、帧数和首帧模型。

图像分辨率以加载和预处理后的结果为准。相机场景归一化得到的尺度记为 \(E\)，用于位置量化和运动残差的归一化。

## 3. 首帧与状态递推

首帧使用预先训练好的三维高斯模型。每个高斯的主要状态为：

| 状态 | 含义 |
| --- | --- |
| 三维位置 | 高斯中心在场景中的坐标。 |
| 四元数方向 | 控制高斯的空间朝向。 |
| 对数尺度 | 三个轴方向的尺度参数；经过模型的激活变换后得到正尺度。 |
| 透明度参数 | 模型内部的透明度表示，可转换为用于渲染的 alpha。 |
| 球谐颜色系数 | 包括直流分量及其他阶次的系数，用于表示颜色和视角相关外观。 |

后续每一帧都以**上一帧解码后的状态**作为参考。上一帧拟合出的运动和区域选择可以用作当前帧优化的初值，当前帧使用自己的图像重新优化；该初值无需作为额外的完整运动场传输。

每个动态帧完成优化后，系统将更新写成码流，调用解码逻辑重建该帧，检查结果，再将解码出的状态提交给模型。下一帧引用这个提交后的状态，使训练侧与接收端使用同一条状态递推链。中间动态帧依赖之前的解码状态，量化和重建误差可能随时间累积。

## 4. 候选空间层级和区域选择

### 4.1 固定候选层级

在首帧的空间坐标中构建候选层级。本例最多构建 5 层：先从场景中的 8 个初始空间单元开始，再在每个父单元内部按三个坐标轴分别划分，得到最多 8 个子单元，递归形成候选区域。划分位置根据单元内点坐标的中位数确定。

为了避免极端位置影响划分，构建阶段先根据点到坐标中位数的距离选取稳健统计支持，本例使用 99.9% 的距离分位数。这个支持集用于估计空间结构；全部高斯均参与场景表示和渲染，极端点按已支持区域的空间代表位置确定路径。

候选划分的位置在首帧确定后保持固定。每一帧根据上一帧解码后的点位置重新将高斯路由到该层级中，同一个高斯的候选路径和所属区域因而可以随时间改变。

本例中，允许细分的节点至少包含 2 个点，而且至少有两个有点的子节点。候选区域总数、选中区域数和有非零运动更新的区域数分别统计。

### 4.2 沿路径选择粒度

每个高斯在候选层级中有一条由粗到细的路径。每个可分裂区域具有一个可学习的二值选择：继续向子区域细分，还是在当前区域停止。某个高斯从初始区域出发，沿路径到第一个不再细分的区域时停止；最终每个高斯恰好属于一个选中区域。

这组被选中的区域构成覆盖当前点集的一个互不重叠的前沿。不同空间位置可以停在不同层级，因此区域大小可以不同。区域选择学习既有候选区域是否继续细分。

训练时使用连续概率及相应梯度近似来优化这些离散选择，实际确定的区域归属仍然是离散的。一个点在某一候选层停止的路径权重，取决于之前各层继续细分的概率，以及当前层停止的概率。训练各阶段分别使用随机路径、硬选择和梯度近似。

## 5. 高斯运动的表示

对上一帧中第 \(i\) 个高斯，记其位置为 \(\mathbf{x}_{i,t-1}\)、方向为四元数 \(q_{i,t-1}\)，当前所选区域为 \(o_i\)。当前帧的运动可概念性地写为：

\[
\mathbf{x}_{i,t}=\mathbf{x}_{i,t-1}+\hat{\mathbf{u}}_{o_i}+\hat{\mathbf{e}}_i,
\]

\[
q_{i,t}=\operatorname{quat}\!\left(\hat{\boldsymbol\omega}_{o_i}+\hat{\boldsymbol\rho}_i\right)\otimes q_{i,t-1}.
\]

其中：

- \(\mathbf{u}_{o_i}\) 是区域共享平移，\(\mathbf{e}_i\) 是逐点平移修正。
- \(\boldsymbol\omega_{o_i}\) 是区域共享旋转向量，\(\boldsymbol\rho_i\) 是逐点旋转修正。
- 帽号表示量化后的量；旋转向量转换为四元数后与上一帧方向组合。

实现中，位置直接叠加共享平移和逐点平移；旋转更新作用于高斯自身方向，高斯中心的位置由平移项决定。

候选层级内部可以使用相对父节点的区域参数；沿父子链组合后得到一个候选区域的代表运动。每个点使用其选中区域的代表运动，加自身逐点残差。

本例位置增量的量化步长为 \(6\times10^{-5}E\)，旋转向量的量化步长为 0.001 弧度；区域和逐点运动使用相同的上述步长。量化可能将小变化表示为零，而小变化也可能包含对重建有意义的细节。

区域选择改变时，系统会重新分配区域运动和逐点残差：如果某点改归另一个区域，就调整其逐点残差，使区域运动与逐点残差之和尽量保持切换前的总运动。这样区域结构变化主要改变运动的编码分解；保持精度取决于量化和编码范围。

## 6. 每个动态帧的 200 步优化流程

本例采用以下分段日程。每个步骤使用一个训练相机，并执行一次共享优化器更新；运动、区域选择、透明度和其他属性分别位于不同参数组。

| 步数 | 区域选择与运动 | 透明度、尺度和颜色 |
| --- | --- | --- |
| 1–100 | 进行共享运动发现和区域选择学习。逐点运动残差不训练；在本配置中，区域和逐点旋转也被冻结，因此主要拟合区域平移。 | 逐点透明度、尺度和颜色增量，以及区域透明度、尺度和颜色增量均冻结。 |
| 101–150 | 暂时固定已选区域；开始联合优化区域与逐点平移、旋转。 | 所有已有高斯的透明度、尺度、颜色，以及区域对应属性开始联合优化。 |
| 151–180 | 重新开放区域选择，并与运动和属性联合优化；重启时清除区域选择参数的优化器历史。硬归属变化时重新分配运动和属性增量。 | 继续更新区域和逐点属性；区域属性图像代理与属性码率代理可以向区域选择传递梯度。 |
| 181–200 | 最终固定区域选择，继续拟合该结构下的运动和属性。 | 继续训练，到第 200 步结束后进行量化、编码与状态提交。 |

首段使用随机二值路径训练共享运动和区域选择，并通过可微松弛近似其梯度。后段区域选择重新开放时，运动参数接收图像梯度；区域选择接收运动码率代理，以及区域属性的图像和码率代理提供的梯度。本配置未启用额外的运动图像梯度代理。

第 101–200 步允许**所有已有高斯**更新尺度和颜色，也允许所有已有高斯更新透明度。最终非零量化增量的分布由训练、量化和稀疏化共同决定。此配置在动态序列中保持高斯数量固定。

运动参数的学习率在前半段保持初值，后半段按余弦形式降低，末值为初值的 0.2。各类属性参数有各自的学习率和衰减规则。

单帧逻辑可写成：

```text
读入上一帧解码状态
根据上一帧位置确定候选空间路径
初始化本帧运动、区域选择和属性增量

重复 200 次：
    按当前阶段控制哪些参数可训练
    选择一个训练相机
    使用量化后的参数渲染当前帧
    计算图像损失及相关存储约束
    反向传播并执行一次优化器更新
    必要时改变区域选择并重分配残差
    对增量进行近端收缩和周期性稀疏处理

生成本帧码流
独立解码并核验
将解码状态作为下一帧参考
```

## 7. 尺度、颜色和透明度如何更新

### 7.1 逐点尺度和颜色

从第 101 步开始，每个高斯都可以相对于上一帧的解码值优化以下增量：

- 三轴对数尺度增量；本例量化步长为 0.005。
- 球谐颜色直流分量增量；本例量化步长为 0.001。
- 其余球谐颜色系数增量；本例量化步长为 0.001。

本例使用一阶球谐颜色：每个高斯有 3 个直流颜色分量，另有 3 组一阶系数，每组包含 3 个颜色分量。直流和其余系数都参与训练，本例其余系数的初始学习率是直流分量的 1/20。

对一种属性 \(a\)，其逐点量化形式可以概括为：

\[
\hat a_i^{\text{point}}=a_{i,t-1}+s_a\operatorname{round}(\delta a_i/s_a),
\]

其中 \(s_a\) 是该属性的量化步长。前向使用量化值，反向使用直通梯度近似；量化符号为零时保留参考值。实现还对零值和设备取整一致性作了处理。

### 7.2 区域尺度和颜色

每个候选区域也有可训练的对数尺度、直流颜色及其余球谐颜色增量。一个高斯获得其当前选中区域的增量，区域层叠加在逐点层之后。对对数尺度与球谐系数，可用下式概括：

\[
a_{i,t}=a_{i,t-1}+Q_a(\delta a_i^{\text{point}})+Q_a(\delta a_{o_i}^{\text{region}}).
\]

区域增量与同类逐点增量使用相同的量化步长。只有当前有点归属的选中区域才形成有效区域输出。区域参数用于表达共同变化，逐点增量用于表示剩余差异。

### 7.3 透明度

透明度的两层更新分别处于 alpha 和 logit 参数域：

1. 逐点层在 alpha 域相对上一帧做量化增量，并将 alpha 限制在有效范围；本例量化步长约为 0.01。
2. 区域层在透明度的 logit 域加入量化增量，再通过 sigmoid 得到渲染 alpha。

区域切换时，为保持透明度，系统在 alpha 和 logit 之间转换，再落回逐点量化网格；这一步可能引入舍入近似。

## 8. 属性信息如何参与区域选择

本例中，区域选择不仅考虑运动表示，还考虑尺度、颜色和透明度的区域/逐点编码代价。

当后段区域选择可以再次变化时，系统针对每种候选区域估计：如果某个高斯改用这个区域，在尽量保持当前重建属性的前提下，区域属性增量需要多少预计存储，逐点属性残差又需要多少预计存储。再利用候选路径的连续权重，为区域选择提供一个码率梯度代理。

区域属性渲染的前向值仍采用当前实际选中的硬区域；连续路径提供给区域选择的只是代理梯度。属性参数自身的梯度仍按硬前向计算。码率代理采用前向数值为零、但反向提供梯度的形式，避免将已经计入的硬编码代价重复收费。

如果离散区域归属发生变化，系统重新调整逐点尺度和颜色残差，补偿新旧区域增量的差别；透明度通过对应的参数域转换和量化进行近似补偿。重分配前会检查整数编码范围，避免静默溢出。

区域选择、属性梯度、码率估计和重编码共同决定最终的区域表示。

## 9. 图像损失、存储约束和量化

### 9.1 图像重建损失

每步从一个训练相机渲染当前场景，再与该相机在当前时间点的真值图像比较。本例基础图像损失由 L1 和结构相似度项构成：

\[
L_{\text{base}}=0.8L_1+0.2(1-\operatorname{SSIM}).
\]

再与一个经过稳定化处理的均方根误差混合。令 \(m\) 为整幅图像的均方误差，则：

\[
L_{\text{rms}}=\frac{m}{\sqrt{m+10^{-8}}+10^{-4}},
\qquad
L_{\text{image}}=0.2L_{\text{base}}+0.8L_{\text{rms}}.
\]

稳定化形式在一般误差范围内与 RMSE 量纲相近，但在误差接近零时不完全等同于直接计算 \(\sqrt m\)。本例没有额外启用按时间变化程度加权的图像损失，也没有在动态帧训练中使用粗到细图像缩放。

### 9.2 存储与逐点残差约束

除图像损失外，优化还考虑区域和逐点运动的预计编码开销、逐点运动残差幅度、透明度和其他属性的稀疏存储开销。概念上可表示为：

\[
L \sim L_{\text{image}}+L_{\text{motion rate}}+L_{\text{motion residual}}+L_{\text{attribute rate}}+L_{\text{selection proxy}}.
\]

上式按作用分类。区域选择和部分稀疏支持使用可微代理；逐点运动、透明度、逐点属性和区域属性的一部分稀疏约束由优化器更新后的近端操作实现。日志中也会记录从参数分离出的代价统计量。

本例使用固定码率权重 0.008。字节价格按首帧参考点数乘以 24 字节进行归一化。逐点平移残差在约束中除以场景尺度 \(E\)，旋转残差使用弧度单位；对应残差约束权重为 1.0。

本例还对不同属性的预计字节代价使用不同倍率：逐点尺度、逐点颜色和区域非透明度属性的相关价格使用 4 倍系数，逐点尺度在此基础上再乘 2。区域透明度和逐点透明度有各自的稀疏强度。这些倍率作用于训练代理中的价格。

近端操作使用优化器的二阶矩估计构造度量，对连续参数做朝零方向的软阈值收缩；周期性地比较保留某个非零行或运动块的近似代价与预计字节价格，决定是否将其清零。本例拟合窗口为 20 步，并在结束时做必要处理。最终稀疏度受到图像梯度、学习率、量化步长和正则化等多种因素共同影响。

### 9.3 代理字节与实际字节

训练中对非零行和运动块的成本采用简化估计，为优化提供可计算的价格。实际传输大小由最终码流和清单的长度确定，还受索引间隔、整数编码、头部信息、符号分布及压缩算法影响。

## 10. 码流与解码顺序

每个动态帧的实际传输内容包括：

| 内容 | 作用 |
| --- | --- |
| 运动更新 | 表示区域结构选择和区域/逐点的运动增量。 |
| 逐点透明度更新 | 表示需要编码的非零逐点透明度增量；全零时可省略。 |
| 逐点尺度和颜色更新 | 表示非零逐点对数尺度及球谐系数增量；全零时可省略。 |
| 区域属性更新 | 表示选中区域的对数尺度、球谐系数和透明度增量；全零时可省略。 |
| 帧清单 | 标明当前帧需要的内容、相关元数据、计数和校验信息；属于逐帧传输开销。 |

逐点尺度和颜色编码会比较多种表示，包括完整整数数组、仅保存非零行及对稀疏整数做可逆变换等，然后选取压缩后较短的有效格式。区域属性按区域编码，解码后再根据区域归属应用到各个高斯。

接收端从上一帧状态开始，先恢复当前运动与区域归属，再应用逐点透明度和逐点尺度/颜色增量，最后根据当前区域归属应用区域属性增量。最终形成的完整状态既用于渲染，也作为下一帧的参考。

每帧编码完成后，系统会从生成的内容独立解码，检查状态摘要和属性摘要，并在一个训练视角下比较编码前后的渲染结果。本例要求两者最大像素绝对差不超过 \(10^{-5}\)，否则报错。训练侧随后直接采用独立解码的状态。该检查验证当前帧编码与训练前向的一致性。

## 11. 评估与报告口径

评估时对指定的留出视角渲染，并计算 PSNR、SSIM 和 LPIPS；计算前将渲染颜色限制在 [0, 1]。同一时间点多个评估视角的结果可先取算术平均，再按明确的帧范围统计序列均值。训练进度中的 PSNR 对应训练视角，评估结果对应留出视角。

报告存储时至少要区分：

1. 动态帧码流总大小、动态帧数量和平均每动态帧大小，说明是否包含帧清单。
2. 共享首帧的大小。动态帧均值不自动包含首帧。
3. 如果需要完整序列平均开销，可另外报告“首帧大小 + 全部动态帧大小”除以时间点数量。
4. 使用 KB 时说明单位，例如 1 KB = 1000 字节；按需补充逐帧大小分布。

速度分别报告已解码状态下的纯渲染 FPS，以及包含读包、解码、状态更新和渲染的完整播放 FPS；尚未测量的指标标为未测。

画质报告包括相机划分、评价帧范围、首帧是否计入、视角与时间维度的平均方式、缺失帧和中断恢复情况。结果按实际评估的场景和帧范围表述。

## 12. 论文中的方法组织

论文可围绕以下几个相互衔接的部分组织方法：

1. **研究动机**：以区域共享粒度平衡运动表达能力和存储开销。
2. **空间结构**：从首帧构建固定候选层级，在各动态帧选择不同位置的共享粒度。
3. **运动表示**：用区域共享平移和方向变化表达共同运动，以逐点残差补充局部细节。
4. **属性表示**：联合优化尺度、透明度与球谐颜色的区域和逐点增量。
5. **联合优化**：结合图像重建、预计码率、运动残差约束、量化和近端稀疏化。
6. **序列压缩与重建**：以首帧为基础，顺序传输和解码动态更新，将每帧解码结果用于下一帧。
7. **实验分析**：按实际评估范围报告画质、存储和速度，并通过控制变量的比较分析各机制的作用。
