# 让模型学会什么时候细分

**代码已接入 `learned_selective` 模式，尚未运行数值检查或训练。** 原 `selective` 模式保留，仍按 [现有规则](selective_motion_current_rules.md) 运行。

设计时与用户确定：共享已有首帧，再处理 20 帧；每帧 450 步。实际运行随后由用户改为 300 总帧，在第 27 个后续帧后停止。整理后的配置见 [实验 YAML](../config/archive/learned_selective_300.yaml)，由用户手动启动；重跑需使用新的实验名。结果见[前 27 帧诊断](learned_selective_27_diagnosis.md)。

## 1. 要改变什么

给每个区域增加三个可学习的选择分数：KEEP、SHARED、SPLIT。它们和运动参数一起训练。图像差分可以用于诊断，但不再用投票阈值关闭区域，也不再因为一个子区域暂选 KEEP 就禁止父区域 SHARED。

第一版继续使用现有空间树作为候选。模型学习在哪些地方停止、哪些地方继续细分；暂时不同时学习空间边界的位置。这是每帧通过优化学习划分，不需要 KEEP / SHARED / SPLIT 标签；也还不是跨场景直接预测划分的网络。

## 2. 证据不足时怎么办

不设置 UNKNOWN 动作，也不使用 UNKNOWN 锁死运动。区域默认有一个可训练的 SHARED 候选，初始运动可以为零；子候选可继承父候选的运动作为起点。

“默认 SHARED”不等于强迫它移动。它表示允许共用和学习运动。KEEP 由优化选择，输出时仍直接复用旧值。

完全不可见的区域没有足够的图像梯度，模型不能凭空恢复其真实运动。对这种区域保留共享运动的默认值或父区域的运动，暂不依据缺失观测把它压成 KEEP；可观测程度保留为数值记录，不作为第四种动作。实现时应避免结构惩罚单独把完全没有观测的分支压成 KEEP。

## 3. split 怎么得到梯度

每个区域保存三个分数，转成三个概率。KEEP 使用旧几何；SHARED 使用这一块的刚体运动；SPLIT 使用子区域各自的候选运动。

前 100 步固定选择分数，使用软混合，让父子运动候选先得到训练机会。接着 250 步联合训练运动和选择，使用 Gumbel-Softmax 的直通估计：前向选一个离散方案，反向用连续近似传递梯度。最后固定选择，精修运动 50 步，再训练新增 GS 50 步。

需要满足三个条件：

- 选择概率必须参与生成送给渲染器的 GS 位置和朝向，不能只把它拿来打印或事后分类。
- 父子候选刚初始化时可能完全相同，此时图像损失不能区分它们。需要前期探索，结构惩罚从弱到强，不能开局就锁定 SHARED 或 KEEP。
- 最终每个 GS 只跟随一个终止区域。选择父区域后停止向下；选择 SPLIT 后使用子区域的完整运动，不重复加一次父运动。

旋转要使用有效的四元数或旋转群插值，不能把几个旋转矩阵直接相加。不能始终只做软混合：模型可能用“小选择概率 × 大位移”拟合图像，却少付结构代价。后期必须按离散选择渲染，并检查固定选择前后的画质差距。

这类可训练离散选择可参考 [Gumbel-Softmax](https://arxiv.org/abs/1611.01144)；它提供梯度近似，不保证一定找到最优划分。

## 4. 第一版 loss 应该表达什么

代码支持三个部分；**本轮关闭变化匹配项，只使用重建和结构代价。**

```text
总损失 = 图像重建误差 + λ变化 × 变化匹配误差 + 结构代价
结构代价 = (λ运动 × 有效共享运动区域数 + λ细分 × 有效细分次数) / 初始粗区域数
```

**图像重建误差：** 保留 L1 + SSIM，要求当前帧本身拟合好。只有这一项，模型没有直接的动力优先使用少量粗区域。

**变化匹配误差：** 要求“渲染结果的变化”接近“真实画面的变化”。同一固定相机下：

```text
变化匹配误差 = mean(abs(
    (当前渲染 - 上一帧渲染) - (当前真实图像 - 上一帧真实图像)
))
```

上一帧渲染来自冻结的参考模型，不参与反向传播。墙面真实图像没变，就鼓励渲染墙面也保持；衣服真的变了，就要求解释这部分变化。这样不必先用一个图像差分阈值决定谁可以动。

但这个项等价于约束前后帧的重建误差保持接近，可能保留旧误差，不能替代绝对重建监督。阴影、曝光和遮挡也会改变图像，它不能单独证明几何在动。参考模型要明确包含哪些旧 GS；合并、裁剪等操作引起的变化也会进入此项，必须单独记录。移动相机还需要对齐，不能直接套用公式。

帧差监督已有先例，例如 [Vid-ODE 的 Difference Loss](https://arxiv.org/html/2010.08188v2#S3.SS3)。这里提出的是在逐帧 GS 运动优化中使用冻结参考的版本，实际帮助尚未验证，不以这个公式本身作为创新结论。

**结构代价：** 训练时使用上述区域数量的期望值，使它能够对选择分数求导。这里惩罚需要多少份独立运动，不按位移大小收费：一大片区域共同平移很远，仍只需要一份运动。

| 场景 | 希望训练得到的选择 |
| --- | --- |
| 墙没变化 | KEEP 能拟合图像且代价最低 |
| 整块物体一起动 | 一份 SHARED 能拟合，比许多小块便宜 |
| 衣服局部动得不同 | 粗运动有明显图像误差，SPLIT 的收益足以抵消额外代价 |

图像误差推动模型使用足够的运动自由度，结构代价推动它合并冗余自由度。权重决定权衡，不能保证自动得到正确运动。先比较“可学习选择 + 重建 + 结构代价”，再加入变化匹配项，才能知道收益来自哪里。

可学习门和稀疏结构惩罚已有 [L0 正则化](https://arxiv.org/abs/1712.01312) 等工作。我们可以针对这个任务设计损失，但不能仅凭这个公式就宣称新颖。需要验证：层级是否按运动需求分配、静止内容是否保留，以及画质和开销的实际收益。

## 5. 实现结构代价时的关键细节

设一个节点选择 KEEP、SHARED、SPLIT 的概率为 `pK、pM、pS`。`a` 是从根走到这个节点的概率：根为 1，子节点为父节点的 `a × pS`。

```text
有效运动数的期望 = Σ a × pM
有效细分数的期望 = Σ a × pS
```

这样，父区域没有选择 SPLIT 时，下面暂未使用的候选不计入最终结构代价。最细层不允许 SPLIT，这是有限候选树的边界。

必须防止两种退化：结构代价太强会全部 KEEP，太弱会全部 SPLIT。前期要让候选先学出差异，再逐渐增加结构约束。图像监督还需保证小动作不会被大面积背景稀释；局部权重不能由选择门随意缩小，否则模型可能通过改变权重逃避误差。

先验证选择门能否得到有效梯度、固定选择后的画质是否保住，再单独验证变化匹配项。暂不继续叠加平滑、码率等其他正则。

## 6. 代码和本轮参数

- `model/learned_selective.py`：选择分数、按层批量刚体计算、有效结构代价、阶段调度和恢复状态。
- `module.py`：训练与渲染接口、可选变化 loss、运动提交和新增 GS。
- 诊断：保存原图时同时保存区域图；记录动作比例、选择梯度、loss、软/硬选择画质差、时间和文件占用。内部 SPLIT 按区域统计，GS 只统计 KEEP / SHARED。

| 参数 | 已确定值 |
| --- | --- |
| 候选树 | 128 个粗区域，最多二分 3 层，最多 1024 个叶区域，子区域至少 24 个 GS |
| 平移 / 旋转学习率 | 0.0005 / 0.0005 |
| 选择分数学习率 | 0.02 |
| 初始 KEEP / SHARED / SPLIT 分数 | -1 / 0 / -0.5 |
| 温度 | 1.5 逐渐到 0.5 |
| 共享 / 细分代价系数 | 0.0001 / 0.00005；前 100 步关闭，随后 100 步逐渐加满 |
| 评估步数 | 100、350、400、450；终端每帧汇总一次 |

这些是待验证的起始值。新配置的 450 步比旧实验的 200 步多，比较画质时必须同时报告训练耗时。完整 bitrate loss 留到后续，当前结构代价和文件占用都不等于真实编码码率。

新增 GS 仍放在运动选择之后，首版先让其训练与区域选择分开，方便判断收益来源。没有固定的 split 比例，也不预设某类物体必须在哪一层。
