# 自适应层级的机制边界补查

2026-09-20；本记录是已读方法段的有限比较，不是新颖性检索完备证明。

## 4DGCPro（NeurIPS 2025）

[正式会议记录](https://proceedings.neurips.cc/paper_files/paper/2025/hash/923285deb805c3e14e1aeebc9854d644-Abstract-Conference.html)，
[方法3.2–3.3](https://arxiv.org/html/2509.17513v1)。其motion-aware grouping
按平均平移阈值更新参考帧，调整时间帧组长度；不是本文候选树的局部深度
决策。它已有分层率失真训练；位置/旋转阶段不加熵约束，属性残差阶段加入。
因此不能把“层级+bit loss”或“运动自适应”泛称本项目独有贡献。

## PD-4DGS（2026-05预印本）

[方法3.1–3.4](https://arxiv.org/html/2605.11427v1)：静态、全局形变、局部细化
三个传输层，属性掩码与熵率损失，以及掩码驱动的层采样频率。这里的层级
是网络/传输层，不等于父区域内不同深度的运动树竞争。未来attribute gate
必须单独比较，当前仍不实施该扩展。

## RALHE（2025-10预印本）

[方法2.2–2.5](https://arxiv.org/html/2510.22812v1)：静态3DGS属性的八叉树
多分辨率latent、轻量解码器和自回归熵模型，联合率失真优化。多分辨率
位置结构由体素几何确定，不能据标题的region-adaptive就判断与本项目
细分决策相同；也不能声称学习层级表示或率失真训练本身新颖。

## 本项目需要证明的更窄命题

候选几何树内，以父共同运动+子差异表示，所有深度在真实符号/结构码长
约束下共同选择，训练中的选择可以恢复被剪分支。当前实现是固定候选
字典中的自适应结构，不是已经学到了任意运动边界。动态规划仅对可分
二次代理和独立符号码长精确，图像STE梯度不提供全局下降保证。

要成为可靠贡献，仍须证明这一结构选择比固定树加无损零子树编码更好，
并验证跨种子稳定性、实际总字节和计算开销。现有两种子质量排序反转，
不足以完成该证明；后续设计不能仅追逐seed0固定深树的单次结果。
