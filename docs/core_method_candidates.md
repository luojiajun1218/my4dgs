## 首选研究假设：联合选择多尺度运动差异

核心问题不是物体动不动，而是：这一片 Gaussian 是否需要不同的运动？
整片区域可以高速运动，但内部完全共享；运动幅度很小的边界也可能需要
精细差异。因此应压缩“区域内部运动的不一致”，不只压缩接近零的运动。

### 表示

在父区域内构建有预算上限的嵌套二分候选树。设左右成员权重之和为
W_L、W_R，保留已有共同项 p 与一份差异 d：

    u_L = p + W_R / (W_L + W_R) * d
    u_R = p - W_L / (W_L + W_R) * d

第一版用成员数量作为权重，避免引入需传输的学习权重。沿路径相加，
得到每个 Gaussian 的六维平移/旋转向量增量。旋转向量最后转四元数；
这仍不是逐层 SE(3) 刚体变换复合。

一个有 K 个叶组的完整二叉树只有一个共同项和 K-1 个差异项，总计 K
份运动自由度。这是对叶组独立运动的可逆多尺度重参数化，不凭空增加
表达能力。可能的价值在于归纳偏置、量化后的 RD 和有限步优化。

### 选择机制

所有候选层级的差异从一开始即可参与图像损失与码率损失的联合优化；
不要求父差异先通过短试验，才允许建立下一层。量化后的零差异表示该
分叉本身无需区分运动，但不关闭后代。只有整个子树的差异都为零时，
才能把其完整运动表示折叠为共同项。

例：四个相邻叶组的目标平移为 [+1, -1, +1, -1]。两大半区的均值都为
零，顶层差异可为零，但左右半区各自仍需要非零细节。在上述表示下，
共同项与顶层差异为 0，两份细层差异为 2，即可重建。这个代数例子只
说明逐级开门会遗漏的一类模式，不证明真实渲染优化一定改善。

目标为图像失真加 lambda 乘可编码码率。候选结构若能由上一帧已解码
几何确定性重建，可不传显式全量成员表；稳定顺序、精度、tie-breaking
都属于解码契约，不能仅声称“同一随机种子”就保证一致。

零系数也不是免费：已知顺序的完整系数流可以直接熵编码零符号，计入
概率表与头部；若改用稀疏位置或树跳过编码，则相应位置/结构开销也要
计入，不能重复或遗漏计算。若引入训练图像/梯度决定的额外分组信息，
必须显式传输，不能假设解码器也能看到这些梯度。

### 预算与边界

- 限制总叶组数 K 和最大深度，而不只限制深度。候选全开训练不免费。
- 相同参数数目不意味着相同运行时间；路径聚合、熵模型与建树都算计算。
- 先不叠加跨帧树学习、神经预测器、光流监督和 attribute gate。
- 固定候选树上选择差异，只能称“有效运动尺度/差异支撑自适应”，不能
  称任意拓扑或任意运动边界自适应。空间候选树可能切错运动边界。
- Haar/RAHT 类多尺度差异和稀疏编码已有大量先例。消除父层准入限制是
  对当前算法的具体改变，但尚不能据此宣称足够的论文创新。
- 光度监督有遮挡和运动歧义；所有层同时训练仍可能学错，不是全局最优保证。

## 如果用户要求分组边界也自适应

上面的固定候选方案单独不足。应将主问题改为“运动共享分组的 RD 选择”，
嵌套差异仅作表示和编码工具。

可进一步研究用多视图累积的共享更新冲突来构造父区域内候选分组，而非
把梯度幅度直接当作真实运动。局部二次近似可同时考虑梯度与可观测性，
但其收益预测不等于真实渲染收益；还要支付自适应成员归属码率。当前
梯度聚类已经覆盖部分思想，新增曲率估计若没有清楚收益只是增加复杂度。

另一条是从细运动开始合并共享区域，可以不受粗层准入约束，但需要先
拟合细运动，搜索成本和组边界编码也未解决。不将其宣称为更优方案。

## 方法成立需要回答的最少问题

1. 与同编码器、同自由度预算的固定 anchors 相比，嵌套差异表示究竟提供
   哪种优势，而非只得益于压缩实现或训练步数？
2. 解码端如何确定共享组，实际需要传哪些信息？
3. 何种运动会让方案失效：候选边界错位、局部旋转、遮挡、新出现区域？
4. 若要求学习边界，额外可编码分组信息是否值得它节省的运动系数？

在这些问题与用户对自适应的含义对齐之前，不启动完整训练，也不将核心
方法宣布为已确定。现有实现及历史实验保持不变。

## 用户允许重叠后的优先候选：软边界的层级差异

用户原话：“运动边界可以产生点重叠没事，这样混合起来的效果可能还会
更好。”优先探索局部重叠，不要求先正确恢复互斥运动分区。

### 已有工作边界

[SC-GS](https://drive.google.com/file/d/1JP6MNUwRnZIeGYgeAVPZv8F5hETLc-CM/view)
已使用四个近邻控制点、归一化 RBF 权重、可学习影响半径和线性混合
skinning，且自适应调整控制点密度。故“软绑定/可学习范围”本身也不是
新贡献。本项目候选需明确回答层级差异与真实码率为何优于平坦软绑定。

### 与共同项兼容的软差异形式

令 beta_ni 是 Gaussian i 对父节点 n 的成员权重，s_ni 属于 [0,1]
表示它在该节点偏向左子区域的程度。子成员权重为 beta*s 和
beta*(1-s)，相加仍为父权重，避免重叠把共同运动计算两次。

    mu_n = sum_i(beta_ni * s_ni) / sum_i(beta_ni)
    delta_u_ni = beta_ni * (s_ni - mu_n) * d_n
    u_i = root_common_i + sum_n(delta_u_ni)

上述式子假设 root 仍互斥且使用等 Gaussian 权重，空节点不激活。
它使每个差异项在全体 Gaussian 上的加权构造具有零和性质，保留父项
表示共同运动的解释；在 s 为 0/1 时退化为本文硬分组公式。若多个 root
也重叠，需要另外保证 root 权重归一化，不能直接相加。

边界可以软，运动差异仍只有一份；但软基底之间可能相关，不能再照搬
硬分组下的正交/可逆性质或保证良好条件数。所有候选深度依然参与优化，
中层 d=0 不删除后代所需的边界参数。

### 如何定义边界而不存储逐 Gaussian 权重

首个可分析版本可用父区域内的低维分界参数加过渡宽度生成 s，例如
非轴对齐平面两侧的平滑过渡；以两簇几何初始化。宽度小可接近硬边界，
宽度适中可表达连续混合。坐标必须来自上一帧已解码几何，分界参数若
学习并变化，须量化、传输并计入码率；渲染训练也使用其量化版本。

低维边界限制了可表示的复杂形状，这是成本与表达的取舍，不宣称能
分开任意交错物体。无限支撑的 sigmoid 若逐层展开会导致大量分支访问；
需研究紧支撑过渡与实际访问预算，不能只凭二叉结构断言复杂度为深度。

可先用几何初始化的混合权重学习运动差异，再在同一训练预算内联合调整
边界。原因是所有差异恰为零时，改变其混合权重不会改变图像，边界的
图像梯度也为零。这不是 parent gate，而是乘积参数化的初始化问题。

### 必须主动防止的失败

- 不同物体相接处过度混合，会把正确运动变成错误的平均运动；允许窄边界，
  不强制到处平滑。连续形变区域才可能受益于较宽过渡。
- 多层宽范围差异互相抵消，会增加不必要的运动系数与编码开销。零均值
  约束只分离共同项，不能消除全部跨层相关性。
- 边界参数、概率模型、成员规则、祖先结构均属于码流设计，不能漏算。
- 移动 Gaussian 的增量与刚体位置旋转不同；当前六维增量方案并不自动
  获得 SC-GS 的局部刚体 skinning 能力，大旋转是明确的压力情形。

不是已证明优越或已确认创新的方法。下一步优先检验它与平坦软绑定的
实质区别和解码/预算闭环，再决定是否值得最小实现。
