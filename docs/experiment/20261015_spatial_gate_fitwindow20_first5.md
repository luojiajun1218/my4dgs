# 窗口拟合、刷新区域众数后稀疏裁决：前 5 帧

运行：`fs_spatial_gate_fitwindow20_300_first5_20261015/20261015T035409_3f5c3d`。动态 frame1–5 已完成，未启用透明度修正。

核心 idea：每步 L0 投影会阻断部分有累积收益的运动，上一轮数值例子证明真实目标 0.02 的位移在每次小更新后被清零。改为先拟合一个短窗口，再做存储裁决；硬区域确定后，由区域内 GS 当前完整量化运动重新统计众数，把共同残差吸收回区域。

代码改动：增加 `motion_fit_window_steps`，本轮为 20。旧配置的默认 `None` 保持原先逐步投影；窗口版在 step40、60、100，以及新增点后的局部 step20、40、60、80、100 做裁决，gate 编码阶段不改写运动。硬 cut 下，先刷新当前有效区域的完整运动众数，重编码 GS 残差，再执行原有 proximal 稀疏选择。软估计阶段不刷新硬区域众数，避免两种代表语义混淆。重编码保留 Adam 历史和未跨量化格的连续余量，处理 round-to-even 的半格边界；若新众数会让区域或任何成员残差溢出 int16，保留旧原点。没有新增损失或模块。

80 项检查通过：持续有收益的运动能拟合，低收益信号仍归零；刷新众数前后完整整数运动一致，位姿保持；共享残差可以被区域吸收；树/Adam 状态不变；亚量化更新保留；半格和溢出处理正确；按阶段本地步数结束窗口。
