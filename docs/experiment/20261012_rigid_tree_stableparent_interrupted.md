# 稳定换父节点基线：完成 113 个动态帧后停止

此运行原计划训练全部 300 帧。配置为 1024 个运动区域加根，600 步运动、其中前 200 步只拟合共享区域，再做 200 步出生。它包含换父节点的稳定四元数角误差修复，仍使用旧的区域平滑存储代理、L2 相对运动约束和旧出生编码；逐 GS 残差有近端稀疏选择。

运行期间已经得到更好的独立诊断候选。为把 GPU 用于改进版本的完整 300 帧验证，主动结束此运行，最后完成帧为 113。共享参考为帧 0，帧 114 及之后没有完成，不能将下面数字标为全 300 帧指标。

画质不足且已有单帧超过 50,000 字节。初始 206,237 个 GS 增至 230,389，旧 GS 未删除。几乎所有旧区域持续有运动，静止选择不足；之后的区域近端稀疏、L1 和更细共享区域针对这一问题展开，详见各自诊断记录。

暂停训练、GPU 独占时测了两个 checkpoint 的完整渲染加 clamp：帧 49 为 205.78 FPS，帧 99 为 206.71 FPS，均为 cam00、1600×1199，启用属性缓存且与未缓存结果逐像素完全相同。它们不是全序列速度。NVML 存在驱动库版本不匹配，工具使用 `/proc` 设备句柄检查其他计算进程，并在 JSON 中保留该限制。

训练曾多次暂停让诊断独占 GPU，因此跨暂停的帧耗时不能作为正常训练速度。未启动完整序列 benchmark，因为序列不完整。终止后运行目录只读，下一轮使用新的实验名和源码快照。
