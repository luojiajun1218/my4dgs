# 直接优化旧点透明度：5帧正确性与阶段检查

核心想法：修复旧点透明度饱和时logit梯度消失，使确需退场的旧点可以降低透明度。全量旧点暂用透明度坐标，量化步0.001、学习率0.0125；学习率按透明度0.5处的原logit步幅换算。其余运动、区域、树和100+100+100预算保持原值。

- 配置：`config/fs_persistent_alphaopacity_first5_20261014.yaml`。
- Run：`output/fs_persistent_alphaopacity_first5_20261014/20261014T123328_adeb8d`。
- `sparse_opacity.py`增加OPD2，基于上一帧实际raw opacity量化变化，用CPU定义生成解码logit，训练forward使用同一解码值，梯度在透明度坐标传递。零符号逐bit保留原raw值，端点使用有限logit。
- module显式区分旧logit与alpha模式，旧checkpoint缺省恢复logit；出生先使用原appearance预测，随后只更新旧前缀。新增饱和、零透明度、幅度和支持数日志。
- 58项检查通过，包含实际CUDA渲染饱和点梯度、CPU/GPU码流逐bit一致、旧包与checkpoint兼容、出生预测顺序及pending optimizer恢复。

训练exit0，wall158.98秒；两个benchmark exit0，100个源码/配置文件冻结且哈希一致。独立重放0–4、manifest哈希、保存质量差0、cache像素差0，无其他GPU计算进程。
