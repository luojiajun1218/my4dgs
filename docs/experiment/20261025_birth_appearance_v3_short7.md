# 按外观梯度补充新增 GS：候选生效，但超大源点导致过拟合

日期：2026-10-25。已完成7帧训练与独立解码核验，尚未达标。

## 核心想法与代码

原有位置梯度候选遗漏了大部分颜色梯度信号。因此，保留原位置候选，加入32个外观候选，总新增候选上限仍为600。

- `pipeline/module.py`：只在运动阶段最后30步对旧GS的DC颜色构造梯度探针；跨训练视角累积梯度向量，最后取范数排序。旧点颜色参数保持冻结，测试相机不参与优化或候选选择。统计状态进入checkpoint并随源点删除同步重排。
- `pipeline/model/gaussian.py`：外观候选可绕过小源点限制，与位置候选共享总预算；外观候选从源中心初始化，保持点序和源点继承。
- `pipeline/trainer.py`：多视角后处理保留探针。启用已有`opacity_update.joint_with_birth`，使旧点透明度与新增点配合拟合；关闭新增点大尺度剔除以保留外观候选。其他拟合配置沿用第二轮。

输入不变：132586 GS首帧checkpoint，初筛后128963 GS解码参考；1345×1008半分辨率监督；首帧加6个动态帧。

## 分析

外观候选确实改变了拟合，但出现明显跨视角过拟合。第1帧同一最终状态下，新增点让抽查的cam01/07/14/20训练视角平均PSNR从36.6868提高到37.3664 dB，测试cam00却从34.3698降到33.8116 dB。该检查没有用于梯度训练；birth-off只是原因诊断，正式指标仍为完整码流渲染结果。

实际第1帧32个大源点的最大轴尺度，中位数3.074、最大21.297世界单位，而场景extent约6.494。复制这类宽覆盖、几何位置不可靠的椭球，会把原有近似误差放大；测试视角差分图出现宽范围人物/背景重影。初步原因是“外观梯度大”没有同时保证源几何适合作为新表面。

下一轮约束外观候选的源尺度，排除这些超大源点；允许正常表面上的外观候选，恢复大尺度异常剔除，并提高弱新增点的稀疏约束。仍先做短序列，不直接运行300帧。
