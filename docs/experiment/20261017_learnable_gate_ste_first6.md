# Learnable gate 的 STE 与运动优化坐标：前 6 帧核验

完成共享首帧加 **5 个动态帧**的 GPU 训练和独立码流核验。全关初始化的实际活动区域依次为 **8、8、287、286、293**，第 3 个动态帧出现有效细分。另用全开初始化检查一个动态帧，区域从 4050 减少到 3859。门控能发生有效变化，但仍不能声称消除了初始化依赖，存储也未达目标。

## 问题与修复

此前全开、全关初始化的两帧短测分别停在约 4050 和 8 个区域。旧代码并非完全没有 STE：图像分支用硬路径前向、软路径近似 gate 梯度。但是存在两个不一致：

1. 实际切换 gate 会重编码 GS 残差，以保持完整运动和画面不变；图像梯度却按“只换区域运动、不补偿 GS 残差”来评价门控。
2. 图像中的硬路径只给当前选中的区域直接梯度，未选中区域只有较弱的残差目标，容易形成对当前表示的偏好。仅看到 gate 梯度非零，不能证明选择机制有效。

修复仍使用 **learnable logits、sigmoid、反向传播和 Adam**。没有加入按父子成本直接设置开关的规则，没有动态规划选树，没有手工触发细分。

- **门控损失使用 STE**：前向按当前二值 gate 计算存储代理与残差，反向使用软路径期望目标的梯度。实现为 `stopgrad(L_hard) + L_soft - stopgrad(L_soft)`。对整条路径的目标应用近似，保留关闭父节点后更深候选的条件训练信号。
- **修正运动优化坐标**：完整运动仍为 `m_i = region[owner_i] + gs_residual_i`。图像损失训练完整运动；区域和 gate 通过现有残差/期望存储目标学习。区域 Adam 更新后，将区域原点变化补偿进 GS 残差，保留 GS 拟合到的完整运动更新、量化箱内余量和 Adam 状态。这样区域表示调整与实际 gate 切换保持一致。
- 存储格式仍是区域运动加 GS 平移/旋转残差。没有增加码流中的全运动数组。非零块计数仍是离散数值，门控梯度通过软路径概率传播；不声称离散字节计数本身对运动参数可导。

主要修改在 `pipeline/model/spatial_gated_motion.py`，测试在 `tests/test_joint_spatial_motion.py`。新的 joint checkpoint 标识为 `joint_motion_v2`、`hard_value_soft_path_v1`，拒绝把旧优化状态静默续训为新机制；历史码流仍可独立回放。

当前配置仍为 `config/fs_spatial_gate_depth4_200_full300_20261016.yaml`，实验名更新为 `fs_spatial_gate_joint70_ste_robustnearest_depth4_full300_20261016`。其余约定保持：深度 4、robust_median、远点最近区域、storage 权重 0.002、首个动态帧细分 gate 全关、后续继承前帧 gate/运动；70 步联合优化、30 步固定 gate，每步 2 个视角；再训练新增 GS 100 步，每步 1 个视角。

## 验证与分析

完整回归 **158 项，154 项通过、4 项 GPU 专项跳过**；真实 GPU 训练和独立渲染另如上述完成。定向检查包括：

- STE 前向等于真实二值选择的成本，logit 梯度等于软二元期望的导数。
- 父 gate 关闭时，后代 gate 仍可得到梯度。
- 仅通过损失与优化器，在已知一致运动的例子中由全开学习合并，在不同子区域运动的例子中由全关学习细分；两种初值均检查目标 gate，未手工设置训练中开关。
- 区域更新与 gate 重编码保持完整姿态，保留残差余量、Adam 状态、跨帧热启动与 checkpoint 恢复。

修复后的全关真实序列中，某顶层 gate 的概率从初值约 0.339 增加到第 2 帧约 0.468，之后跨过阈值并产生有效细分。这与旧实现顶层 logits 很快饱和在初始方向的现象不同，但不能据此声称任意初始化都会收敛到同一棵树。

**门能变化与压缩有效是两个问题。** 当前平均更新 126.10 KB 仍明显超过 50 KB，主要数据仍在运动包；前两帧画质相近时，存储也没有明显优于此前全关版本。五帧平均不能直接与两帧平均比较并宣称压缩提升。没有执行当前配方的完整 300 帧，也未完成消融验证。
