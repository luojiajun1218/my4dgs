# 实际成像贡献作为运动观测：100帧

本轮把区域维护的有效观测从“投影进入视野”改为“实际参与像素合成”。透明、被遮挡或未参与成像的点不应仅因为有投影半径就累计有效运动观测。保留持续区域、共同运动树、饱和点透明度更新，以及100步初始拟合、100步结构后联合优化、100步新增点与旧点透明度的预算。

## 实现与验证

- 配置：`config/fs_persistent_observedmotion_first100_20261014.yaml`。
- Run：`output/fs_persistent_observedmotion_first100_20261014/20261014T135725_47867d`。
- `extensions/observed_rasterizer/`在真正进行像素混合的位置收集每个GS的贡献标记；`contribution_rasterizer.py`与`contribution_renderer.py`接入训练。出生点统计继续使用原来的投影信息，测试评估与正常播放继续使用原渲染器。
- `effective_motion_observations`显式启用新观测；历史配置默认保留原定义。无有效观测的旧点保持归属，训练阶段统计投影计数、实际贡献计数和未观测旧点数。
- 99项数值与集成检查通过，包括实际GPU图像和梯度、透明与遮挡点、观测累积、区域及树调整、opacity编码、checkpoint恢复、严格因果扩展及测速。实际首帧206237点、1600×1199图像，与原渲染器的图像和投影半径完全一致；126440个投影点中实际贡献点123142个。
- 训练和两个独立benchmark均exit0。训练3893.47秒，约64.9分钟。548个源码、配置及CUDA依赖文件在训练与测速期间冻结，完成后哈希复核无变化。

新观测修正了确实存在的维护依据问题，但当前结果仍不足以解决画质和更新量。后段在结构调整前已经较差，后续联合优化和新增点补回有限；这不排除之前的成员划分或共享拟合造成累积失配。不能把结构变化瞬间保持位姿当成长期区域质量的证明。

第30帧区域68的实际联合优化检查还表明：拆分后旋转残存非零321个，100步联合后下降到36个。因此只看结构刚调整后的残存，不能直接认定整组共享旋转被GS全部抵消。此检查保存在`region68_joint_optimization_check.json`。

后续优先检查后段共享运动拟合、局部成员维护与联合优化为何无法恢复质量，再依据实际残存和字节选择一项机制修正。继续保持单实验推进；本轮没有做聚类算法轮换或系统消融。

结果入口：实验父目录的`sequence.json`、`frame99_playback.json`、`regression.log`、`checkpoint4_verification.json`；每帧阶段日志在run的`frame_summary/`，区域ID、GS比例、共享运动及残存统计在`region_statistics/`。本轮100帧结束后仍需改进，再完成300帧最终验收。
