# Gate 候选训练、图像梯度与局部代价短测

## 结论

本轮确认并修复了一个具体的梯度问题：旧的直接图像模式把 STE 放在 gate 权重上，硬关闭候选的区域参数仍收不到图像梯度。改为对整个共享运动场做 STE 后，合成检查中 576 个关闭候选全部获得图像梯度，硬划分的前向位置与原实现逐值相同。

但**梯度接通尚未转化为真实的画质、码率收益**。四个已完成短测都没有超过匹配基线，不更新默认配置，不为这些配方启动完整 300 帧。当前完整序列结果仍以[已独立核验的旋转全关基线](20261017_all_rotation_off_full300.md)为准：34.054672 dB、38.194930 KB/动态帧、233.014 纯渲染 FPS，质量目标仍未达到。

## 实验条件与结果

四次均从同一个完整第 209 帧 checkpoint 恢复，训练 210–212；数据集保持 300 帧、1600×1199、运动阶段每步 2 个视角。所有旋转更新关闭，不增加颜色通道。KB 为 1000 字节，完整更新包含运动、透明度、新增属性和 manifest；共享参考帧另计。

前三行为 100 步运动＋100 步新增，gate 在第 70 步固定。最后一行为 200 步运动＋100 步新增：前 70 步学习划分，随后到第 100 步仍做稀疏选择，第 101–200 步固定运动和透明度的非零支持集，仅拟合数值。延长运动阶段还会改变原有余弦学习率的时间尺度，因此最后一行不能单独归因于“幅值去偏”。

各短测纯渲染约 243–244 FPS，均为三帧结果，不能当作新方法的完整序列速度。增加区域或非零更新并未自动提高画质，固定支持集后数值幅度增大也可能使实际编码变长。

## 核心想法与代码改动

第一种尝试保留图像 Adam 更新提出、尚未经过 L1/L0 收缩的完整运动，以其更新度量估计某个区域预测器下的剩余修正成本。所有候选都拟合该提案，不因祖先关闭而失去训练。新增 `predictor_rd.py` 与默认关闭的 `spatial_gate.predictor_objective: proximal_rd`；拟合目标及度量随 checkpoint 保存，退休 GS 时同步筛选。这里的 Adam 对角度量是局部优化代理，**不是图像 Hessian，也不等于真实 PSNR 损失**。实测没有优于原方法，后续不沿该代理继续做参数扫描。

第二种尝试在第 70 步固定 gate 后，让实际选中的区域直接接受图像梯度，停止在每次 Adam 后用 GS 残差抵消区域更新，并清除区域从上一拟合目标继承的 Adam 矩。短测仍未改善整体结果。

第三种尝试针对现有直接图像模式的死候选问题。原式可写为 `sum(STE(hard_weights, soft_weights) * region)`；区域参数的梯度仍乘硬权重，关闭候选得到 0。现改为 `STE(sum(hard_weights * region), sum(soft_weights * region))`，同时移除让关闭候选复制当前粗运动的辅助项。前向继续使用离散划分，反向经软路径训练所有候选，gate 固定后区域和 GS 继续直接拟合图像。该模式保存为 `joint_image_dense_candidates_v2`，旧直接图像训练 checkpoint 不会被静默解释成新梯度语义；历史解码不受影响。使用已有 `rate_model: codec` 估计生产码流成本，但稀疏目标和实际无损压缩仍是近似对应。

最后一项复用现有运动、透明度幅值重拟合功能，固定已选择的更新位置后增加图像拟合。窗口脚本和独立核验脚本改为按配置保存、检查最终步数，覆盖实际第 300 步 checkpoint，而非误用第 200 步的中间状态。

## 额外诊断

- 第 209 帧已有 211370 个 GS，8 个区域解释掉多数完整运动，剩余 10798 个平移残差。对这份已经收缩的固定运动，逐层分别选最佳整向量共同平移，最深层仍需 10744 个残差，仅额外归零 54 个。因此不能指望对该固定结果事后细分就得到大量共享收益；这项诊断没有测量被收缩丢掉的图像细节。
- 在整个场 STE 短测的第 212 帧，固定当前实际运动和已学划分后，最佳模态共同平移只能将 20414 个残差降到 20385 个，少 29 个。因此这次码率增长主要不是可直接重编码消除的共同偏移。
- 合成梯度检查中，旧实现关闭候选的梯度绝对值总和为 0；新实现为 0.004014248，576/576 个关闭候选获得非零梯度。它只证明梯度连通性，不证明真实多视角图像优化的有效性。

## 核验与证据

最终生产代码通过 243 项回归检查，覆盖候选梯度、二值前向、图像更新与重编码的区别、量化、支持集、恢复和删除/新增解码。四个真实窗口均完成独立顺序解码，PSNR 差与渲染缓存逐像素差为 0；首尾两帧的最终 checkpoint 原始属性与解码结果逐值一致，来源 checkpoint 和冻结源码哈希保持不变。第四项核验的是最终第 300 步，不是运动阶段第 200 步。

汇总及各 run 路径在 `output/fs_goal_rd_20261017/gate_proposal_dense_short_comparison.json`。梯度证据为同目录 `gate_closed_candidate_gradients.json`，固定运动容量诊断为 `gate_motion_distribution_209.json`。每个 run 保留配置、冻结源码和独立核验结果。第一次局部代价试跑在一帧训练完成后因缺少汇总字段而退出；补齐诊断接口后，从原第 209 帧重新完成三帧，表格仅使用完整重跑结果。

## 下一步机制假设（尚未实现）

当前 GS 个体残差在所有区域层级始终可用。gate 改变共享预测器后，GS 仍可单独拟合和补偿，因而“区域细分”与“是否需要个体自由度”没有直接耦合。本轮证据足以停止仅调整候选拟合目标或延长拟合时间，下一步优先验证计算图中的这种绕行。

拟做一个可独立验证的层级原型：关闭区域只允许共享运动；打开后进入子区域，直到最深叶子才允许 GS 个体残差。gate 由图像误差和实际更新成本共同学习，仍使用离散前向和 STE。关闭候选的区域场和潜在 GS 修正仍需获得训练梯度；对应的 GS 稀疏惩罚必须按到达该细粒度层级的概率加权，避免候选在尚未激活前再次被压掉。

可以利用现有内部 gate 的路径连乘表示到达最深叶子的概率。协议当前要求最深叶子自身的开关位为 0，不能直接把这些位改成新的个体 gate。训练输出只需把未获许可的 GS 残差置零，既有解码器即可解码这些数值，不需要传额外的逐点许可表。该约束可能导致过度细分，所以必须先检验完整字节与真实画质；它是待验证假设，不能提前作为论文已实现贡献。
