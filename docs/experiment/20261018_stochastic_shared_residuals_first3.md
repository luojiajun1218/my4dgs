# 随机共享场与各级GS残差：三帧候选

## 核心想法与代码

此前层级个体通路只允许最深叶子中的GS保留个体残差，可能限制细节。本次恢复任意选中区域下的GS残差，继续用真实随机离散gate选择共享场，再通过量化与近端收缩控制个体更新。

扩展 `image_relaxation: stochastic_ste` 支持 `hierarchical_private: false`、`private_full_motion: false`：采样完整区域路径，前向为选中区域的绝对运动＋各GS残差；只有采样区域接收其真实参数梯度，而每个GS残差都能接收图像梯度。gate固定时清理运动Adam状态，后续20步固定支持精修保持不增加更新块。

新增训练语义标签 `joint_image_residual_stochastic_v1`，已有完整提案及切换残差的模式继续保留各自标签。默认入口与特别重要的完整基线配置未更改。

## 完成的实验

## 分析

恢复个体自由度没有补回画质，实际非零GS残差显著增加，gate也更少细分。结果不支持“放开个体残差即可解决当前质量不足”。因为权重等同时不同，不能用此表证明单个开关的独立贡献。

旧GS基础颜色仍未更新；此前逐GS颜色实验能改善画质，但增加较多负载。下一步将考虑复用已学习的空间区域共享颜色增量，检查外观误差能否用少量区域属性解释，减少通过个体位移补偿颜色变化的需要。该共享颜色机制尚未实现，不能计入本实验成绩。
