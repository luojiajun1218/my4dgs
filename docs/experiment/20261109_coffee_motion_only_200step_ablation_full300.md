# Coffee：200 步运动主干与 300 步稀疏纠偏

## 实验设置

在相同 160,000 点共享首帧和 depth-5 候选空间层级上，对 Coffee 进行完整 300 时间点比较，frame 0 是共享首帧，frame 1–299 为动态帧；每步只使用一个随机训练视角，cam00 评估且已参与开发选型，并非独立最终测试集。两组保持 80% RMSE 图像损失、固定码率损失权重 0.008 和逐点运动近端收缩权重 1.0。

- **200 步无纠偏**：保留区域共享运动、可学习 gate、逐点运动残差及量化透明度更新，每帧优化 200 次；不执行梯度探测、GS 选点、尺度或 SH 稀疏属性更新，不新增 GS。
- **300 步纠偏**：相同运动主干，101–104 步用四个单训练视角探测并选择最多 1% 的点，105–200 步联合训练选中点尺度和 SH；201–300 步继续所选点的位置、方向、透明度及尺度、SH 纠偏。

因移除探测，200 步组的 101–104 步正常进行运动优化，合计 200 次优化；300 步组的四次探测不更新参数，因此其前 200 步有 196 次优化，两组这四步使用的训练相机也可能不同。两组均从自己的真实解码状态逐帧递推。这个对比衡量完整纠偏训练方案相对 200 步运动主干的效果；步数、选点探测及选中点位置/透明度更新同时变化，不能将差值全部归因于尺度或 SH 属性包。如需单独识别稀疏属性机制的因果贡献，还需同训练步数的无属性纠偏对照。

200 步运行 `output/experiments/coffee_motion_only_200step_prox10_300frames_20261109/20261109T091930_f8dd09`，配置 `config/coffee_motion_only_200step_prox10_300frames_20261109.yaml`；300 步运行 `output/experiments/coffee_early_joint_rmse08_prox10_1pct_300frames_20261109/20261109T024323_086490`。本次新增 `ablation_motion_only` 消融开关，关闭稀疏属性分支并在 200 步真实编码收尾；正常训练默认不启用。两次运行目录均含源码快照。

## 核验

200 步组的 299 份 manifest 均记录 200 次优化、零探测、零稀疏属性更新，实际无 `fullattr` 包和新增 GS；逐点运动残差与透明度更新保留。两组首帧参考所有数组逐项完全一致；从首帧独立顺序解码到第 299 帧，200 步组的末帧尺度、DC 和高阶 SH 与首帧逐位相同，末状态 SHA256 `69fc9693d9ea0fb94deb3a108592e6e0aa1dd3a5b2c3c2b28d672f0d735580b5`。200 步组逐帧前向与解码的最大像素差均为 0。相关回归检查 119 项通过，纯渲染和完整播放 FPS 未对本次消融另测。
