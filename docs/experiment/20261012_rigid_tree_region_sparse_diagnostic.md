# 区域残差也做稀疏选择

原实现只对 GS 局部残差做离散稀疏选择，区域用平滑存储项。结果是几乎所有区域都有微小运动。本轮给两者使用同一种 Adam 度量的近端选择：分别保留平移、旋转、两者或全部归零。根节点跳过，量化格以下的参数仍能积累；没有新增 gate 或运动模式。平滑存储值改为只做诊断，避免重复处罚，相对运动项仍参与求导。

从完整实验第 49 帧的独立 checkpoint 副本开始，仅运行第 50–52 帧，超参数保持原值（rate 0.015、warmup/ramp 20/20、1024 个可动区域、每次尝试 4 个换父节点候选）。副本只修改数据帧数为 53，全部原始 GS 属性和其他张量逐项一致。包含此前 CPU decoder 状态恢复修复。完整检查为 295 项数值检查、46 项 unittest、11 项压缩检查通过。

平均 PSNR 下降约 0.068 dB，平均增量降至 29,970 字节，减少约 12.85%。旧 GS 中姿态改变数分别为 150,149 / 164,689 / 154,858，低于原来几乎全部旧 GS 改变的状态。该方法确实形成了静止区域，不能据此断言这些区域都是真实背景，也不能据此推断从首帧运行的长期效果。

本轮没有测 FPS，不是完整 300 帧结果。原完整实验在诊断结束后恢复，继续使用原冻结实现。后续候选是增加共享区域的表达能力，检查能否用节省的预算减少局部拟合损失。
