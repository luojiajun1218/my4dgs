# 未选中个体运动提案的图像监督：210–212帧短测

## 核心想法

随机离散gate训练时，个体完整运动提案只有在所有祖先gate都采样开启时，才能从实际图像获得梯度。例如三层开启概率各为约0.48时，个体通路仅约11%的step被选中；尚未拟合好的提案可能因此被gate放弃。这是训练机制上的风险，不是对真实数据退化原因的定论。

新增可选的`spatial_gate.proposal_image_weight`，默认0。设为1时，在gate固定前，让个体完整运动提案额外渲染相同的训练视角并直接拟合图像；不经gate筛选。辅助分支只给提案图像梯度，区域、gate、α和颜色不接收这条分支的梯度；也不收集额外的新增GS统计。正式图像分支仍使用采样离散gate，并联合训练gate和区域。

gate固定后辅助监督自动关闭，仍使用既定区域＋GS量化残差输出，码流格式和解码器均不改动。该训练不通过规则或遍历比较来选择gate。

## 代码与配方

`spatial_gate.py`增加权重及配置检查；`spatial_gated_motion.py`增加独立提案位姿和阶段控制；`module.py`增加辅助渲染与图像loss，分离外观梯度和新增统计。checkpoint沿用既有配置与优化器保存，旧配置缺失该字段时按0恢复。

其余与[区域共享颜色短测](20261018_regional_dc_first3.md)一致：从特别重要基线的第209帧续跑210–212；70步随机gate联合、30步固定gate稀疏优化、100步固定支持精修，再100步新增GS；运动每步2视角。辅助渲染使用这两个相同视角，不多抽取相机。storage权重0.002、运动L1权重0.5，全部旋转关闭；区域共享DC在gate固定后开始训练，保留量化、近端收缩与低α删除。

## 实际结果

| 同范围210–212 | 平均PSNR/dB | 完整动态更新/KB | 非零GS平移块/帧 |
| --- | ---: | ---: | ---: |
| 特别重要完整基线窗口 | 33.826224 | 39.609333 | 11069.00 |
| 原区域颜色配方 | 33.863360 | 27.783333 | 3478.00 |
| 增加未选中提案的图像监督 | **33.882102** | **31.331667** | 4436.67 |

相对同配方，提高0.018742dB，增加3.548333KB；相对完整基线匹配窗口，提高0.055878dB、完整更新减少约20.90%。后者有多项配方差异，不能归为gate或辅助监督的单独贡献。

实际更新平均为运动19.752667KB、α6.244KB、共享颜色0.446333KB、新增属性4.227333KB、manifest0.661333KB；KB=1000B，一次性参考另计。区域均值232.33，独立纯渲染243.097FPS（不含解码与上传），训练窗口约34.60秒/帧。辅助监督提高了训练成本，收益幅度仍小。

当前结果支持继续检验提案训练不足这一方向，尚不能证明从共享首帧或完整300帧有效。接下来使用相同冻结数值源码验证原生0–29帧，尚未启动新完整300帧。

## 核验与证据

新增6项检查覆盖关闭路径仍获提案梯度、区域/gate不接收辅助梯度、α/颜色分离、双分支loss与真实图像包、冻结后停用、恢复与旧配置兼容；297项全量检查通过，耗时46.134秒。

三帧独立顺序解码通过，PSNR差、缓存逐像素差均为0，首尾终态checkpoint原始属性一致；来源与冻结源码哈希通过。全部运动、α、颜色、新增属性及manifest均按实际大小计入。
