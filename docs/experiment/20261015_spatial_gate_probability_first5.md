# 空间候选按选择概率计费：前 5 帧

运行：`fs_spatial_gate_probability300_first5_20261015/20261015T003748_8b3dd2`，已完成动态 frame1–5。调度为 100 motion + 100 birth + 100 固定树运动细化，未启用透明度修正。

核心想法与改动：细层候选的图像梯度按选择概率加权，存储惩罚却原来按完全启用计费，二者不一致。修正区域 L0 proximal 为概率加权的候选成本，硬选择后仅对选中的区域计费。每个新帧保留上帧有效开关作为较弱的初始倾向，避免继承 -6 饱和 logit。添加 step20/40/60/100 的候选学习记录。编码仍为单一硬区域的绝对运动加 GS 相对残差。

结果：动态均值 PSNR 34.237593 dB，motion + birth 增量均值 49.438 KB，新增 1196 GS。5 帧仍都只有 8 个有效区域。本次尚未验证 FPS 或长序列。

分析：frame1 的第二层 64 个候选在 step40/60 都有非零运动；第三层 step60 有 444 个非零候选，第四层有 2366 个。修正候选计费后，细层确实能保留运动，但顶层八个 gate 仍在 step60 全部到达 logit -6，实际细分仍失败。

进一步机制问题：训练渲染使用不同层绝对运动的加权平均，图像损失约束的是平均运动，不能保证每个候选单独承担完整运动。不同层可以互相补偿；编码成本却用单个候选作为完整运动评估。当前实际 GS 残差的 L1 损失也没有直接让各个区域解释完整 GS 运动。因此优先修正候选残差目标，再让 gate 判断细分收益，暂不据此启动长实验。
