# 空间 gate + 临时完整 GS 运动：首 5 帧迭代

运行：`fs_spatial_gate_modalinit_first5_20261014/20261014T220021_b34ea6`。每帧 100 motion + 100 birth step，未启用旧透明度修正。

核心改动：
- 用参考空间各区域的坐标中位数切出八个子区域，减少离群点造成的空间密度失衡，后续固定参考路径。
- 训练参数临时保存 GS 的完整帧运动，图像梯度直接拟合需要的变化；编码时减去启用区域的量化共享运动，只输出区域运动与点残差。共同量化网格保证归属变化只改变表示。
- step15 用观测 GS 的量化六维运动众数初始化所有候选；step30–70 学习细分 gate，后续固定开关完成拟合。众数用于初始化，不强制覆盖后续区域参数。

结论：已解决第一次实验的粗区域图像梯度误带动问题，画质有所改善；尚未学到有效树，不能启动长实验。下一步先按量化后的实际候选运动计算 gate 代价，并提高空间候选深度，让细分有机会隔离运动集合。保持同一核心方法，不增加辅助机制。
