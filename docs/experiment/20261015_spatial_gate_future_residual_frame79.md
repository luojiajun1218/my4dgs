# 第79帧：让gate估计细分后的点残差开销

## 核心问题

当前生产规则在41–60步关闭GS残差，使gate能真实影响共享场图像。但 `loss_terms` 在共享场阶段跳过点残差循环，只计算区域运动的存储开销。gate能够因图像改善而打开，却不能因“区域增加，但未来点残差减少、总存储更低”而打开。这与作者提出的细分收益没有完整对齐；它是需要验证的机制缺口，不是已经证明的长程退化唯一原因。

此次保留learnable gate、硬frontier图像、区域绝对运动、GS相对残差、100步运动+100步新增，不改透明度、不加模块或损失项。仅在gate学习时补上已有rate/relative项对未来GS残差的估计。

## 第一项局部检查：冻结自由运动作为未来成本参考

40步共享初始化前，保留完整GS量化运动的临时副本。41–60步按该参考与各候选区域运动的差，估计未来点残差字节与相对L1；参考及候选运动在该估计中都停止梯度，只给gate概率梯度。区域仍由原图像拟合，实际渲染GS残差仍严格为零。

60步冻结gate后丢弃临时参考，GS仍从零开始。绝不把自由运动恢复成实际GS残差或改回旧位姿；与此前保留全部自由运动的joint feedback不是同一规则，也不同于冻结全部图像运动后仅做编码选择。

从原worldroute第79帧step20恢复至100，测试相机只报告，不用于选参数。纯运动包不含出生GS、manifest与参考。

该检查正常结束后发现估计明显偏大：60步预测未来点残差约3021802原始代理字节，100步完整原始运动流约64896字节。自由提议中大量运动并不会在后续稀疏拟合后保留，因此不能直接把它们全部计为未来存储。

## 对齐现有稀疏裁决的估计

第二项局部修正沿用原本 `_proximal_blocks` 的四种选择：保留T/R、只T、只R、全部清零。对每个候选假设的GS残差，使用40步已有Adam二阶矩与已知首次残差prox窗口的学习率，先预测哪些块会保留，再算其字节与相对L1。没有引入新阈值或系数。

本配置首次残差prox为80步。Adam统计保持冻结、没有梯度；实际区域优化、gate图像梯度和GS零起点规则都不变。参考和估计metric在60步丢弃，不增加正式播放包。实验checkpoint仅为恢复训练临时阶段保存参考和metric，并以新目标标记禁止普通旧规则静默恢复。

这是近似预测：40步梯度统计、运动参考不会等于80步的真实统计与拟合结果。修正后60步预测点残差715444原始代理字节，仍明显高于100步整个原始运动流69739字节，不能宣称预测已准确。所验证的是使用现有裁决后的候选成本方向，而不是未来码量真值。
