# Coffee：逐点运动提前参与，30 个动态帧

沿用共享 SH1 首帧、单步单训练视角、300 步、四视角提前选点、最多 1% 点纠偏和 50% RMSE 的 `coffee_early_joint_rmse_1pct_31frames_20261108.yaml`，仅将共享独占期从 100 步缩至 75 步。第 76–100 步逐点运动残差与共享 gate 联合优化，101–104 步仍是四次单视角属性探测，后续训练流程与固定运动 storage loss 0.008 不变。动机是让早期选点以前有更多逐点运动拟合时间；这是研究假设。另一场景曾观察到更激进的 50 步共享期退化，不能直接外推至 Coffee。配置 `config/coffee_early_joint_rmse_discovery75_31frames_20261109.yaml`。

## 结果

两个方案同一共享首帧，各自真实训练并递推动态帧 1–30；相机逐步序列一致。cam00 已参与开发选型，不是独立测试；动态 KB=1000 字节，包含 manifest，首帧另计。
