# Gate 控制个体残差通路：已完成三帧短测

## 核心想法与当前结论

原方法在任意粗细区域下都允许 GS 个体残差，个体通道可以补偿区域预测。这里尝试让 gate 直接控制运动自由度：停在粗区域时只有共享运动，沿内部 gate 到达最深叶子后才允许个体残差。前向使用硬划分；整个运动场的 STE 让未激活候选仍有机会学习。

该约束确实减少了实际个体更新和文件大小，但**尚未证明相同画质下更省，也尚未达到完整序列目标**。较好的三帧候选为 33.739380 dB、31.467 KB；匹配旧基线为 33.826224 dB、39.609333 KB，即少 20.6% 字节、低约 0.087 dB。没有据此启动完整 300 帧。

本记录的表格为已完成、已独立核验的210–212帧窗口。从共享首帧训练的前30帧也已完成，得到34.042090dB/91.428138KB，差于匹配基线，详见[原生前30帧记录](20261017_hierarchical_private_native_first30.md)；没有启动新完整300帧。

## 代码改动

新增默认关闭的 `spatial_gate.hierarchical_private`，目前要求绝对区域、联合图像拟合和图像 Adam＋GS 近端稀疏。内部 gate 的路径连乘给出到达最深叶子的软概率；硬许可由 GS 是否实际分配到最深叶子确定。

- 渲染和码流都把未获许可的 GS 平移、旋转残差置零。现有解码器可以直接解码这些数值，无需额外传逐点许可表。最深叶子开关位仍为 0，未改变 SPG 对叶子位的约束。
- v1 中，潜在个体通道的图像梯度和近端 L1/L0 成本按通路概率匹配缩放；gate 同时收到打开个体容量的图像收益和存储惩罚。不是通过遍历比较决定开关。
- gate 固定时清理不允许的 GS 值，并为硬图像通路重启运动 Adam 状态；共享区域与被允许的个体修正继续联合拟合。
- 帧内使用独立的许可策略标记。下一帧切换方法时，先按上一帧策略读取实际已应用的运动，再启用新策略，避免把旧方案的个体运动误当作 0。跨帧热启动、来源行、退休 GS 和恢复均有检查。
- v2 试图按通路概率归一化候选运动参数梯度，gate 梯度保持原样，近端改为条件成本并保留有效候选的矩。两项变化合并后未改善结果，因此没有推广。

当前工作树已回到较好的 v1；与 v1 已通过 250 项检查的冻结源码逐文件比对，59 个源文件哈希完全一致。v2 的源码和 251 项检查证据保存在它自己的冻结 run 中，不会静默把 v1 checkpoint 当作 v2 恢复。

## 分析与限制

层级约束建立了开关与个体自由度的直接联系：例如首个 v1 短测第 210 帧，允许个体更新的 GS 从第 1 步的 0 个变为第 70 步的 11125 个，并在固定 gate 后保持不变。最终真实非零个体块更少，并非只修改了存储估计。

然而放宽惩罚不保证画质提高，v2 优化修正也没有改善结果。一个可能问题是共享和私有通道仍以相加方式同时响应相同图像误差。只读检查中，第 210 帧 v2 在两类参数均变化的 4120 个获许可 GS 中，约 72.4% 的区域与个体更新方向夹角小于 90 度。该分析使用近似连续预热量，相关性**不能证明因果**；它仅提示继续检查两路如何分工。

如果原生前缀仍退化，下一步优先考虑：让私有分支训练完整运动提案，gate 选择共享场或私有提案，编码时才减去叶子的共享预测得到 GS 残差，从参数化上避免两路都重复追同一误差。该结构**尚未实现**。必须处理好叶子预测器的编码目标、围绕预测器的近端收缩，以及渲染与解码的浮点相加顺序，不能仅把已有 GS 参数改个名字。
