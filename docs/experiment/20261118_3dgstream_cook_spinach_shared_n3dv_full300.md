# 3DGStream：cook_spinach 共享首帧 300 帧复现

复现官方 3DGStream 两阶段逐帧训练（150 + 100 步），用现有 N3DV 半分辨率图像、cam00 测试视角及本项目共享的 15000 步首帧；原始图像通过软链接读取。官方预热网络保留，但 AABB 改为当前场景共享首帧点坐标的 6.7%—93.3% 分位范围。源码采用 747ddfef，使用 ReConGS 环境及隔离构建的官方光栅化器和 tiny-cuda-nn 1.6；修复新版 PyTorch 的 stdout 兼容性并增加指标和播放统计。因此这是共享首帧、统一数据口径下的复现，不等同论文原始设置。

| 指标 | 结果 |
|---|---:|
| 299 动态帧 PSNR / SSIM / LPIPS | 32.8863 / 0.95478 / 0.13596 |
| 含首帧 300 帧 PSNR / SSIM / LPIPS | 32.8902 / 0.95480 / 0.13592 |
| 动态 NTC + 新增高斯 | 8040.83 KB/动态帧 |
| 首帧和动态文件均摊（官方公式） | 8068.68 KB/帧 |
| 动态帧平均墙钟时间（含评估和保存） | 11.45 秒/帧 |
| 已解码纯渲染 / 读取、解码、更新、渲染 | 282.59 / 78.05 FPS |
| 重放画面与保存 PNG 的最大 MAE | 0.000982 |

动态大小按实际保存的 NTC.pth 和新增 PLY 文件计，不包含训练用的完整中间高斯 PLY；官方公式还包含导出的首帧 PLY。这里不将未经验证的量化或压缩估算当作已实现码流。播放速度是 Python 实现的顺序重放、预热操作系统文件缓存、cam00、无显示，不是官方 C++ 查看器的论文测速。训练时间不含共享首帧训练，且含评估和保存；不可与仅统计优化的时间直接等同。

数据、每帧指标、实际码流文件、日志与测速详情见 `/mnt/SSD500GB/n3dv/3dgstream/experiments/shared_n3dv_20261118/cook_spinach`。六场景比较和潜在收益归因需待全部场景完成后分析。
