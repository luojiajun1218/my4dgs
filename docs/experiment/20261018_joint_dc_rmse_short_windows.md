# 同一门控配方改用RMSE像素项：早晚短窗口

## 想法和实现

保留随机STE gate、区域DC联合学习、独立GS运动提案与量化近端，将像素L1改为全图平滑RMSE，使较小误差的像素梯度随误差减弱。提交`654339f`增加可选`photometric_loss: rmse`，默认L1行为不变；主图像、提案辅助图像和新增阶段均使用同一选项，SSIM权重仍为0.2。

稳定形式为`m/(sqrt(m+1e-8)+1e-4)`，其中`m`是全部像素通道的均方误差。没有改变gate选择方法、量化、码流或步数。310项完整检查通过。

## 完成结果

KB=1000B，完整动态更新计入运动、α、区域DC、新增属性及manifest，一次性参考另计。所有窗口仍使用300帧数据配置、1600×1199图像；运动200步，其中70步联合gate、30步固定gate、100步固定支持精修，再100步新增。每个运动step两个视角。

晚期提高0.117481dB，但更新增加19.446KB。其运动/α/DC/新增/manifest分别为28.758/8.937333/0.516/12.033333/0.662KB。GS平移块均值5461.33、新增617，均高于原L1配方（4571.67、199），不能宣称小更新或新增减少。

第210帧新增前step200已由33.816254提高到33.932751dB，说明收益在新增前就已存在；末阶段还会继续训练旧点DC，不能把剩余收益全部归于新增。

原生早期动态PSNR比原L1低0.025225dB，存储增加36.307KB，未推广到前30帧或完整300帧。含共享第0帧的0–3均值为34.121777dB。早晚窗口行为不同，不能用晚期短测替代完整目标。
