## 核心想法与实现

此前GS从一开始自由拟合，容易先形成围绕粗预测的零散运动，区域和gate随后很难重新形成共享。本次先让共享模型承担实际图像拟合，再开放GS例外残差。

源码为`7c462fb`，核心开关是默认关闭的`spatial_gate.shared_discovery`，本次显式开启。位置增量为`Δx_i = Σ_{n∈path(i,g)} Q(δ_n) + Q(e_i)`：区域存父子相对增量，gate学习空间共享粒度；固定gate后所有GS均可使用残差，不限制为最细层。

每个动态帧300步，流程为：

1. **1–20步**：预热共享区域和区域颜色，gate不更新。GS残差为0、位移学习率为0，但记录真实图像梯度尺度。
2. **21–70步**：用实际采样共享场的图像误差及区域成本学习gate，使用随机离散前向和STE梯度；GS残差仍为0。首动态帧的确定性细分开关从关闭开始，后续继承前帧区域参数及弱化的gate logit。
3. **71–100步**：固定gate，开放全部GS残差，区域与GS稀疏联合拟合。保留GS梯度的二阶统计，清空一阶方向，避免刚开放时放大小更新。
4. **101–200步**：固定非零块的支持范围，精修运动幅度；这一阶段不继续施加运动稀疏惩罚。
5. **201–300步**：普通新增GS、量化及阈值删除，并继续区域DC拟合。

运动每步2视角，新增每步1视角。最大树深度4，`robust_median`初始化，远点连最近有效区域，GS按上一帧解码位置确定空间归属。storage权重0.002、GS残差L1=0.5，区域/GS平移步长均为`6e-5×extent`；α步长0.01，α＜0.01删除。区域及GS旋转更新、出生GS旋转更新均关闭。区域DC使用相同gate和0.01量化步长。

共享阶段的主图像已经来自共享预测，额外预测器图像权重为0。前述区域物理图像梯度、温度独立的硬采样概率及冻结后优化器状态修正均保留。方法源码在短测前通过340项完整检查和12项针对性检查；本次70个冻结Python文件与该提交、当前代码逐项SHA-256一致。

先完成并核验原生动态1–3，再同配方延长至29，最后延长至299；旧前缀没有重编码，数据配置始终为300帧。短测过程见[前三帧](20261018_shared_discovery_first3.md)和[前30帧](20261018_shared_discovery_native_first30.md)。

## gate实际承担了什么

299个动态帧中，**283帧有细分、16帧仅使用8个粗区域**；选中区域数范围8–306，平均112.04。所用共享节点连必要祖先平均127.84个，其中非零块再按稀疏规则编码。约70.1%的旧GS停在第一层、23.3%在第二层、3.7%在第三层、2.9%在第四层。

平均13507.95个旧GS需要平移残差，按点数加权约6.42%；约93.58%不需要逐点平移残差，**其中也包含静止点**。这些统计说明共享粒度会随空间和帧变化，不能只凭开关数量判断性能贡献。

固定同一份总量化运动，做新增前运动包的只读重编码：

| 帧/选中区域 | 当前共享运动包/KB | 按码率/L1代理重拟合8粗区域/KB | 全部改成GS运动/KB |
| --- | ---: | ---: | ---: |
| 239 / 50 | 37.202 | 78.947 | 149.451 |
| 269 / 8 | 37.838 | 37.790 | 127.167 |

第239帧的层级比重拟合8粗区域省52.88%的运动包，GS平移块从39323减少到13144。第269帧实际选择粗层，体现的是粗共享收益，**没有细分增益**；额外48B来自无关后代开关，运动字段完全相同。上述只含新增前运动，不是整帧存储；量化整数运动不变，浮点重组差不超过3.815e-6，源检查点未修改。

针对第269帧，再读取step20/70，在全部20个训练视角和留出cam00上比较现有候选图像，使用真实未截断的`0.8×L1+0.2×DSSIM`目标。在step20，联合使用候选颜色时，粗层训练损失0.014685813，四层为0.015284884；step70固定当前颜色后，粗层为0.014529740，四层为0.014673835，留出PSNR分别为34.1215和33.9861dB。**在这些已学到的候选下，选择粗层与训练图像目标一致。**

step70已丢弃未选中的颜色表，因此该步只能固定当前颜色比较运动；step20才保留联合候选颜色。所有比较均在训练结束后只读进行，不参与gate决策，也没有重新训练替代划分。它们不能替代“充分训练的固定细树”消融。本次还改变了区域颜色、稀疏强度和精修步数，不能将整体PSNR增益全部归因于gate。
