# Learnable gate：候选训练与共享运动机制短测

## 问题与结论

[完整旋转全关300帧](20261017_all_rotation_off_full300.md)为34.054672dB、38.194930KB/动态帧、233.014纯渲染FPS，但299个动态帧最后都只有8个粗区域。属性优化改善整体结果，尚不足以证明learnable gate形成了有效共享运动。

本次从同一已完成第209帧checkpoint恢复，仅训练210–212；配置仍加载300帧、1600×1199、2个运动视角/步，100运动＋100新增步。保持所有旋转更新关闭，不加入颜色通道。完整更新包含运动、透明度、新增属性和manifest，参考帧另计。

## 思路与实现

第一步处理候选训练不充分的问题。关闭的子区域获得当前完整运动的初始化，已选区域、GS残差与gate保持原值，初始化不改变图像。`candidate_refresh_interval`默认0，启用后只在学习gate阶段更新未选中候选；`temporal_logit_decay`默认1，可保留前帧开关符号并减弱置信度累积。首轮用坐标中位数；后两轮改为与块码率＋残差目标相同的整向量代表值，避免三个坐标的中位数拼成不存在的运动。gate始终由梯度和STE优化，没有用规则遍历替代学习。

第二步区分两种更新：区域学习真实共同运动时，应保留其图像梯度造成的位置变化；gate改变表示划分时，重新表达GS残差可以保持已拟合画面连续。新增可选`shared_image_recode`，默认false：选中区域从图像误差学习，GS使用图像Adam和近端稀疏，gate通过不同划分下的剩余GS残差及区域开销学习。未选中候选单独拟合完整运动目标，按区域观测点数归一化，不再被祖先关闭概率压低；其辅助目标不能通过关闭gate逃避。

gate切换保持完整运动不变，因此该模式没有虚构直接图像gate梯度；图像训练共享运动，码率/残差目标训练划分。反事实重编码的残差代价只为gate提供梯度，不给真实区域运动施加假设GS同时补偿的导数。

第三步检查稀疏是否过早移除共享信号。发现版使用20步码率预热，GS连续近端和块L0延迟到gate冻结后；它确实产生大量实际细分，但私有残差明显增加。渐进版使用20步预热、50步正则强度爬升，恢复逐步GS稀疏，同时将初始logit改为-0.2、前帧logit保留系数改为0.1；仍未形成有用细分。训练墙钟分别约35.44和31.78秒/帧，未改善效率。

## 核验与限制

235项数值检查通过，覆盖关闭候选初始化不改画面、合成运动中gate自主学会有利细分、区域图像更新不被抵消、切分保持完整运动、GS图像Adam与稀疏分离、阶段边界与恢复。四个真实短测均完成独立顺序解码和原始checkpoint核对，PSNR差和缓存逐像素差均为0；旧点朝向不变、新点朝向继承。

证据集中在`output/fs_goal_rd_20261017/gate_mechanism_short_comparison.json`及其中记录的四个run。各run保留自己的配置、冻结源码、来源哈希和独立核验文件。新控制默认关闭；已完成300帧的固定源码和文件未改变。

结果表明单独修补候选初始化、共享图像梯度或稀疏时机，尚未建立共享收益。后续应优先诊断：空间候选内部运动是否一致、单个共享平移是否足以解释这些运动、区域与GS两条通道是否重复解释误差，以及训练代价能否预测真实编码收益。最终需要证明相同画质下更少的非零个体残差和实际字节；当前不宣称该贡献已经成立。
