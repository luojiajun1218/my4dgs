# robust_median、最近区域与 70+30 联合训练：两视角短流程核验

完成共享首帧加两个动态帧的真实 GPU 训练，以及从独立码流解码后的三帧核验。此记录用于确认新流程可执行，不能代表 300 帧画质、存储或速度已经达标。

## 配方与代码改动

当前入口为 `config/fs_spatial_gate_depth4_200_full300_20261016.yaml`，新实验名为 `fs_spatial_gate_joint70_robustnearest_depth4_full300_20261016`。本次短测另用临时实验名，没有覆盖历史结果。

- 最大深度 4；`robust_median` 以首帧坐标中位数为中心，使用距离的 0.999 分位数内的 GS 估计分割面。远处 GS 保留，连接到距离最近的非空叶区域中心，再由该路径上的 gate 决定实际共享层级。
- 最近区域的中心由首帧统计范围内的 GS 求均值，固定不动。支持球、叶中心与叶编号只存进共享参考一次；编码、解码都从前一帧已解码坐标计算归属。不是删除远点，也不是每帧重新聚类。
- 第一个动态帧（frame 1）的所有可分裂 gate 打开。`min_region_size: 2` 允许非空分支展开；空分支、末层、只有一个非空子分支的节点不作为可训练开关。
- 1–70 步同时训练 gate、区域平移/旋转、GS 平移/旋转残差；71–100 步固定学到的 gate，继续训练两级运动。固定 gate 不等于把 gate 全部关上。
- 每个运动 step 使用两个同一时刻的训练相机，平均图像损失后更新一次；相机无关正则只计一次。101–200 步训练新增 GS，每步一个视角。合计 200 次参数更新、300 次视角渲染。
- 后续帧继承前帧完整运动增量、区域参数与 gate logits，不再将平移增量乘 0.6。归属变化时重算 GS 残差，保持继承的完整运动；切换 gate 同样重编码残差，避免姿态跳变。跨帧 Adam 状态仍重新初始化，第 70 步固定 gate 时保留本帧 Adam 状态与 GS 残差。
- storage 权重 0.002、固定首帧归一化；平移步长约 0.000194809 世界单位、旋转步长 0.001 rad；相对运动权重 1.0。关闭原来的运动图像粗到细调度。每 20 步的块稀疏化保留，固定 gate 后第 80/100 步仍刷新区域代表运动。

`pipeline/model/spatial_gate.py` 实现稳健建树和确定性最近叶路由；`spatial_gated_motion.py` 实现联合训练、完整增量热启动和 gate 切换重编码。参考状态、导出和独立回放同步修改在 `rigid_tree_codec.py`、`pipeline/trainer.py` 及两个 replay/benchmark 脚本中。旧配置默认保留 staged 路径，旧参考没有最近叶字段时仍按原分割面路由。

新增 GS 保留现有梯度驱动的克隆/分裂/剪枝机制：使用最后 30 个运动 step 的统计，围绕源 GS 的旋转协方差采样，继承源 SH、尺度和旋转；不透明度 raw logit 初始化为 0.1。新增阶段冻结已有 GS，只优化新增 GS，并保留新增属性量化和源编号编码。区域旋转仍只影响 GS 椭球朝向，不绕区域中心旋转点的位置。

## 已完成结果

RTX 3090 Ti，350 W，随机种子 0，共享已有原生首帧；输出图像 1600×1199。首帧原生 GS 按原有不透明度阈值 0.0075 从 214996 个保留 206237 个；这一步与 robust_median 的远点处理不同。最近叶支持统计排除 207 个远点的统计贡献，所有保留 GS 仍参与渲染。

|---|---:|---:|---:|---:|---:|
| 1 | 34.4353 | 27.4848 | 171954 | 172389 | 80 |
| 2 | 34.3890 | 26.4486 | 106617 | 107052 | 82 |
| 平均 | **34.4122** | **26.9667** | **139285.5** | **139720.5** | 81 |

完整更新为运动、新增属性 payload 加每帧 manifest；不含一次性共享参考 17720236 B。KB 使用十进制，即平均完整更新约 139.72 KB。

独立进程从参考与增量解码，验证状态哈希，并渲染保留测试相机 cam00；两帧的 PSNR、SSIM、L1 与训练时保存值差异均为 0。frame 2 诊断确认初始化来自 `previous_full_increment`，frame 1 为 `all_eligible_open`；第 70 步 gate 固定，第 100 步 GS 残差仍在训练。

每帧预热 10 次、同步计时 50 次完整渲染：三帧合计纯渲染 201.66 FPS，两个动态帧 201.62 FPS。该值不含文件读取、CPU 解码与验证、上传；动态帧 CPU 读取/解码/验证分别为约 0.603/0.472 秒，不能将纯渲染 FPS 当成端到端播放速度。

完整回归为 153 项，149 项通过、4 项 GPU 专项跳过；本次另有上述真实 GPU 训练和独立渲染验证。新增 8 项测试覆盖远点归属、参考往返与哈希、首步联合梯度、残差成本、gate 切换姿态连续、第 70 步保留残差与 Adam 状态、含新增点的下一帧热启动和 checkpoint 恢复。

## 分析与限制

流程和独立解码通过，但压缩尚未达到目标。两帧均保持 583 个可分裂 gate 全开，活动区域分别为 4050/4047，几乎所有 GS 都在第 4 层；gate 有梯度，当前短测中没有跨过关闭阈值。全开初始化和较弱 storage 权重可能使前几帧优先拟合画质、尚未形成层级合并；不能据此声称 gate 已学到有效压缩，也不能仅用这两帧判定长期不会关闭。

这是最终两视角配方的工程验收。训练中关闭了阶段截图、保存图像，只在 frame 1 的第 70/200 步保存 checkpoint；同时运行过 CPU 回归，因此耗时不是严格提速对照。它与此前默认 median、分阶段训练、不同视角数的实验不构成单变量画质或速度比较。没有执行该配方的完整 300 帧训练。
