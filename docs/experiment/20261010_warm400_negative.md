# 400步运动与跨帧初始化的联合候选：前29帧负结果

这次检验能否通过更充分的运动拟合减轻后续帧退化。结果没有支持这组候选：相同1–29帧平均PSNR降低0.1416 dB，存储和训练时间都增加。因此在保存第29帧checkpoint后结束了这组运行；停止时第30帧已经完成。这不是完整64帧或300帧结果。

## 核心改动

以固定3层颜色复用对照为基础，将运动阶段200步改为400步，其中根拟合100步、完整树拟合200步、门压缩80步、固定门精修20步。新增阶段仍为100步。

`common_contrast.py` 的 `motion_prior_decay: 0.6` 只在复用同一布局时，把上一帧已经量化、已经到达的运动参数用于初始化；关闭分支不携带隐藏运动。第1帧从零初始化，第2帧起使用0.6。颜色复用预算同时从0.2%改为0.5%。保持96／12／6粒度、固定树、storage权重0.002和原有学习率。

另启用 `motion_entropy_compression: true`。它对原运动包进行无损zlib封装，有长度和CRC验证，旧码流仍可读取。软存储损失使用压缩前成本，实际存储使用真实文件大小。这个封装不改变解码的参数，但不能抵消候选产生的更多表示。

## 相同区间的结果

测试cam00、训练cam01–20、1600×1199、共享首帧。KB为1000字节，包含运动、颜色和新增点文件，排除首帧及诊断产物。

这是一组联合改动，不能单独断言“跨帧先验无效”或“训练400步无效”。可能原因包括固定学习率下过度拟合部分视角、运动初始化偏差，以及扩大颜色更新集合后更多旧点改动。只有分开对照才能确认原因。当前更合理的下一步是检查运动学习率和新增点的几何初始化，而不是继续扩大这组预算。
