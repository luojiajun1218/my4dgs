# 因果平移初值：完整100帧未解决质量退化，完整更新偏大

## Idea、改动与故障恢复

本轮只增加`causal_translation_init=True`。从最近两段已完成、已解码的完整WORLD位移，按稳定GS ID生成当前独立GS平移初值；区域与旋转仍为0、Adam全新。两段都须有效观测、GS整数位移范数严格>4、方向余弦≥0.5、幅值比≤2。step100在Adam/prox之后、结构维护之前撤回当前缺测预测行并清理对应Adam moments；不改其他行和scalar step，不将预测写入当前观测/历史。

代码集中于`causal_translation_prediction.py`、`causal_motion_initialization.py`及setup/optimizer/checkpoint接线；100/200记录模型对初值的校正。checkpoint保留按ID排序的初值与fallback状态，缺失/错帧/错阶段状态会拒绝恢复；9项helper、7项真实模型CPU回归通过。保持原有local维护、回收、tree、opacity、量化和预算。

前一个run意外退出于frame28训练中，原因未知，见`20261014_causalinit_first100_interrupted27.md`。本100b从共享首帧、同源码同参数重新运行，是故障恢复，不是对照实验；前缀不与100b混合平均。

motion包含区域/旧GS运动，以及新GS位置、旋转、出生source等；`birth.bin`主要保存appearance，不能把motion总大小全部归为旧GS残存。step200尚无本帧birth的packet_score可核实：平均raw143944.3 B，由layout217.5、ownership2459.1、shared727.7、residual140441.1、header/survivor/checksum99 B组成；该阶段压缩包平均74134.7 B。raw residual占比高，但压缩非线性，且最终包包含出生，不能把这些raw分块当最终压缩字节份额相加归因。

局部subset共32次尝试、18次接受，累计12206次GS归属分配（跨维护可重复，非去重数）。world-zero回收全程0；30起叶容量基本用满，legacy merge腾出的容量由subset/split/root继续使用。整轮没有非root内部节点、最大depth1，开启tree并未形成实际多层共享。维护路径运行不等于已解决质量/成本目标。

## 保存图像的辅助定位与后续方向

frame49保存图像可见手/喷枪附近散碎拖影，狗嘴也有误差，背景相对稳定。8bit PNG固定ROI辅助统计：手/喷枪`x630:805,y740:1000`占2.3718%像素、16.4302% SSE；人物`x660:1030,y495:1005`占9.8363%、20.3175% SSE；狗`x80:290,y790:1070`占3.0651%、2.5874% SSE。人物与手ROI重叠，不可相加；PNG PSNR32.9893与官方浮点49帧33.0038口径不同。这只能定位部分误差，不能声称所有退化来自这些区域，也不是GT流证据。

后续应重新检查自由运动拟合与共享运动表示为何保留这些局部误差，以及旧GS appearance固定等约束是否限制修复；本轮尚未提供唯一因果解释。当前结果明确不支持把因果初值当作已经解决长期退化的机制。保持单项改进、严格online，不用未来帧或heldout数值参与训练选择。
