# 200 步联合优化＋最终补点上限 200：完整实验记录

实验日期与整理日期：2026-10-02。

**完成情况：共享首帧 0，第 1–299 帧全部完成。** 训练日志从 00:30 到 02:37。本轮取消了新增候选池上限，最终平均保留 198.84 个新点，补点数量达到了预期。但画质和参数存储的组合比上一版更差，尚未解决背景失真和运动拟合问题。

## 1. 核心思路与改动

上一版平均每帧只留下约 17 个新点。用户决定先解决补点数量，再测试取消固定 gate 精修是否有效。

本轮同时修改两项训练行为：

- `max_new_gaussians: null`：取消候选池数量上限，原有梯度和尺度生成条件、训练期裁剪仍生效。
- `max_retained_gaussians: 200`：最终保存前，先排除低透明度点；超过 200 个时按量化后透明度降序保留，同值按原行序。这个排序是启发式，不是图像贡献评分，也不强留点凑够最低数量。
- `gate_refine_steps: 0`：运动第 1–200 步全部联合学习 gate 和运动，随后 100 步只训练新增 GS。

日志新增低透明度、屏幕尺寸、世界尺寸裁剪计数，以及最终预算筛除计数。存储统计、树成员映射和下一帧补偿删除数量都按最终保留结果计算。

Storage 权重仍为 `0.001`，前 30 步关闭、之后 50 步加满；每 5 帧重建，按存活成员对应继承 gate；运动初始化衰减仍为 `0.6`。联合阶段的“硬门前向、全 SPLIT 运动反向”代理没有修改。温度仍从 `1.5` 降到 `0.5`，但退火区间随联合阶段从 150 步延长到了 200 步。

因此，本轮与上一版不是只改变精修开关的单变量对照，也没有通过多随机种子重复实验估计方差。

## 4. 补点问题解决到哪一步

**数量问题解决了，质量收益仍有限。** 几乎每帧都保留了 200 个新点，补点阶段净收益比上一版更大，但全序列平均只增加约 0.029 dB，无法抵消运动阶段的失真。

本轮训练期裁剪计数累计为：低透明度 **882710**、世界尺寸 **1**、屏幕尺寸 **0**、多原因重叠 **0**。这是多帧、多次裁剪事件的累计，不能当作唯一 GS 身份数量。初步说明在实际执行的筛选中，低透明度占主导。

最终预算还累计额外筛除了 **103886** 个透明度合格的新点。训练时这些候选一起参与拟合，最终只留下最多 200 个，可能造成训练与最终表示不一致。透明度也不等于图像贡献。

**当前没有保存同一帧最终预算筛选前后的独立测试评估**，所以不能把 200→300 步的净收益拆成“候选训练收益”和“最终预算裁剪损失”。这需要补诊断，不能仅凭候选被删数量推断损失大小。

## 5. 删除与 KEEP

本轮日志中误删 KEEP 的数量仍为 0。但补偿删除开始有可测影响：94 帧的 cam00 PSNR 下降，最明显是第 240 帧的 **−0.2130 dB**；部分帧删除后指标上升，全序列平均变化约 +0.0026 dB。不能再沿用上一版“已测删除影响都是零”的结论。

全局 KEEP 比例下降不等于已证明背景被错误移动。下一步仍需将背景失真与实际 GS 运动和 gate 对应起来。KEEP 保留上一帧姿态，也不会恢复此前已损坏的表示。

## 6. 判断与建议

1. 保留新增 GS，候选池与最终预算分离的数量目标已实现，不宜再用“最终只有十几个点”解释本轮。
2. 200 步全部联合优化没有带来更好的最终质量与存储组合；但本轮同时修改了补点预算，尚不能单独归因于取消精修。
3. 若要回答精修是否有效，下一组应保持本轮补点规则，只恢复 150 步联合＋50 步固定门精修，并控制随机种子、视角顺序。建议先做短帧对照，参数需讨论确认。
4. 补充最终预算筛点前后的同视角评估，以量化保留排序的影响。
5. “硬门前向、全 SPLIT 运动反向”的不一致仍是待验证风险。本轮结果没有单独验证或排除它。
