# 区域物理图像拟合与gate切换重编码：原生三帧

## 核心机制

主图像始终使用`P_owner + E_GS`，区域参数和GS残差接收真实图像梯度。gate学习时，暂时固定当前量化总运动，计算不同共享预测下的剩余编码成本；这部分成本只训练gate，不把“假设GS补偿区域变化”的梯度加给区域参数。

gate切换owner时，按同一总运动改写GS残差，保留其优化状态及bin余量。区域参数本身的图像更新不会被补偿。共享预测还做一次真实辅助图像监督，使用同一采样和同一对视角，权重0.25，外观detach。开关由STE学习，没有逐个渲染比较或手工选择。

提交`2cc386a`扩展`shared_image_recode`的受限随机联合图像组合，复用原码流；配置为相对区域、全GS允许残差，不使用完整运动提案。6项新检查包含通过梯度学习相关子运动并降低真实包大小、仅gate切换重编码、GS优化状态与余量保持、区域物理更新、共享图像梯度和精确恢复。**334项完整检查通过，47.797秒。**

## 检查与下一步

第一帧step1/35/70都停在8区域，梯度范数后两者为6.380e-6和1.124e-9。说明加入合法码率梯度与真实区域图像监督后，候选训练动态仍需要改进。

检查到三个问题，后续将一起验证其实际效果：

- 参数按整张表交给Adam，未参与当前图像的细候选仍可沿旧一阶动量移动；应停止这些行的速度更新，同时保留方差估计。
- 原采样`logit/T + logistic_noise`会随温度降低额外压低负logit的采样概率；改为`(logit+noise)/T`，使实际概率为`sigmoid(logit)`，温度只控制反向平滑，并让码率期望使用同一概率。
- 该模式主图像的GS导数在冻结前后相同，不必在step70清空GS照片梯度的Adam状态；区域的辅助目标停止时仍重启区域状态。

上述均为待短测的训练改进，不计为本次已取得的收益；不会直接设置gate为打开。新采样需要独立checkpoint标志，避免静默混用旧状态。
