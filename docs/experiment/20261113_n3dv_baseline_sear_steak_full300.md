# sear_steak：当前代码的 300 时间点 baseline

## 设置

共享首帧 frame 0 和动态帧 1–299；候选空间层级、区域共享运动与逐点残差，每动态帧 200 步，区域与逐点属性联合更新。沿用场景现有参数，本次没有改动训练代码。短实验为 30 个时间点（29 个动态帧），平均 PSNR 34.3831 dB、动态存储 37.99 KB/帧，未据此改参。完整配置 `config/n3dv_baseline_sear_steak_300frames_20261113.yaml`；结果经用户同意整体移至 `output/best/sear_steak`。运行时日志及帧摘要保留原始输出路径作为历史信息。

## 结果

测试视角逐动态帧算术平均；KB=1000 B。动态存储包括完整动态帧包、不含共享首帧；分段值由日志中的逐帧小数计算。

| 动态帧 | PSNR / dB | 动态 KB/帧 |
|---|---:|---:|
| 1–299 | 34.1503 | 31.80 |
| 1–100 | 34.2688 | 34.08 |
| 101–200 | 34.2310 | 31.08 |
| 201–299 | 33.9492 | 30.22 |

总体 SSIM 0.9651、LPIPS 0.1197；0/299 帧超过 50 KB，最大 49.43 KB。共享首帧约 11.299 MB，动态总计约 9.51 MB，合计约 20.81 MB；平均训练 17.34 秒/动态帧。日志包含 1–299 共 299 个不同的帧并正常结束；本次未独立顺序回放，也未测已解码渲染 FPS 或包含读包和解码的完整播放 FPS。

全序列动态帧 PSNR 超过 34 dB，未达到 34.2 dB；动态码率低于 50 KB。`output/best/index.json` 中 `previous_record` 保留的旧方案历史记录为 34.0633 dB、39.00 KB/帧，原结果目录已失效；本次高约 0.0870 dB 且每帧少约 7.20 KB，但两次方案和代码版本不同，不能将差异归因于单个机制。末段均值低于前段，画面和运动随时间变化，单次结果不能证明累积漂移，也不足以证明本方案超过 SOTA。

本次沿用短实验配置中的 checkpoint 保存帧列表，因此没有保存 frame 299 的训练 checkpoint；完整 1–299 动态帧码流及首帧参考均已保存。
