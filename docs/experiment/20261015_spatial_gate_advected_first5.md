# 区域边界随共同运动移动：前5帧基本持平，继续检查时间积累

## 核心idea与改动

原方法的空间分割面固定在首帧。此前CPU逐帧模拟显示，点运动及新增点会使少数最深候选拥挤；单纯增加层数又会沿运动轨迹生成深链。因此本轮只检查区域调整规则：每帧解码后，分割面按原成员实际位置增量的逐坐标中位数平移；空节点继承父增量。有成员节点不重复加父增量。

仍用原五层候选树与learnable gate，父子连接不变。区域运动仍是绝对量，GS仍存区域残差；旋转只改变GS朝向。损失、量化、学习率、每步4个运动视角、100步运动+100步新增均沿用原规则，没有加入候选增长、透明度修正或额外损失。

隔离后端用APG1标记新解码规则，分割面坐标从已有解码位置推导；每包标记增加4字节，但新分组会影响残差及压缩率，不能据此宣称完整存储只增加4字节。出生点没有前帧位移，不参与平移统计，其归属元数据按更新后的分割面生成。

输出：`output/fs_spatial_gate_advected_200_first5_20261015/20261015T190945_cb6178`。配置及入口：`/tmp/fs_spatial_gate_advected_200_first5_20261015.yaml`、`/tmp/my4dgs_run_advected_spatial_20261015.py`。普通main.py/旧解码器不会安装本实验规则。完整基础源码及5份实验脚本冻结在该运行的source_snapshot。
