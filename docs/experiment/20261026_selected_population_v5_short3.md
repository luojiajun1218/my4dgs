# 全训练视角与最终结构再拟合：短3帧

完成日期：2026-10-26。首帧＋2动态帧全部完成并独立解码。固定132586 GS首帧、1345×1008半分辨率监督，learnable gate不变。未达标，暂未扩大到30/300帧。

## 核心机制

撤销额外的16拟合＋4内部留出，全部20个标准训练相机参与候选拟合和实际码率选择，cam00继续完全隔离。按完整场景mean MSE下降选择原子区域替换，不再逐相机零损伤否决。

保留粗/细两轮探索，各600步。选择最终候选结构后撤回其他候选，恢复其旧源覆盖；被选择的旧点删除仅作为渲染keep-mask，原始incumbent不变。使用选定真实码流的decoded survivor参考和固定source，再完整训练600步。refit未改善训练失真或超预算则回退选择时已验证的场景，最后才物理退休旧点。动态总步数最多2000；无birth跳过最终600步。

改动主要在`pipeline/model/residual_birth.py`、`pipeline/module.py`、`pipeline/sequence_extension.py`及回归。长序列扩展校验交叉检查实际截止、global_step与manifest，避免把1400/2000误判为800。代码由普通agent完成。

## 判断与下一步

延长训练、修复候选与提交结构不一致、恢复全部训练相机，都没有保证测试视角改善。当前需要区分独立MVS空间出生与旧点替换各自的损失，避免继续扩大一个会损伤未见视角的出生机制。正在按实际最终参数分类型只读复核；不将测试图用于候选选择。

静态残差分析见`20261026_baseline_persistent_residual_analysis.md`，提示大量误差延续自首帧，可能更适合几何一致、长期保留的修复，而不是把所有RGB残差解释成新空间表面。尚未证明增加持续出生容量就能达标。

## 精确重放修正

审查发现：把trial已归一化的量化四元数重新当作工作参数，会再次量化，初始化和fallback不是严格幂等。2048个非网格四元数中29个漂移，最大分量差4.59e-4。当前两帧实际初始化MSE与selected MSE最大差约1.9e-9/1.5e-9，不能把第二帧-0.143dB主要归因于此。

后续根源码v5_1已保存原探索池的连续fitted参数，约束种子仍使用trial几何；2048个真实码流检查中六类属性全部逐位重放一致，全349回归通过。本轮冻结v5未追溯修改。
