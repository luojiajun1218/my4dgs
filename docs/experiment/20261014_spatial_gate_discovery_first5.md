# 稀疏完整运动发现 + 空间 gate：首 5 帧

运行：`fs_spatial_gate_discovery_first5_20261014/20261014T222347_0dca37`。每帧 100 motion + 100 birth step，无旧透明度修正。

核心改动：step1–89 对临时 GS 完整运动施加稀疏 proximal，避免早期共享统计拉动整片 GS；step90–100 对输出共享残差施加 proximal。每 10 step 更新联合量化众数，step20–90 学习 gate。用先量化完整运动、再减共享整数符号的方式处理舍入边界，保证 gate 切换保持姿态。

结果：动态 PSNR 34.166645 dB，motion+birth 均值 98.90 KB，新增 1120 GS。逐帧有效区域数为 [98, 105, 8, 141, 64]，末帧 65.14 KB、非零点残差 12016 个。初始八区域以外的实际层级首次被启用，并在第三帧回到八区域。

边界：
- 这些启用区域在最后 step100 的共享运动都是零，当前树还没有证明可带来明显运动共享收益。不能用区域数增长宣称方法有效。
- step100→200 的 heldout PSNR 在第二帧下降约 0.116 dB、第三帧提高约 0.061 dB；新增 GS 并不保证画质提高，需要更长前缀检查其行为。
- 旧 GS 运动数已等于非零点残差数，解决了此前非零共享量带动大批低梯度成员的现象。
- 第一帧存储明显较大，后续下降，五帧均值不能代表完整序列。
- 此短实验日志中的 `tree_edit_count=0` 是调度器覆盖 gate 返回计数导致的记录错误；空间归属和数据包实际改变。后续已修正统计分支，未改写历史输出。

验证：9 项空间 gate 数值检查通过，覆盖真实优化打开 gate、姿态保持、舍入边界、序列解码、birth 路径继承、checkpoint 恢复。下一步沿相同配置继续到 frame29，观察更大运动下的树和新增 GS，尚未达到完整 300 帧质量与存储目标。
