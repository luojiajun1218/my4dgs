# cut_roasted_beef：当前代码的 300 时间点 baseline

## 设置

共享首帧 frame 0 和动态帧 1–299；候选空间层级、区域共享运动与逐点残差，每动态帧 200 步，区域与逐点属性联合更新。沿用场景现有参数，本次没有改动训练代码。短实验为 30 个时间点（29 个动态帧），平均 PSNR 34.0541 dB、动态存储 54.03 KB/帧，未据此改参。完整配置 `config/n3dv_baseline_cut_roasted_beef_300frames_20261113.yaml`；结果 `output/experiments/n3dv_baseline_cut_roasted_beef_300frames_20261113/20261113T054324_13a4b1`。

## 结果

测试视角逐动态帧算术平均；KB=1000 B。动态存储包括完整动态帧包、不含共享首帧；分段值由日志中的逐帧小数计算。

| 动态帧 | PSNR / dB | 动态 KB/帧 |
|---|---:|---:|
| 1–299 | 33.6333 | 50.00 |
| 1–100 | 33.9701 | 52.87 |
| 101–200 | 33.7287 | 49.74 |
| 201–299 | 33.1967 | 47.37 |

总体 SSIM 0.9601、LPIPS 0.1296；165/299 帧超过 50 KB，最大 63.84 KB。共享首帧约 11.952 MB，动态总计约 14.95 MB，合计约 26.90 MB；平均训练 19.02 秒/动态帧。日志包含 1–299 共 299 个不同的帧并正常结束；本次未独立顺序回放，也未测已解码渲染 FPS 或包含读包和解码的完整播放 FPS。

全序列动态帧均值低于 34 dB，动态码率显示约 50.00 KB/帧，接近目标。历史同方案完整实验为 33.6373 dB、50.018 KB/帧，本次数值接近；`output/best/index.json` 的旧方案历史记录为 34.2344 dB、49.81 KB/帧，原结果目录已失效，且方案和首帧不同。末段均值低于前段，画面和运动随时间变化，单次结果不能证明累积漂移或归因于自适应层级。
