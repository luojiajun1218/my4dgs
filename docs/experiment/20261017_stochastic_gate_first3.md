# 随机离散gate与实际候选反馈：210–212帧

## 核心想法

硬STE会让关闭候选收到与自身预测无关的梯度；真实连续混合又可能通过候选幅度补偿小概率，最终硬化产生落差。本次训练时实际采样离散选择，让被选中的运动提案面对自己的真实图像误差；选择概率通过路径STE学习。

共享区域与个体完整运动提案保持互斥，叶子区域作为编码预测器，最后仍传绝对区域运动＋GS整数残差。区域父子表示未改为相对运动，也未按枚举比较来决定gate。

## 代码改动

新增默认不启用的 `spatial_gate.image_relaxation: stochastic_ste`，目前要求 `private_full_motion: true`。

- 用独立CPU随机生成器采样logistic噪声，从学习到的logit得到二元选择；温度从3退火到0.3。
- 同step的两个视角共用一次采样。前向选择一条实际路径；运动参数接收该路径的实际Jacobian，STE仅提供选择概率的梯度。
- 随机生成器、当前噪声和步数进入训练checkpoint，可精确恢复，并保持数据/新增GS的全局随机状态不受gate采样影响。
- 第70步仍按学习到的logit符号固定最终gate，后30步联合拟合区域与个体运动。评估及码流均使用确定的离散模型；采样状态不进入传输码流。

新增checkpoint语义标签 `joint_image_private_proposal_stochastic_v1` 和 `stochastic_binary_path_v1`，防止把此前不同训练方式静默恢复到新方式。

## 已完成结果

同一已完成第209帧checkpoint续跑210–212，storage权重0.002、残差L1权重0.5、T网格6e-5、运动每step2视角、70联合＋30固定gate＋100新增。全部旋转更新关闭，透明度量化、稀疏与阈值删除保持原设定；首个logit=-0.2，跨帧logit缩放0.1。与原基线不止一个设置不同，本实验用于筛选候选。

独立纯渲染约242.974FPS，训练约19.33秒/帧。KB=1000B，更新包含运动、透明度、新增GS及manifest；一次性参考帧另计。相对连续提案，PSNR提高约0.0155dB，字节减少约12.1%；相对匹配基线仍低约0.0597dB，字节减少约32.8%。

**没有推广至原生前缀或新完整300帧，特别重要的完整基线不变。** 结果表明候选能以更少更新拟合，但尚未证明同画质收益；三帧也不能代表完整序列。下一步应优先检查残差偏置、预算利用与原生起步的稳定性，不再把“梯度非零”当成gate已经有效的证据。
