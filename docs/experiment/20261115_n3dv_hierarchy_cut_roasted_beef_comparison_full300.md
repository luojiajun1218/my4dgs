- 相对 depth3，baseline PSNR +0.1904 dB，存储 -3.271 KB/帧；运动包差 -2.097 KB/帧，区域属性包差 -0.431 KB/帧。
- 相对 depth4，baseline PSNR +0.6577 dB，存储 -21.757 KB/帧；运动包差 -17.464 KB/帧，区域属性包差 -3.032 KB/帧。

动态大小统计实际帧包与 manifest，不含首帧；所列文件分量不含不透明度等其他文件。时间为各自记录的训练时间，跨日期可能受负载影响。分量差异描述实际字节，不能据此单独归因。

逐帧相机顺序、关键步骤非 gate 参数冻结、固定层归属、训练与解码的一个训练视角渲染、包字节和首帧起顺序回放摘要均已核验。共享首帧 SHA256 相同；配置除输出位置、时间点数和 checkpoint 保存帧外一致。原 baseline 早于工程重构且没有当时完整工作区源码快照，不能证明非 gate 实现逐行相同。
