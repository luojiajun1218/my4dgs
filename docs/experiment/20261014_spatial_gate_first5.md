# 空间 gate 首次短实验：共享运动误带动静止点

实验：`fs_spatial_gate_first5_20261014/20261014T215147_4c32d8`，动态帧 1–5，每帧 100 motion + 100 birth step，共享已完成首帧；未启用旧透明度修正。

核心 idea：参考空间八叉划分提供候选层级，learnable gate 选择是否细分。当前启用区域存独立的完整帧运动，GS 存相对区域的残差；区域旋转只改变 GS 朝向。开关通过区域加点残差的预期编码代价学习，关闭后保留点残差。

代码：新增 `spatial_gate.py` / `spatial_gated_motion.py`；接入 200-step 路径；SPG/SPC/SPL 数据包编码 gate 位图，从固定空间路径恢复归属，避免逐点发送细分产生的归属变化。

结果：动态均值 PSNR 33.956022 dB、SSIM 0.969467、LPIPS 0.117584；motion+birth 均值 246.57 KB，新增 3346 GS。step100 均值 33.948186 dB。所有帧有效区域均停留在第一层 8 区域。

机制分析：
- 首帧 206237 个 GS 中，132481 / 73387 个聚集在两大空间块；候选细分没有有效接管。
- 每帧所有旧 GS 的姿态都发生变化，首帧非零点残差 59211 个。粗区域的图像梯度直接驱动整体运动，使静止 GS 一起运动，再由大量点残差补偿。
- 候选子区域刚开始拟合，gate 就与它们同时竞争。父层已拟合、子层尚未拟合，首层 gate 概率很快下降；个别深层 gate 虽打开，但祖先关闭，仍不起作用。
- 此结果不能证明固定空间关系无效；它证明共享运动估计和 gate 候选训练的耦合存在问题。未启动长实验。

下一步：以图像拟合得到的 GS 完整运动作为临时训练变量，区域共享量学习解释这些运动；输出仍只存区域运动和点残差。候选先用量化统计初始化，随后学习 gate，避免粗区域强行带动静止点和未拟合候选被提前淘汰。
