# 末段降低学习率没有解决画质与码率的矛盾

区域平移的末步更新可能跨过多个量化格。本轮检验在后半段用余弦曲线把四组运动学习率降至初值的 0.1，是否能稳定训练终点。近端稀疏计算同步使用 Adam 参数组的实际学习率，出生阶段不变。

从与 L1 3072 区域诊断相同的 frame49 bootstrap 开始，只添加学习率比率配置。仍为 600 步运动、200 步共享预拟合和 200 步出生，L1 权重 0.006、存储权重 0.015。新 codec 已接入，因此存储对照使用原 L1 实验经新 codec 无损重编码的真实文件，见 `20261012_rigid_tree_lossless_codec.md`。

| 帧 | 原 L1 PSNR | 本轮 PSNR | 原 L1 新格式字节 | 本轮字节 | 本轮有局部残差的旧 GS |
|---|---:|---:|---:|---:|---:|
| 50 | 33.20445 | 33.14614 | 36,082 | 102,797 | 23,489 |
| 51 | 33.38559 | 33.42472 | 29,952 | 91,653 | 22,071 |
| 52 | 33.19198 | 33.30748 | 27,574 | 83,796 | 20,511 |

平均 PSNR 从 33.26067 到 33.29278，仅增加约 0.032 dB。平均增量从 31,202.67 到 92,748.67 字节，约为原来的 2.97 倍。出生数为 154、156、137，体积增加主要来自逐 GS 运动支持，而不是出生数量。

低学习率让近端二次度量更倾向保留已有残差，这是试验前已识别的风险，本轮结果与之相符。因此不将四组统一衰减的 0.1 配置用于完整序列。默认比率 1.0 保持原数值行为；旧 checkpoint 缺该字段时仅兼容为 1.0，不放宽其他配置检查。

运行前完成 302 项数值检查、55 项 unittest（CPU 阶段跳过 1 项 CUDA 检查）、12 项压缩检查。暂停完整基线后单独运行 CUDA 恢复检查，2 项通过。本轮未测 FPS，只是三帧诊断，不代表全 300 帧指标。
