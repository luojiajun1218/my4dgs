# 共享几何变换：第79帧局部验证

作者允许重新考虑“区域旋转只统计朝向、不改变GS中心”后，检查同一组区域平移和旋转能否共同解释位置与朝向。这是核心运动表示候选，暂未替换生产方法。

## 表示与必要配套

一个GS只使用gate选中的区域绝对变换，不累加父运动。区域数值原点由上一帧已解码位置及该候选区域成员的均值确定，不作为额外参数传输，也不假设它是真实物理关节。位置共享位移为 `Q(R(x-c)-(x-c)+t)`，然后加量化GS平移残差；朝向仍使用区域旋转向量加GS旋转残差的指数映射。只有区域R同时影响位置与朝向，没有增加第二组旋转。

初始化从自由拟合的点位置运动做Kabsch刚体拟合，退化组回退到原旋转统计值；随后保持原图像拟合、gate和点残差阶段。候选残差必须减去几何预测位移，不能再直接减区域常量T。原众数重编码也不能任意替换R：候选更新后重算真实变换残差，只有当前原始码量代理加相对L1下降才接受，并保持完整整数运动不变。

本地隔离实现位于 `/tmp/my4dgs_shared_transform_probe_backend_20261015.py`，执行器 `/tmp/my4dgs_audit_shared_transform_20261015.py`。没有修改生产模型、旧实验或旧checkpoint。

从worldroute原第79帧step20恢复至100，沿用相同的前一帧、原100步运动阶段、4视角/step、gate与GS归零/重启规则、rate/relative权重及prox窗口。无新增GS阶段。对照数据复用已完成的同策略重放，不另开系数/调度扫描。原重放本身与保存的step100并非逐位确定，测试PSNR差约-0.00068 dB。

候选包使用独立的私有STG1/STC1/STL1版本，引用摘要额外绑定共享变换语义，沿用已有稀疏int16块与压缩方式；独立CPU解码从包内符号重建。CPU和GPU完整位置/旋转运动符号逐项相等，最终位置最大差为0。此包不含新增GS、manifest与共享首帧，也不是已接入生产的完整序列存储/FPS结果。

## 判断与限制

方向弱正向，尚不足以认定解决长程退化，也不足以单独替换正式方法。尤其本实验沿用此前已经退化的第78帧状态，只验证一帧内拟合，不能检验误差是否跨帧累积。下一步仅安排从共享首帧出发的5帧连续短验证，失败或无明显收益时不直接扩大到长实验。

原有真实已学流的刚体位置拟合也仅降低约2.77% SSE，说明构造刚体例子的巨大残差节省不能直接外推到这个真实场景。原生ReCon-GS同样主要用平移场解释位置，不能把旋转语义说成落后原生的唯一根因。
