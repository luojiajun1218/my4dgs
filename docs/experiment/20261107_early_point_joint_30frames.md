# 稀疏 DC/尺度在 step101 提前训练：连续30帧配对

2026-11-07。两个场景各30个动态帧、单seed；Sear采用共同 frame200 解码前驱的201–230，Flame Salmon 从共同首帧的1–30。目标是在不增加每帧300个优化步的情况下，比较同一step100训练视角误差选点规则下，从step201或step101开始更新最多1000点的DC/logscale；不额外留出训练相机，每个优化步一个随机轮换视角。gate在151–180仍按原规则重新优化、step200绑定最终区域共享DC。早选点固定的是点行身份，不锁定运动区域；图像改变使各自的运动和gate轨迹可自然分叉。两组使用相同照片损失、率价、压缩格式和 per-step视角顺序，真实解码后递推；码率不是严格相等。

实验前实现了默认关闭的 `point_training_schedule=standard/select100/joint101`，并经100项旧/新CPU回归、额外6项选点摘要测试、两场景两模式各两帧GPU烟测及独立重放。step101–200不对未选点的运动或透明度掩码；仅对逐点DC/尺度掩码及Adam状态保护。选点额外渲染全部训练相机但不执行优化步；step101–200按原属性初始学习率，201–300两分支沿用原100步衰减；共同点码流FUA3、共享DC/运动/透明度格式不变。完整动态字节含所有包和manifest；精确率点及时间见每帧 JSON。

## 恢复、时间和核验

实验运行在用户级systemd服务中，每5帧保存finalized step300检查点；用户管理器的linger=no，退出最后登录会话或重启仍可能终止服务，非自动重启。先实际从帧201 step300恢复至帧202，前驱及视角序列一致，复原结果真实包独立重放通过；其202的逐位raw/运动state没有完全重合，训练cam06 PSNR差 -0.00326 dB、动态包字节差 -236 B，因此不是位级确定重现。禁止恢复step100–299未finalized checkpoint；最终恢复应从已完整写完的step300检查点在新目录验证前缀。

报告帧耗时包含该帧训练和评估，但不含末尾全前缀独立重放，也不完整包含每帧终点checkpoint的写盘；每组服务墙钟 sear_select100_recoverable30 0:09:02（含启动、训练、保存及独立重放）；sear_joint101_recoverable30 0:09:08（含启动、训练、保存及独立重放）；flame_select100_recoverable30 0:09:15（含启动、训练、保存及独立重放）；flame_joint101_recoverable30 0:09:19（含启动、训练、保存及独立重放）。所有四条结果均按首帧完整独立重放，逐帧 state/raw摘要、manifest/实际包字节、前向/解码训练相机最大像素差与300个每步相机记录核验；预选3帧另外渲染所有训练相机。输入、代码SHA、逐帧结果、独立重放日志、恢复烟测和服务日志保存在 `output/experiments/early_point_persistent_20261107/`；详细方法和预注册 `protocol.json`。
