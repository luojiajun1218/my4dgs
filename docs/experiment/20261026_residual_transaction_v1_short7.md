# 多视角残差出生与验证后提交：第一轮短序列

完成日期：2026-10-26。固定132586 GS首帧、1345×1008半分辨率监督，7帧（6个动态帧）。未达到300帧目标。

## 核心想法与实现

此前克隆/源点移交依赖旧点的空间支持，不能可靠补充真正出现的新表面。本轮改为从训练相机的RGB残差选位置，用同步多视角图像做由粗到细的深度搜索，独立初始化新点位置、颜色和足迹；另外保留少量旧点修复候选。候选训练600步，每步3视角，旧模型冻结。候选训练后，使用未参与拟合的4个训练相机检查完整解码画面和实际码流成本，只有改善画面且满足预算才提交。低透明度旧点也先验证删除的影响，遮挡但未观察到的旧点保留。

主要代码位于`pipeline/model/residual_birth.py`，`pipeline/module.py`接入候选训练、checkpoint与提交，`pipeline/trainer.py`分离候选拟合相机和验收相机。learnable gate不变；外部测试相机不参与选择。

## 原因分析与下一步

验收保护了已有覆盖，但大多数候选无法通过，拟合能力仍不足。第一帧有357个空间候选和128个修复候选，其中476个在至少两个拟合相机实际贡献过像素，说明不是完全没有观察到。进一步检查发现：200个空间候选在训练时临时替代了157个旧点；旧点最大尺度与新点的中位比值为3.093，29%的旧点足迹超过候选允许的4倍尺度范围。深度位置不同的新点被强迫填补旧点原有的覆盖，导致候选训练中产生空洞。不是简单延长训练就能解决。

下一轮机制修正：真正空间新点只做叠加，不承担删除旧遮挡面的任务；仅精确复制的修复候选临时替代自身源点；拒绝的候选群递归细分，避免坏点否决整组好点；删除检查覆盖全部训练相机。另补充拟合相机上的训练前后MSE，明确区分欠拟合与跨视角失效。深度搜索排除平坦单色和多深度歧义。这些修改需另行实测，不能视为已提高质量。
