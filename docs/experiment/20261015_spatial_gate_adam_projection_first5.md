# 既有Adam度量共享初始化前5帧：早期小幅下降，继续核查累积趋势

## 核心idea及改动

第179帧条件检查表明，40步共享投影采用既有Adam二阶矩的量化加权最小二乘代表量，比原中位数初始化提高约0.216 dB、训练图像损失降低1.027%，无出生纯运动包仅增加332 B。本轮从同一个原生共享首帧开始，检查早期实际序列，避免把单帧后段收益直接当作全序列改进。

规则只替换区域候选初始化：对有实际合成观测的GS，用自由拟合既有`sqrt(v_hat)+adam_eps`作每坐标权重，选择量化加权平均。该量是Adam度量代理，不是真实图像Hessian。原初始化中位数还包含同区域未观测成员，因此本规则也改变统计支持，不把收益唯一归因于权重。

原五层空间候选、learnable gate、区域绝对/GS相对运动、朝向旋转语义、量化、图像损失、rate/relative权重、视角、学习率、100步运动+100步新增以及80/100步原代表量刷新全部保留。没有增加系数、损失或透明度修正。原SPG1码流不变，无额外传输字段。

隔离入口`/tmp/my4dgs_run_adam_metric_region_20261015.py`安装`/tmp/my4dgs_adam_metric_region_backend_20261015.py`及`/tmp/my4dgs_adam_metric_region_init_20261015.py`。训练checkpoint使用`quantized_existing_adam_metric_projection_v1`标记，严格拒绝恢复不同初始化规则的训练状态；原生共享首帧仍可正常加载。生产默认方法未修改。
