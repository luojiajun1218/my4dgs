六场景等权均值：3DGStream 32.1539 dB、8059.83 KB/动态帧；baseline 32.6264 dB、41.51 KB/动态帧。

3DGStream 文件大小按作者代码直接保存的浮点 NTC.pth 和新增 PLY 实测；baseline 包含动态包和 manifest。复用同一首帧与数据有利于比较，但 3DGStream 使用作者默认两阶段参数与场景分位 AABB；该设置不是对论文原始初始化及测速环境的逐项复刻，不能把文件大小直接当作论文压缩码率。

完整播放为本机 Python 解码器顺序读取、更新和渲染的结果，含文件读入，使用预热的操作系统缓存；已解码渲染单列，不是官方 C++ viewer FPS。训练时间包括评估和保存，不含首帧训练。baseline 旧运行的完整源码不可得，比较须保留这一限制。
