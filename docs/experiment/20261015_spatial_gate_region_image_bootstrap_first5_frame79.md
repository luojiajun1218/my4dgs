# 区域直接拟合图像的初始化：短序列及第79帧验证未获得有效提升

## 核心想法及改动

生产方法前40步先让GS独立运动，再用量化运动的中位数初始化候选区域。此次检查能否直接通过共享区域拟合图像，减少独立点运动噪声，使后续gate有更可靠的候选。

仅在隔离实验后端实现，不修改生产模型：1–40步GS残差为零，依次训练空间树的五个深度，每层8步；切换深度时，子区域保留此前帧运动的细节，并继承本帧父区域已经学到的修正。40步保留图像拟合后的全部候选，41–60步沿用原gate训练，61–100步沿用GS零残差启动，101–200步沿用新增GS。最终位姿仍只使用选中区域的绝对运动加GS残差，没有父子路径累加；区域旋转仍只改变朝向。

原图像目标L1+SSIM、rate/relative系数、图像尺度调度、视角数量、量化、标准SPL1码流均保持原规则。候选初值沿用前帧实际运动的0.6倍平移和1倍旋转。检查点另存当前深度与初始化种子，拒绝混用旧初始化策略。

配置：`config/fs_spatial_gate_imagebootstrap_200_first5_20261015.yaml`，须用实验入口 `/tmp/my4dgs_run_region_image_bootstrap_20261015.py`，普通main.py不会安装此实验后端。首5帧输出中 `source_snapshot/experimental_bootstrap/` 冻结了后端、入口和9项检查源码；后续第79帧诊断没有修改这些冻结输入。

为检查此次改动是否有针对后段退化的收益，复用已有worldroute流，不重训此前帧，也不复用本帧已学20步的运动。读取旧step20检查点仅用于取回第78帧解码基准和旧GS属性；丢弃本帧提议与优化器。通过标准第78帧运动包恢复实际上一帧运动，包含新生点沿出生来源继承的运动，再从步骤1开始完整100次运动更新。原始rate_reference_count=206237保留，不能误用当前218265点作为分母。

## 检查、原因及决定

初始化、五层调度、父修正传递、非活跃参数与Adam屏蔽、40步保留候选、60步GS零启动、检查点恢复、标准码流及旋转语义共9项数值检查通过；新增上一帧运动包/出生来源恢复及完整重启与rate分母检查后共11项通过。它们是隔离原型的检查，不代表重新运行了生产完整测试套件。

直接训练共享区域没有自然解决后段退化。此次由粗到细调度也可能使细区域仅有8步直接拟合，限制了局部运动学习；这是待验证解释，不能认定为唯一原因。短序列和后段单帧均没有实际画质收益，故不合入生产，也不扩展长实验。长程退化及全300帧目标仍未解决。
