# 继承区域从帧开始学习共享运动：完整100帧

本轮让上一帧解码状态中已有的区域从第1步同时优化共享运动和GS残存；首次发现区域仍先独立拟合100步。step100保持位姿做区域维护，再联合优化100步，最后新增GS与旧点opacity优化100步。关闭点级因果平移预测，量化、学习率、损失和总预算保持原值。

实现集中于`rigid_residual_tree.py`、`module.py`、`trainer.py`。资格依据不可变的上一帧解码归属，首次及延迟首次发现不会回溯激活。新增真实post-Adam/prox、维护前的阶段记录，与维护后记录共存；固定heldout只用于诊断并恢复RNG。新增8项CPU检查、旧53项回归及opacity模块4项检查通过，覆盖双梯度、root零运动、99/100/150恢复、码流与RNG。子代理负责实现、独立检查和分段分析；主代理完成最终benchmark与记录。

## 机制分析与下一步

共享确实承担运动：frame49有52501个leaf GS的共享位移超过半个GS平移步，其中47989个独立平移为0。联合优化把独立非零支持14309降至6046；leaf内非零4791/52728=9.09%，root占全部非零1255/6046=20.76%。不能将leaf贡献大解释为大多数leaf点非零。

第30帧起64叶上限让一些局部候选在拟合前被阻止，root发现也直接跳过。逐帧root最多占2槽，subset每10帧最多新增2槽，存在先到先占的不对称；容量阻塞不证明候选有效。有界CPU诊断固定final49解码位姿，仅拟合4候选，2个有小幅统一量化L1收益22.65/131.10，且只能搭配当前零运动donor；最便宜非零donor退root代价321.45，均不足抵偿。部分候选L1下降同时非零块增加，因此未实施容量交换，也未证明实际字节或画质收益。

同run frame29到49，手/喷枪PNG ROI的MSE约翻倍，SSE份额9.51%到17.25%；人物ROI14.61%到21.66%，两ROI重叠不能相加。静态背景色偏从frame1已有，至49未增长。原checkpoint本来SH degree1，未降阶或截断，保留旧点SH逐bit不变。原首帧cam00 PSNR34.0047，当前共享首帧34.0113，未发现明显加载损失。PNG辅助统计不等于官方浮点评估，也不能作为GS归属或真实运动标签。

motion还包括出生位置、旋转和source，birth主要是appearance，不能将motion总大小全归为幸存GS残存；raw分块不能作压缩字节份额相加。
