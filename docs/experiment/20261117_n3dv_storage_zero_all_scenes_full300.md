关闭整个存储约束是组合消融，不分辨各分项的贡献；运动残差约束与量化仍生效。旧 baseline 完整工作区源码不可得，跨日期、代码版本及负载比较有局限。真实存储含完整动态包和 manifest，不含首帧。

测速口径及各场景结果见 `docs/experiment/20261117_n3dv_storage_zero_speed_full300.md`。

## 结果分析与论文使用边界

六场景等权均值中，有存储约束的 baseline 为 32.6264 dB、41.514 KB/帧；关闭后为 32.5201 dB、705.694 KB/帧。baseline 的动态存储约为关闭组的 5.9%，PSNR 高 0.1063 dB；但 baseline 的 SSIM 低 0.00039、LPIPS 高 0.00112，不能表述为所有画质指标都更好。关闭组在 coffee_martini 和 flame_salmon 的 PSNR 更高，另外四个场景更低；六个场景的实际存储都显著增加。

按实际动态包分解，逐点全属性包的六场景平均由 15.743 增至 604.619 KB/帧，是总存储差的主要组成；透明度包由 4.006 增至 40.123 KB/帧，区域属性包由 0.357 增至 18.821 KB/帧，运动包由 19.584 增至 40.309 KB/帧。这是编码字节差异的观察，不能单独认定某项损失造成了某一分量的全部变化。

该消融对整套存储约束的压缩价值提供了支持，但同时关闭了码率价格和属性 L1，不能区分各项贡献；旧 baseline 的完整历史工作区未保存，亦不能排除非存储相关代码差异。论文若要进一步加强机制论证，应在同一代码快照下补跑有存储损失的成对对照，并根据论文主张补充单项消融或多权重的率失真结果。每组当前仅一次运行，未衡量随机种子方差。
