# Kmeans：接纳有效划分后联合细化 100 步

## 核心想法和代码变化

上一轮完整包门控拒绝了所有候选，区域共享没有实际启用。本轮按用户要求默认接纳量化有效的非空划分，即使当前包变大；真实字节仍记录。四方法统一使用 **100 步自由 GS 运动 → 第 100 步分区一次 → 100 步共享区域+GS 残差联合细化 → 100 步出生拟合**。本记录仅分析已经完成的 Kmeans 运行，不建树、不用未来帧。

新增 `RigidTreeConfig.post_partition_steps=100`，`online_partition_policy=accept_valid`。自由阶段冻结共享参数，分区后安装有效 optimizer 参数，成员固定至细化结束；细化阶段的 relative motion loss 针对 GS 残差平移/extent 与旋转 rad 的 L1，不把所需共享运动往零惩罚，保留存储稀疏 proximal。第 200 步优化后记录最终码流/残差并开始 births，历史只在最终导出、解码后写入。阶段、真实梯度更新、成员固定、checkpoint 续训及最终解码记录均有数值回归检查。

- 配置：`config/fs_online_flat_kmeans_refine_first5_20261013.yaml`
- 完成目录：`output/fs_online_flat_kmeans_refine_first5_20261013/20261013T190219_cf861b`
- 命令：激活 ReConGS 后 `python main.py --config=config/fs_online_flat_kmeans_refine_first5_20261013.yaml`
- exit=0，wall 137.23 s；resolution=-1、共享 frame0、动态帧 1–4 各 300 步、种子 0。

## 残差分布和共享变换

下表是按各区域有观测存活 GS 数加权得到的全局**均值**；没有把各区域 p50/p90 合并成全局分位数。平移为世界坐标单位，旋转为组合后的最短角度 rad。

| 帧 | 平移均值：分区后→细化后 | 旋转均值 rad：分区后→细化后 |
|---|---:|---:|
| 1 | 0.00048729 → 0.00027234 | 0.00038253 → 0.00029782 |
| 2 | 0.00065491 → 0.00063339 | 0.00014885 → 0.00013851 |
| 3 | 0.00044590 → 0.00040673 | 0.00010365 → 0.00009603 |
| 4 | 0.00035037 → 0.00033214 | 0.00007329 → 0.00006652 |

例如帧1最大运动区域 id=1，7,062 GS，占存活 GS 3.42%。共享 affine 平移从 `[-0.002963,-0.002791,0.002866]`（范数 0.004978）变为 `[-0.004228,-0.009991,0.003779]`（范数 0.011489），旋转角从 0.00405° 到 0.02327°，最终轴约 `[-0.4924,0.1231,0.8616]`。平移残差 mean/p50/p90/max 从 `0.002157/0.002056/0.003565/0.008899` 到 `0.000861/4.41e-7/0.004209/0.016657`；旋转 rad 从 `0.001510/0.00007071/0.006929/0.013857` 到 `0.001015/2.05e-8/0.002449/0.025456`。共享平移是 `R*x+t` 的世界 affine offset，不是任意点的实际位移。

这说明许多点的残差归零，但 p90/max 并非全部减小：少数仍需改变的点承担更大的残差尾部，不能把“活跃行减少”写成“所有残差变小”。全区域逐项共享 xyz/norm、轴角/四元数和独立 mean/p50/p90/max 已保存于每帧 `flat_region_diagnostics.refinement.before/after.regions`。

## 与历史结果的区别及限制

相比旧 strict、100 motion+100 birth 的 Kmeans，动态平均 PSNR 从 34.29735 到 34.41381 dB（+0.11646），payload 从 83.69 到 85.84 kB（约 +2.15 kB/帧）。新的区域机制确实被启用，且细化期间码流和非零 GS 残差减少；但最终平均存储尚未优于旧独立 root 回退。

本轮同时改变了接纳策略、增加 100 步优化，并把细化 relative loss 转为 GS 残差项；不是单因素消融，不能把质量提升归因于聚类或某一个 loss。没有额外调参或质量保证，也没有全序列结论。完成后的速度测量如下，没有套用历史 root-only FPS。
