# DBSCAN 在线平面共享运动：初始参数前 5 帧

## Idea、代码和完成范围

尝试固定半径的 DBSCAN 聚类，与先前四方法统一 **100 步自由 GS → 分区一次 → 100 步共享+GS 残差联合细化 → 100 步 births**。accept_valid 接纳量化有效非空划分，历史最多 5 个过去/当前转移，无未来帧、无树、无中途改参。细化成员固定，GS 残差 L1 与存储 proximal 共同作用。

新增真实 DBSCAN 分支和 dbscan 参数；exact duplicate 合并保留正 sample_weight 以保持密度，KDtree 查询并限制邻居索引数量，不采样。**初始 eps=1.0（归一化运动特征距离）、min_samples=8、min_region_size=8**；translation_scale_extent=0.0004，位置历史维度从3→6→9→12。最大250百万邻居项护栏未触发，本轮最大索引约796 MB；不是经过调优的最佳参数。

- 配置：config/fs_online_flat_dbscan_refine_first5_20261013.yaml
- 完成 run：output/fs_online_flat_dbscan_refine_first5_20261013/20261013T215204_a72542
- 命令：激活 ReConGS 后 python main.py --config=config/fs_online_flat_dbscan_refine_first5_20261013.yaml
- exit=0，wall216.00 s；resolution=-1、种子0，共享frame0+动态帧1–4。实际DBSCAN proposal/gate/JSON/export回归通过，未追加参数扫描。
