# 保留粗核的守恒细节族：短3帧

完成日期：2026-10-26。frame0＋2动态帧训练完成，实际码流独立解码验证通过。本轮未扩到30帧，300帧目标尚未达成。

## 核心机制

出生与替换单位从自由漂移的子点改成三成员细节族：保留已训练粗核，在其切面内生成对称的两个细核。子核共享协方差，继承父核法向和角向外观；局部位移、协方差与透明度共同约束表面光学质量及低阶几何矩。该约束是薄表面代理，不等于每个相机的遮挡后像素颜色严格不变。

细轮600步固定粗细质量份额，给予子核训练机会；最终结构选定后再训练600步并解冻份额。颜色只学习成对正负contrast，以真实合成响应差计算兄弟交叉项，使用跨视角一致性、源颜色范围及实际量化MSE回溯。repair不自由学习共同DC。novel仍用独立MVS出生，并用时间变化/未覆盖证据区分真正新增内容。repair候选按跨视角空间残差contrast排序。

代码主要涉及`conservative_family.py`、`family_radiance.py`、`residual_birth.py`，以及module、量化、checkpoint和序列延伸的接入。最终仍编码成普通平坦GS，无推理期族状态或新码流格式。普通代码agent分工实现，未使用Command Code。

## 分析

第一帧coarse完整池训练收益+0.02764 dB，fine为+0.02585 dB，最终选择coarse。第二帧fine完整池训练收益+0.08186 dB，但新增前后测试PSNR从33.901058降到33.777634 dB，不能将训练拟合改善视作真实序列收益，也不能据此运行300帧。

细节族的几何代理按预期工作：第一轮128族量化后质量比均值1.000186、范围0.996815–1.004066，最大法向位移6.72e-7米，成对contrast符号完全抵消。第一帧颜色contrast跨视角一致性均值仅0.0615，校准训练MSE从2.335386e-4到2.334816e-4，收益约0.00106 dB。守恒并未让细分获得足够的图像修复能力。

当前族局限于单个父点范围，novel入口又抑制已覆盖静态残差，因而不能自然修复跨多个旧点的大块误差。后续方向应围绕有多视角表面证据的区域出生与旧覆盖退出机制，避免继续堆叠小克隆。

提案入口的误差分配也很窄：两帧在8个提案相机上，typed novel仅保留原始误差质量的17.54%/20.50%；进入区域分配的为1.89%/2.14%；成功匹配anchor分配到的仅0.288%/0.475%。对应区域像素分配量2903/4202（8视角合计）。这些是参考视角区域分配统计，不是去重后的世界表面积、原生可见响应或严格收益上限；但能说明novel入口没有覆盖大部分待修复误差，延长同一小池训练并不能扩展其支持域。

只读复核还发现fine种子切轴排序与模型局部坐标轴排序可能交换两个分量；本轮冻结源码未追溯修改。它不会解除薄面/范围约束，但可能改变种子方向，后续实现需要修正。

### 完成后的同人口原生审计

从最终码流精确重建六类属性，分别恢复未接管时的原旧点；coarse按最终root lineage及旧父ID匹配，不把父alpha重复赋给多个孩子。

| frame2场景，相对新增前 | 训练视角平均PSNR收益 | cam00收益 |
|---|---:|---:|
| 完整成熟coarse | +0.076753 | −0.130932 |
| 与最终root匹配的coarse | +0.076761 | −0.130997 |
| 最终repair family | +0.076557 | −0.131954 |
| 同107族退回各自成熟coarse anchor | +0.072587 | −0.136379 |
| 最终novel | +0.004328 | −0.001087 |
| 完整最终码流 | +0.081438 | −0.123425 |
| 完整族contrast清零，其他保持最终值 | +0.078674 | −0.120739 |

主要退化在600步粗修复阶段就已发生；细分相对成熟anchor反而略有改善，contrast额外损伤约0.00269 dB。成熟anchor相对原source中心位移中位0.0130米，旋转中位3.75°、p90为13.56°，logscale变化L2中位0.203；共同DC完全未变。这支持“自由几何正在替代颜色/覆盖解释误差”的假设，不能把细分约束本身或训练步数不足作为主因。

Adam核对排除了未训练：coarse位置、尺度、旋转、透明度均600步；最终107族切面offset全部改变；terminal保存点的offset与gate各200步。frame1选回coarse后未保留完整fine终态，因此不声称逐族复原了它的末步Adam。

实际可见响应也与区域分配分开核对：novel在cam00的alpha积分仅为屏幕0.0157%，响应≥1/255的支持为0.445%像素、对应2.62%原误差；repair family为7.84%像素、15.3%原误差。alpha积分不是硬面积。cam00父核没有投影轴方差低于原生0.3像素平方AA项，子核仅0.86%；含AA单profile质量比中位1.002、p90为1.037。AA不是此次主要退化来源。

cam00浮点图像的空间诊断进一步发现，新增SSE主要集中火焰/锅/喷灯附近。描述性矩形x=[530,870)、y=[420,1008)占14.75%像素，SSE增加48.95；其余三块矩形合计减少约1.57。该划分只是诊断，不是语义分割，更没有进入训练或提案。它提示不能将高误差火焰等缺乏稳定表面证据的内容直接当作可信表面repair。误差图`frame2_spatial_diagnosis.png`与数值`spatial_sse_audit.json`均在上述wire审计目录。

轴序bug随后由普通agent单独修正，34项相关CPU检查通过；旋转非等尺度anchor的六轴排列回归在旧实现上有3项失败。该修复没有计入本轮结果，也没有为它另做参数实验。
