# 区域/gate 联合学习 + 出生后固定树运动细化：首 5 帧

运行：`fs_spatial_gate_joint300_resume_first5_20261014/20261014T231610_d791c5`。首轮在 step200 的新增模型参数接口处报错，修正后从 frame1 step100 checkpoint 继续；未重训已完成的 motion 阶段。

核心方法：参考空间八叉候选；区域存完整运动，GS 存区域内残差；区域旋转仅改变 GS 朝向。众数只初始化候选，区域运动与 learnable gate 接受图像梯度；step60 硬化后重编码保持姿态。新增点沿源协方差采样并继承朝向。

300-step 调度：1–100 区域/残差/gate 训练；101–200 新生 GS；201–300 固定树与已量化的新生 GS，继续拟合区域和旧 GS 残差。期间不新增 GS、不改变 gate。支持 step200 的待完成 checkpoint 恢复，终帧只在 step300 写包。未启用旧透明度修正。
