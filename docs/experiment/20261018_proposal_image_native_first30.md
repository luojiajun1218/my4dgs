# 个体运动提案图像监督：共享首帧起步30帧核验

## 想法和结论

为避免个体完整运动提案因gate关闭而缺少训练，在gate固定前增加相同视角的提案图像监督。此前210–212帧短测为33.882102dB/31.331667KB。本次使用完全相同的66个冻结Python源文件，从原始共享第0帧开始训练1–29帧，随后独立顺序解码核验。

**相比没有辅助提案监督的候选，小幅提高画质；相比特别重要基线，画质仍低，未进入完整300帧。**

| 特别重要基线 | 34.276890 | 38.130724 | 213.137 |

| 增加个体提案图像监督 | 34.171395 | 21.346828 | 216.483 |

相对同配方无辅助监督，提高0.022999dB、增加1.571655KB；相对特别重要基线，降低0.105495dB、更新减少约44.02%。第0帧计入30帧画质均值，29个动态帧用于更新量均值；KB=1000B，一次性参考另计。FPS仅含已上传状态的渲染，不含解码与上传。

## 配方与代码

`proposal_image_weight=1`，辅助图像只训练个体完整运动提案，不向区域、gate、α、颜色回传梯度，也不增加用于新增GS的观测统计。gate仍从正式的采样离散图像与存储目标学习。固定gate后停止辅助监督，转为共享区域＋个体残差联合拟合；码流和解码器不增加辅助信息。

70步随机gate联合、30步固定gate稀疏优化、100步固定支持精修，之后100步新增GS；运动每step抽2视角，辅助渲染使用同两个视角。storage权重0.002、运动残差L1权重0.5，T量化6e-5×场景尺度，全部旋转更新关闭；区域共享DC从gate固定后开始，α直接量化、近端稀疏与α＜0.01删除保留。

树为4层robust_median，远点连接最近支持叶子。数据仍配置300帧、resolution=-1，实际1600×1199，通过原有软链接访问。实现改动与297项全量检查见[三帧记录](20261018_proposal_image_first3.md)；对应提交`4687510`。后续区域候选拟合原型不在本次冻结源码中，没有混入这轮训练。

选中区域均值144.31，非零GS平移残差均值2094.59，新增GS均值171.52；训练约35.39秒/动态帧。辅助监督确实让当前配方留住更多个体修正，但画质增幅不足。晚期短测优势仍不能直接推广为原生序列优势。

只读检查同一原始参考下的第1动态帧：基线step100已有34957个非零GS平移残差，对齐其退休映射后，只有6449个落在新候选step70冻结gate允许个体残差的区域；基线残差L2幅度之和中，该区域覆盖约29.18%，最强10%残差的点覆盖约54.76%。新候选原始206237点中允许个体残差的点为12464。这提示初始拟合的个体容量可能不足。

上述比较测量的是**GS残差而非完整共享运动**。基线残差不是运动真值，另一个共享场可能吸收其中一些修正；不能据此直接认定画质损失来自被排除的点。基线与候选的参考位置通过原始survivor行号精确对齐，未修改任何历史checkpoint。

另一个合成关闭路径梯度检查发现，中间层候选没有实际图像梯度，辅助个体图像也不依赖这些区域，但区域仍接收压向零的存储梯度。下一步短测默认关闭的新候选拟合项：让各层区域拟合已受图像监督的完整提案，并隔离gate及提案自身的梯度。它尚未获得真实数据效果验证，不能提前宣称解决问题。
