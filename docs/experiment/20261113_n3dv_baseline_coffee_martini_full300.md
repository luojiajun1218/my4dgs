# coffee_martini：当前代码的 300 时间点 baseline

## 设置

共享首帧 frame 0 加动态帧 1–299；候选空间层级、区域共享运动和逐点残差，每动态帧 200 步，区域与逐点属性联合更新。沿用 `config/best_coffee_martini.yaml` 的现有参数，本次没有改动训练代码。短实验为 30 个时间点（29 个动态帧），平均 PSNR 29.7269 dB、动态存储 65.77 KB/帧，数值与历史全属性方案前 30 个动态帧接近，未据此改参。完整配置 `config/n3dv_baseline_coffee_martini_300frames_20261113.yaml`；结果 `output/experiments/n3dv_baseline_coffee_martini_300frames_20261113/20261113T023346_1fb2f5`。

## 结果

测试视角逐动态帧算术平均；KB=1000 B。动态存储包括完整动态帧包，不含共享首帧。分段值由逐帧日志中保留的小数计算。

| 动态帧 | PSNR / dB | 动态 KB/帧 |
|---|---:|---:|
| 1–299 | 29.7681 | 54.95 |
| 1–100 | 29.7152 | 72.41 |
| 101–200 | 29.8031 | 49.22 |
| 201–299 | 29.7863 | 43.11 |

总体 SSIM 0.9235、LPIPS 0.1546；141/299 帧超过 50 KB，最大 106.69 KB。首帧参考约 13.027 MB、动态总计约 16.43 MB，首帧和动态合计约 29.46 MB；平均训练 19.34 秒/动态帧。日志包含 1–299 共 299 个不同的帧并正常结束。本次没有独立顺序回放，也未测已解码渲染 FPS 或包含读包和解码的完整播放 FPS。

本次 PSNR 和动态均值均未达到目标。与 `output/best/index.json` 的历史完整记录（29.8984 dB、48.39 KB/帧）相比，本次 PSNR 低约 0.13 dB，动态均值高约 6.56 KB/帧；两次运行的代码版本与递推过程不完全相同，历史结果曾恢复训练，不能把差异归因于单一改动或 gate。三个时段动态码率下降而 PSNR 略有变化，画面内容和运动也随时间变化，不能据此判断因果关系。
