# 新增 GS 后的运动细化使用独立学习率调度：前 5 帧

运行：`fs_spatial_gate_refinephase300_first5_20261015/20261015T030253_de2f67`。动态 frame1–5 完成，从共享原生 frame0 开始，未启用透明度修正。

核心 idea：固定完整运动学习 gate 已能启用空间细分，但最新 30 帧画质随运动累积下降。检查发现 201–300 步旧 GS 运动细化一直使用第一阶段耗尽后的最低学习率。因此先修正已有优化流程，不添加新的方法模块。

代码改动：`MotionBase._motion_lr_factor` 为新增 GS 后的运动细化阶段单独计算 cosine 衰减。step201 使用基础学习率，step300 降到基础值的 20%。首次 1–100 步调度保持原样。区域运动、GS 残差都按该调度更新；gate 和新增 GS 在此阶段固定。配置与上一轮前 5 帧相同，使用新的实验名。74 项检查通过，包括实际 optimizer 学习率以及 gate/区域归属冻结。

结果：动态平均 PSNR **34.395164 dB**，motion+birth 平均 **92.7878 KB/帧**，含必要帧索引平均 **93.2238 KB/帧**，均不含共享首帧 17,662,622 字节。新增 1016 GS。上一轮短前缀为 34.294695 dB、98.5348 KB/帧，此次画质提高约 0.100469 dB，增量存储下降约 5.747 KB/帧；尚不代表长序列达标。
