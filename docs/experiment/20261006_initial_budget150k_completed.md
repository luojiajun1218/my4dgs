# 首帧15万GS预算候选：完成记录

本轮将首帧的增密上限改为严格净增长预算。克隆和二分分裂候选一起按梯度排序，预算满后仍执行正常剪枝。训练保持15000步、SH=1、seed=0、原增密阈值和学习率；训练及评测尺寸1600×1199。

用户随后选择首帧只调整分辨率、其余参数沿用原设置。因此本候选只完成首帧训练，不继续接24帧，不作为最终速度方案。

## 结果

| 步数 | cam00 PSNR | SSIM | GS数 |
|---:|---:|---:|---:|
| 5000 | 33.2011 dB | 0.9712 | 149950 |
| 10000 | 33.9461 dB | 0.9715 | 149950 |
| 15000 | 34.450695 dB | 0.971893 | 149950 |

最终首帧PLY为15,595,432 B。15000步checkpoint通过独立恢复评测；预热10次、计时100次、重复5轮，独占3090Ti测得前向加clamp为218.29 FPS，预先准备相机与GS属性后的光栅化为222.22 FPS。该首帧FPS没有与同帧旧checkpoint做配对，因此不据此宣称相对速度收益。

历史首帧日志的cam00 PSNR为34.0047 dB。本轮较高，但有限密度、训练视角抽取和随机优化均可能影响结果，不能单独归因于预算筛选。
