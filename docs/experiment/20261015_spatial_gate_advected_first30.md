# 区域边界随动前30帧：迁移率下降，画质未提升

## 核心idea与代码范围

只调整空间分区：每帧解码后，将既有树的分割面按原成员GS实际位置增量的逐坐标中位数平移；空节点继承父增量。父子关系和五层候选不变，仍由learnable gate决定细分。区域采用绝对帧运动，GS采用区域残差；旋转只改变GS朝向。

损失、量化、学习率、视角和100步运动+100步新增均不变。没有启用CPU候选增长原型，没有加入透明度修正或额外机制。APG1标记新解码规则，分割面从已解码位置确定；新分组会影响整体压缩率，不能说只增加4字节。

隔离入口及后端：`/tmp/my4dgs_run_advected_spatial_20261015.py`、`/tmp/my4dgs_advected_spatial_backend_20261015.py`。生产默认规则未切换。普通main.py不会安装本实验解码后端。

## 实际完成范围与核验

运行：`output/fs_spatial_gate_advected_200_first30_20261015/20261015T191739_5ce380`。实际完成0–29共30帧，其中动态1–29共29帧。从已完成前5帧的frame4-step200继续，0–4的13个参考/运动/出生/manifest文件逐字节相同。训练与独立码流核验均正常结束，实际核验30/30。

冻结的79份基础输入、5份实验脚本与冻结副本及运行后输入哈希一致。训练期间没有改写运行源码。共享首帧18361949 B单列；数据仍通过已有软链接读取。

## 结果

与已有worldroute相同1–29范围比较，没有重训基线。

|动态1–29指标|原worldroute|边界随动|
|---|---:|---:|
|最终平均PSNR / dB|34.363429|34.341944|
|运动100步平均PSNR / dB|34.348025|34.333645|
|完整增量含manifest / B每帧|28485.276|28666.207|
|有效区域数均值|157.138|165.172|
|训练秒数每帧|36.8157|37.3329|

平均画质下降约0.02149 dB，完整增量增加约0.64%。分段最终PSNR差：1–4为−0.00709，5–9为+0.00785，10–19为−0.00593，20–29为−0.05747 dB。不能以最后第29帧单帧+0.01680 dB替代整个范围结果。

独立核验含首帧平均34.330923 dB，纯渲染201.617 FPS，动态201.656 FPS；不包含解码、上传及核验。原完整序列进程当时SIGSTOP并保留显存，检查器记录了停止上下文，因此速度只作临时观测，正式速度需GPU无其他保留上下文时复测。这不是全300帧结果。

## 新诊断：候选边界稳定不等于实际共享更有效

CPU从两种方法各自真实训练码流独立逐帧解码0–29，每个动态帧摘要全部匹配。对每个原有GS，比较运动前、运动后的位置在各自分割面中的路径。有效区域迁移率固定使用当前帧同一组gate，排除gate开关本身及本帧出生点的影响。

|动态帧平均|原worldroute|边界随动|
|---|---:|---:|
|候选最深叶子迁移率|1.57869%|0.25273%|
|当前有效区域迁移率|0.16905%|0.12690%|
|最大候选叶子人口|268.552|213.517|
|量化后非零GS残差比例|2.36101%|2.35716%|
|GS加权选中深度|1.48510|1.48556|

候选叶子的迁移明显减少，但实际选中区域的迁移本来就很少，非零残差和选中深度也基本不变。许多候选叶子边界并未被当前gate启用，因此不能把所有最深路径变化都当作实际共享运动被打断。这个诊断使下一步优先级转向共享切换、实际残差恢复及局部候选容量，而非只追求区域成员不变。

两种方法使用各自优化后的轨迹，运动和出生点已不完全相同；迁移率不是同一真实运动下的控制测量，不证明物理跟踪正确。低残差比例也可能伴随欠拟合，不能单独证明画质好。该CPU诊断没有读取测试图像或更新参数。

## 决定与后续范围

边界随动单项停在30帧，不作为画质改进接入默认方法，不沿用相同规则直接延长长序列。CUDA拟合非逐位确定，不能把小幅差异都归为某个局部规则的确定因果，但目前没有采用该规则的正面画质证据。

同时只读汇总原规则已经完成至187帧的阶段记录：160–179的运动100步平均31.81700 dB，新增阶段到200步为31.89746；180–187分别31.85347和31.89737。主要后段差距在运动阶段已存在，不能靠扩大出生阶段解释。进一步读后段保存的20/40/60/80/100状态，定位共享与残差恢复的衔接；这不等于已经证明某个gate规则有错。

调度器为本次短验证暂停原完整序列989.578秒，随后已自动恢复；它停止前最后完整帧187，该暂停会计入原frame188的wall time，应单列剔除，不当作计算退化。全300帧最终目标保持不变；旧规则因已出现约2 dB同帧差距，另安排在frame199完整checkpoint后停止并保留200帧前缀，不宣称它完成300帧。
