# 新增 GS 充分拟合：第一轮短序列未达标

日期：2026-10-25。实验已完成，结论：不进入长序列，下一步解决新增点离开源表面的问题。

## 核心想法与代码改动

保留 learnable gate 和 200 步运动阶段，把新增 GS 改为 600 步、每步 3 个训练视角。降低学习率并指数衰减，前 160 步允许增点，之后固定点集精修；新增阶段使用 RMSE+SSIM。候选上限 1400，初始扰动为源协方差的 0.7 倍。

`pipeline/module.py`：新增阶段学习率、多视角统计、固定点集精修；修正周期增点替换参数导致当步梯度丢失的问题，先优化再变更拓扑。`pipeline/trainer.py`：新增视角数与半径信息保留。`pipeline/model/rigid_residual_tree.py`：移除历史总训练步数≤300限制。`scripts/benchmark_rigid_residual_tree.py`：按配置验证并记录实际图像尺寸。

## 输入与结果

固定首帧 `output/n3dv/flame_steak_1020/frame0.pth`，原始 132586 GS；沿用透明度初筛，解码参考为 128963 GS。训练与评估图像均为 1345×1008，数据通过现有链接访问。序列为首帧+6个动态帧，测试相机 cam00 不参与梯度训练或候选点选择。

## 分析与下一步

候选存活率显著提高，但数量不等于效果：第1帧新增点仅增加0.0174 dB，第2帧反而下降0.0765 dB；当前新增点仍存在多视角过拟合。第1帧几何检查发现57.46%的新增点偏离源GS超过3个标准尺度，偏移最大轴的中位数4.15倍、90分位72.11倍。源GS通常很薄，世界坐标Adam的等尺度位置更新破坏了初始协方差约束，容易产生离表面的浮点。这是依据几何诊断提出的原因，尚需后续实验验证。

下一轮将对位置更新做源椭球坐标下的投影约束，降低初始透明度并加入弱透明度稀疏项，减少冗余候选。继续短序列验证。历史50帧原版均值33.870872 dB、33.293 KB；本轮不能直接把与历史均值的差异归因于单一机制（序列长度、随机初始化消耗及后续状态均可能不同），同帧birth off/on更能说明新增点的即时作用。
