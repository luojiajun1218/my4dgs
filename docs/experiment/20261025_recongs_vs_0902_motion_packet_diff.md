# 当前ReCon-GS出生与“最重要版本”的运动包差异

## 范围

历史提交：`0902bc1`，提交说明“最重要版本：34.3db 50kb 33.07s 228.45fps”。历史数据取该提交保存的`docs/experiment/evidence/manual_full300_20261018/`，当前取`output/n3dv/flame_steak_1025/recongs_birth/20261025T180552_c105b3`实际保存配置及码流。

下表统一比较动态frame1–250，KB=1000字节。历史全300帧PSNR为34.2597 dB，当前0–250帧为33.8943 dB，两者不是相同评价范围。历史图像1600×1199，当前1345×1008，首帧checkpoint也不同，因此不能把全部质量差异归因于某一项代码修改。

本次仅完成只读码流审计和历史代码对比，未训练，未修改模型或配置。

首帧保留点数下降37.5%，但需逐点传输残差的点数只下降7.7%。当前非零逐点残差比例约9.65%，历史按逐帧旧点数计算约6.47%；区域也更多。运动存储取决于非零残差和区域描述，不能直接按总点数缩放。

更大的变化是新增数量增长8.35倍，同时新增朝向从继承改为独立传输。完整更新增加39.327104 KB，其中motion增加22.724192 KB、新生其余属性增加18.873604 KB，其他包略有减少。

## 逐包重编码核实

对当前250个motion包逐一解压、解析、重编码，原包重编码全部字节一致。保留相同旧点运动、删除映射和门控，只改变指定新点字段，得到：

| 当前相同包内容的编码诊断 | 平均KB |
| --- | ---: |
| 实际完整motion | 64.052784 |
| 去掉新点段，并将头部出生数量设为0 | 29.824560 |
| 两者差值：新点几何的条件压缩增量 | 34.228224 |
| 保留新点位置，但改成继承源朝向的字段格式 | 46.168976 |
| 两者差值：独立四元数的条件压缩增量 | 17.883808 |
| 相同符号使用0902bc1编码器，恢复旧版完整门控位图 | 64.105232 |

所以当前64.05 KB不能全部称为旧点共享运动开销。新点几何的条件增量加上独立新生属性包，约为56.45 KB/帧，已经超过整帧50 KB目标。

注意：这是字节审计，不是关闭新增GS后的训练结果。29.82 KB仍包含删除映射等字段；直接去掉四元数会改变新点朝向，并非无损省17.88 KB。压缩增量依赖上下文，两种删字段诊断不能相加。相同符号的旧编码器只多52.448字节/帧，未显示压缩算法本身导致本次大幅膨胀。

## 实际生效的代码差异

| 环节 | 历史实际行为 | 当前实际行为 |
| --- | --- | --- |
| 运动阶段 / 幅度重拟合 | 200步 / 100步 | 180步 / 20步，重拟合包含在运动阶段内 |
| 新增梯度统计 | 运动末30步 | 全部180步，包含运动尚未拟合好的阶段 |
| 新点位置与朝向初始化 | 按源协方差旋转采样，继承源朝向 | 世界坐标轴采样，单位四元数 |
| 新点朝向 | 冻结，码流继承源朝向 | 优化，码流独立传四元数 |
| 新生优化器 | 重新初始化stage2优化器 | 继承基础优化器组设置和Adam step，新点动量清零，只重新调度xyz学习率 |
| 实际新生DC / alpha / scale学习率 | 0.075 / 0.75 / 0.075 | 0.0025 / 0.05 / 0.005 |
| 淘汰时序 | 运动结束按当前alpha<0.01自然剪枝 | 下一帧合并后全局删除上帧新增数量K个最低alpha点 |
| 新生最终剪枝 | 出生拟合末端剪枝 | 第40/80步split/prune，无额外末端出生剪枝 |
| 区域DC补偿 | 启用 | 关闭 |

当前优化器行为来自`initialize_recongs_sources()`继承基础组设置，随后`_configure_birth_phase()`的ReCon-GS分支仅调度xyz。已核对本轮frame29 step220 checkpoint，不能把YAML中的stage2非xyz学习率当作实际学习率。

两版均保留空间层级共享运动、旧点朝向不更新、相同运动量化步长与相对运动正则基本设置。当前区域数增加的成因尚未隔离，可能涉及参考点密度、运动拟合阶段和跨帧点替换，不能只凭区域数断言建树算法退化。

存储loss也不能直接按原始权重比较：历史0.002除以206237×24，当前0.00003除以50000，折算每字节系数分别为4.04066e-10和6e-10，当前反而为历史的1.485倍。现有运动rate项不能自动约束当前出生数量与全部属性开销。

## 改进优先级

1. 保留用户已选的共享运动＋官方新增/删除配平时序，首先处理新增几何与属性的高周转、高传输成本。不能直接恢复历史自然剪枝而忽略配平要求。
2. 优先核对“运动收敛后再找缺失点”的候选逻辑：全运动阶段梯度可能把尚未完成的运动误差当作新增需求。历史末段统计与更长重拟合值得作为流程依据，但本次没有证明单独恢复某项即可达标。
3. 朝向继承、协方差采样、实际新点优化器设置应作为一套新增流程审视。若保留自由朝向，其收益应覆盖实际传输成本；不能只为省字节删掉字段。
4. 编码器替换或继续加大运动惩罚优先级低。本次直接证据指向新增内容，而非压缩实现膨胀。正式实现后仍先短帧验证画质、完整字节与点生命周期，再跑长帧。
