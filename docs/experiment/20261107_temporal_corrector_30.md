Flame 原每帧选区的完整序列（`output/experiments/flame_salmon_shared_dc_step0025_full_20261107/runs/flame_step0025_full/20261107T063551_5f041b`）在同一 201–230 段为 30.184 dB / 46.275 KB；当前按需为 30.213 dB / 46.637 KB，约 +0.029 dB / +0.362 KB。旧结果连续从首帧训练，本次从其 frame200 检查点继续；基础源码与非续跑配置核对一致，但运行轨迹和外部训练开销不同，不能当作严格重复种子因果消融。

## 算法与协议

- 三组均保留原 1–200 步 gate、共享及逐点运动、透明度，以及 201–300 步区域共享 DC；不增点、不删除点。每步从全部训练相机中随机轮换一个视角做前向和反向。Sear 20、Flame 18 个训练相机；cam00 仅测试，不额外留训练相机。
- 无逐点纠偏组冻结尾段逐点 DC/log-scale；周期组在 210、220、230 帧按当前训练视角误差选最多 1000 点进行尾段纠偏；按需组按前一帧真实解码后、当前帧 step200 的同点同相机实际合成权重误差选择最多 1000 点。使用现有候选树对子区域做非重叠分配，不改变运动 gate 的 cut。
- 按需组对所选区域**联合**编码 DC/log-scale 的 FUA3，独立解码后按全部训练相机 MSE 和候选完整包相对基线的实际增量字节选择是否提交。不是逐区域分别测量边际字节。未提交分支不流入下一帧。显式视角集不包含 test，相同训练视角的随机数状态被恢复。
- MSE/byte 权重固定 1e-10；它是在 Sear 两帧烟测的训练 MSE 和实际增量字节基础上、正式对照前选定，在两个场景使用同一个值，不根据测试视角调整。其跨场景泛化和其他率点没有验证。两场景三组各 300 个优化步、每步一个训练视角；额外无梯度统计和分支评分不是优化步。
- 第 200 帧之后分支各自递推，后续不再具有相同前驱。Sear 周期组在首次更新前的 201–207 帧与基线已有约 +0.015 dB 平均差；Flame 在 201–209 约 −0.0026 dB。不能将其当作精确噪声分布，但提示两次训练轨迹不完全一致。

Sear / Flame 首帧参考分别 11,299,285 / 11,563,100 bytes，均不包括在上表。按需组平均 FUA 包 3,672 / 3,389 bytes 每帧；额外前向评估、统计与 encoder history 另计时间：按需组相比基线约 +0.737 / +0.709 秒/帧。encoder history 是编码端诊断和续跑状态，不传输；记录在各自 `encoder_diagnostics/temporal_history` 中。六组完整流及日志归档于 `output/experiments/temporal_corrector_20261107/`。

## 正确性与限制

CPU `tests.test_temporal_corrector_runtime`、`tests.test_temporal_corrector_policy`、`tests.test_color_v3_two_frame`、`tests.test_sparse_attr_v3` 共 13 项通过，覆盖接受和拒绝、非空纠偏包回退、身份及历史摘要、两帧状态、独立解码及 FUA 预算。真实 GPU 两帧 Sear 和 Flame 烟测及其完整前缀重放通过。六个 30 帧训练完成后均另行从 frame0 重放到 230，逐帧 manifest 摘要和视角数检查通过；完整源码哈希核对通过。当前 GPU 没有本次训练进程。

本结果不证明长期漂移解决、运动 gate 本身有效、真实等码率优于原每帧选择，或 N3DV/MeetRoom 整体达标。两个结果都没有达到 34 dB，但仅代表各自选定的后段 30 帧。原周期全属性历史实验与当前周期组的属性和增点策略不同；本次周期组是为公平对齐当前训练预算而重建的对照。实际新增实现通过 `scripts/run_temporal_corrector.py` 显式启用；普通 `main.py` 训练不调用该策略。

训练中的中断后实际从 checkpoint 恢复尚未做端到端实验；历史序列的张量化保存/加载和摘要校验经过 CPU 测试，但不能将其等同于完整断点续训验证。当前实验所有 30 帧均连续完成。
