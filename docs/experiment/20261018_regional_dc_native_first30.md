# 区域共享颜色：从共享首帧起步的30帧核验

## 想法和结论

复用learnable gate选出的运动区域，共享量化DC颜色增量，补充旧GS的外观变化。晚期210–212帧短测曾达到33.863360dB/27.783333KB；本次使用同一数值训练配方，从原始共享第0帧训练到第29帧，检验是否能推广。

**存储减少，但画质下降，未进入完整300帧。特别重要的基线及其Git标签保留。**

| 同范围0–29帧 | 平均PSNR/dB | 动态帧完整更新/KB | 纯渲染FPS |
| --- | ---: | ---: | ---: |
| 特别重要基线 | 34.276890 | 38.130724 | 213.137 |
| 随机gate＋固定后残差精修＋区域颜色 | 34.148397 | 19.775172 | 216.817 |

PSNR低0.128494dB，动态更新减少约48.14%。KB=1000B；第0帧计入画质均值，29个动态帧用于更新量均值。一次性共享参考另计，FPS不包含解码与上传。这是30帧结果，不能视为完整300帧成绩。

## 配方与代码

运动共200步：70步随机离散gate与运动联合训练、30步固定gate稀疏优化、100步固定支持精修，之后100步新增GS；运动每步2视角。gate固定时，把个体完整运动提案转换成共享区域＋GS残差，保留量化码流和实际位移，使共享叶子与残差继续接收图像梯度。storage权重0.002、残差L1权重0.5，平移网格6e-5×场景尺度；关闭区域、旧点和新增点的旋转更新。

区域颜色在gate固定后开始，三个量化DC增量通过既有owner共享，步长0.01、学习率0.0025、L1权重0.005。保留α量化、近端收缩及α＜0.01删除。4层robust_median树，远点连接最近支持叶子；数据配置仍为300帧、resolution=-1，实际图像1600×1199，数据通过原有软链接访问。

本次数值训练代码与已完成晚期三帧一致，增加已检查的前缀颜色文件复制修复。实现和290项全量检查、16项续训检查见[三帧记录](20261018_regional_dc_first3.md)。源码保存在各run独立快照中。
