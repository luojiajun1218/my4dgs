# greedy：共享区域与 GS 残差联合细化

## 想法与统一协议

用小种子刚体拟合、稀疏邻接合并形成平面共享运动区域，再真正联合优化共享变换与 GS 残差。四方法统一 **100 步自由 GS → 第 100 步分区一次 → 100 步联合细化 → 100 步 births**，accept_valid 接纳量化有效的非空候选，真实完整字节继续记录。不建树、不用未来帧，没有中途调参。

共同代码增加 post_partition_steps=100，自由阶段共享参数冻结为零，细化阶段成员固定；relative loss 针对 GS 残差平移/extent+旋转 rad，保留存储 proximal。第 200 步优化后才冻结运动并开始 births，最终导出解码后更新历史。greedy 使用 8192 点拟合预算、seed_size=32、8 个邻居、64 区域上限、0.0004×extent 拟合容差。

- 配置：config/fs_online_flat_greedy_refine_first5_20261013.yaml
- 完成 run：output/fs_online_flat_greedy_refine_first5_20261013/20261013T191235_979a4c
- 命令：激活 ReConGS 后 python main.py --config=config/fs_online_flat_greedy_refine_first5_20261013.yaml
- exit=0，wall 143.77 s；resolution=-1、种子 0、共享 frame0+动态帧 1–4，各动态帧 300 步。

## 残差与原因

各区域按有观测存活 GS 数加权均值如下；平移为世界单位，旋转为组合后的最短角度 rad，区域分位数没有误平均为全局分位数。

| 帧 | 平移均值：前→后 | 旋转均值 rad：前→后 |
|---|---:|---:|
| 1 | 0.00055533 → 0.00037882 | 0.00037928 → 0.00029711 |
| 2 | 0.00044655 → 0.00049416 | 0.00013145 → 0.00014318 |
| 3 | 0.00035974 → 0.00045364 | 0.00008648 → 0.00010249 |
| 4 | 0.00032007 → 0.00041291 | 0.00006499 → 0.00007691 |

帧2–4均值上升与支持/码流减少同时出现，少数点承担更大残差，不能宣称全部残差变小。帧1最大区域 id=1，4039 GS，占存活点 1.96%；共享 affine 平移从 [-0.002896,-0.003018,0.002955]（norm=0.005121）变为 [-0.007031,-0.006326,0.003145]（norm=0.009968），旋转角 0.00286°→0.01834°，最终轴 [0,0.6247,0.7809]。其平移 mean/p50/p90/max 为 0.001435/0.001419/0.002210/0.002854→0.000220/4.17e-7/7.94e-7/0.009805；旋转 rad 为 0.001190/0.0000500/0.006033/0.013274→0.000677/1.83e-8/6.76e-8/0.019849。完整逐区域共享变换和分布在 refinement.before/after.regions。

相比旧 strict、200 步 greedy，平均 PSNR +0.11556 dB、payload -3.23 kB；但接纳策略、额外 100 步、GS 残差目标同时改变，不是单因素消融。当前比 Kmeans 更少的共享成员降低部分归属成本，为这个序列提供线索，不能证明普遍更优。后续优先关注当前量化收益驱动的成员选择及空槽/归零共享区域的布局成本；此记录不自动修改算法或追加全 300 帧训练。

## 统一速度测量

训练全结束后顺序测量，RTX 3090 Ti、1600×1199 cam00、冻结属性缓存开启。每帧 10 预热+50 CUDA 同步完整渲染+clamp，动态帧 1–4 **201.600 FPS**，最低单帧 200.921 FPS；含 frame0 为 201.428 FPS，排除解码/上传。2 轮动态帧本地读取、CPU 校验解码、上传、渲染播放为 **4.015 FPS**，排除一次性 reference、相机/GT 加载和预检查，预读可能受 OS 缓存帮助，不能把约 202 FPS 称为播放速度。

含共同 frame0 的五帧平均 PSNR 为 **34.33108 dB**；动态平均仍为 34.41102 dB。报告位于 output/online_flat_refine_first5_benchmarks_20261013/greedy_sequence.json 和 greedy_frame4_playback.json，精确命令见 benchmark_commands.json，exit=0。仅覆盖这个短序列。
