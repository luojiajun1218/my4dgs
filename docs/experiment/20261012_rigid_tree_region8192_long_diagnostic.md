# 更细的共享区域与更充分的拟合

3072 区域的 L1 诊断在新格式下只用约 31.2 KB/帧，但画质不足。本轮尝试把共享刚体区域细化，同时增加拟合步数。方法仍是硬归属、父子刚体运动和逐 GS 量化残差，不添加 gate 或混合权重。

从原 stableparent frame49 已完成的相同 GS 属性和姿态出发，重新建立 8192 个有点的运动区域和静止根。每区 25–26 个 GS，父节点初始均为根，运动和 Adam 状态清零。运动步数从 600 增至 1200，共享预拟合从 200 增至 600，树编辑在第 720 步，出生仍为 200 步。存储权重从 0.015 提至 0.03，L1 相对运动权重仍为 0.006，学习率固定，每次最多评估 32 个换父节点候选。

这是容量、拟合时长和存储约束一起调整的候选，不能把结果单独归因于区域数。Bootstrap 的 GS 属性、姿态和 RNG 与来源一致，调整的布局、配置和已完成帧调度元数据都有记录。

平均 PSNR 为 33.53155，增量为 37,088.67 字节。与 3072 区域 L1 的 33.26067 / 31,202.67 字节相比，增加约 0.271 dB 和 5,886 字节。与 3072 区域 L2 的 33.34983 / 36,928.33 字节相比，约多 0.182 dB 和 160 字节。对照体积均采用同一新 codec 的实际无损重编码结果。

第 50 帧接受 21 次换父节点，未改 GS 归属；树编辑瞬间原始流增加 84 字节，最大位置和旋转误差分别约 8.96e-5 米、3.46e-5 弧度。后两帧更多区域归零，存储明显下降。更细区域可能更容易区分局部运动，但这种解释仍需完整序列验证。

首帧超过 50,000 字节，三帧均值也还没有达到画质目标。本轮未测 FPS，不代表全 300 帧达标。模型代码未改；沿用已通过完整测试的版本，并单独检查新配置恢复和初始姿态。
