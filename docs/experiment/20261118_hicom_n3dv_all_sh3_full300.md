## 结果分析

六场景动态帧均值为 30.9217 dB、SSIM 0.94197、LPIPS 0.14301；动态帧墙钟平均 9.03 秒（含评估与打包），其中打包约 0.29 秒。已解码纯渲染六场景等权均值为 237.85 FPS，包含读包和解压的 Python 播放为 44.78 FPS。`flame_salmon` 的纯渲染为 183.8 FPS，低于 200 FPS。

本次独立训练的 HiCoM 首帧质量本身存在场景差异：`flame_steak` 首帧 30.748 dB、动态帧平均 31.060 dB；`coffee_martini` 首帧 28.887 dB、动态帧平均 27.565 dB、末帧 26.120 dB；`flame_salmon` 首帧 29.919 dB、动态帧平均 28.551 dB、末帧 27.590 dB。后两个场景的序列后段出现画质下降，可能涉及时序误差累积、密度变化或训练参数，但本次并未开展能区分原因的诊断。

现有 baseline 的动态帧均值是 32.6264 dB、41.514 KB/帧，但其 SH1 首帧与本次 SH3 首帧不同；训练评估、编码和播放实现也有差异。此次 HiCoM 的 1795.67 KB/动态帧是额外实现的无损数据包大小，不是论文发布的码率，更不能据此断言 HiCoM 论文方法的压缩性能。应分别报告此复现的设置、可重放文件大小及论文原始数值。

[HiCoM 论文表 1 与表 6](https://arxiv.org/html/2411.07541) 报告 N3DV 六场景、含首帧 300 帧平均 PSNR 为 31.17 dB，本次对应口径为 30.9237 dB，低约 0.25 dB；其中 flame_steak 本次 300 帧平均约 31.06 dB，论文报告 32.87 dB。论文使用未经额外去畸变的原始数据、RTX 4090 和三次运行均值，本次使用本地去畸变后的数据、RTX 3090 Ti 和单次运行。差异不能直接归结为某一项，也不足以称为严格复现论文实验。
