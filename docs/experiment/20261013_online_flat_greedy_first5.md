# 在线平面共享运动：greedy 前 5 帧

## 想法与完成范围

用小运动种子及稀疏近邻图逐步合并刚体拟合相容的组，再按拟合变换向全部点分配成员，形成平面共享运动候选。历史只来自当前及至多 5 个过去转移，稳定 GS ID 对齐；不利用未来帧、不建树。frame1 开始每帧重新提案，候选与旧划分经过相同量化限制和完整压缩 motion 包比较，仅更省字节才采用。

核心实现同其余方法：`online_motion_clustering.py`、`online_flat_motion.py`、`online_motion_diagnostics.py`；此轮只修改配置 method=`greedy`，没有根据结果改算法。8192 最大拟合预算、seed_size=32、8 个近邻、最多 64 个抽样区域、拟合容差为 scene extent 的 0.0004；不同观测模式分别拟合，缺失历史不作为零运动。

- 配置：`config/fs_online_flat_greedy_first5_20261013.yaml`
- 完成目录：`output/fs_online_flat_greedy_first5_20261013/20261013T183412_05a5e0`
- 命令：`conda activate ReConGS` 后 `python main.py --config=config/fs_online_flat_greedy_first5_20261013.yaml`
- exit=0，进程 wall 74.25 s；共享 frame0 + 动态帧 1–4，后者各 100 motion + 100 birth 步，resolution=-1，种子 0。
- 初始保留 206,237 个 GS，共享 reference 16,656,569 B，只计一次。

## 独立残差与解释

实际区域 0 的残差仅统计有观测的存活 GS；平移为世界坐标单位，旋转为目标与共享预测组合后的最短角度 rad。

| 帧 | 平移 mean / p50 / p90 / max | 旋转 mean / p50 / p90 / max rad |
|---|---|---|
| 1 | 0.001213 / 0 / 0.005661 / 0.016871 | 0.000369 / 0 / 0 / 0.015033 |
| 2 | 0.000549 / 0 / 0 / 0.016871 | 0.000151 / 0 / 0 / 0.015033 |
| 3 | 0.000418 / 0 / 0 / 0.015033 | 0.000118 / 0 / 0 / 0.015033 |
| 4 | 0.000361 / 0 / 0 / 0.015033 | 0.000093 / 0 / 0 / 0.015033 |

greedy 通过历史上的刚体拟合容差合并区域，但其容差并不是当前量化码流收益。首帧 31,791 个成员的 raw 归属要 124,854 B，raw 残差仅减少 5,978 B；后续独立残差增多。历史上曾运动、当前已不需要改变的点仍可能被分到一个共享运动区域，需要抵消共享位姿，因此几何相容并不保证存储有益。

下一步更值得改进的是当前量化收益驱动的成员选择与部分区域接纳，保持实际 codec 门控；单纯把候选生成从 Kmeans 换成 greedy 没有解决收益不足。四帧均退回 root，不能依据不足 0.02 dB 的平均差异给算法排序。

## 统一速度测量补充

训练全部结束后独占 RTX 3090 Ti，以 1600×1199 cam00 渲染，开启冻结 GS 属性缓存。sequence 每帧预热 10 次、计时 50 次完整 forward+clamp，CUDA 前后同步；不含解码、上传和质量评估。缓存与不缓存图像相同，解码重放 PSNR 与保存值逐帧一致。

- 动态帧 1–4 纯渲染 **201.762 FPS**，最低单帧 200.534 FPS；含首帧的 0–4 聚合 201.674 FPS。
- frame4 物化渲染，30 次 × 3 轮：201.053 FPS。
- 从共享参考依次播放动态帧 1–4，共 2 轮，包括本地文件读取、CPU 校验解码、上传和渲染：**4.329 FPS**。平均读取/解码 222.92 ms/帧，上传+渲染 8.10 ms，解码占计时约 96.50%；不含一次性 reference、相机/GT 加载、manifest 预检查和质量评估，预读文件可能受 OS 缓存帮助。
- 共同 frame0 PSNR=34.011318 dB，含首帧的 0–4 平均为 **34.23863 dB**；仅动态帧平均仍为 34.29546 dB。

报告：`output/online_flat_first5_benchmarks_20261013/greedy_sequence.json`、`greedy_frame4_playback.json`，精确命令见 `benchmark_commands.json`，全部 exit=0。纯渲染刚超过 200 FPS 的结果仅适用于这个短序列，端到端播放远低于 200 FPS，不能混用。
