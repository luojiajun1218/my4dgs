# 先学习共享场，再开放GS残差：原生前三动态帧

## 想法与代码

此前细层共享预测在训练和留出视角都优于粗层，但GS早期已围绕粗层拟合了零散运动，随后重编码成本仍奖励粗层。本次让共享结构先承担真实主图像拟合，GS残差在gate固定后再参与运动优化，避免自由点场抢先吸收全部变化。

提交`7c462fb`新增默认关闭的`shared_discovery`，仅用于已有物理共享/STE模式：

- 前70步的主图像使用采样共享场，GS运动学习率为0，真实图像梯度仍积累二阶统计。第一动态帧初始细分全关，后续继承弱化的前帧logit；前20步logit不更新，21–70步学习开关。
- 发现阶段所有切分下GS残差均为0，因此gate优化共享图像及实际区域成本；切换不为保持旧粗预测而生成GS补偿残差。
- 第70步固定gate，保留GS梯度方差、重启其一阶方向并恢复学习率；所有GS均可使用必要残差。接30步稀疏联合拟合、100步固定支持精修，再100步新增。
- 共享阶段主图像已是共享预测，辅助权重设为0，避免重复渲染。运动仍每步2视角；相对区域、全部旋转关闭、α量化和阈值删除保持原配方。

新增检查覆盖发现阶段位置不更新但统计积累、冻结后释放所有GS、发现阶段gate改变共享场且不制造点残差、完整解码。12项针对性检查通过，**340项完整检查通过，47.988秒**。默认配置和特别重要基线未改动。
