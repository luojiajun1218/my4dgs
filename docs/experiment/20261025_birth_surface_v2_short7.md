# 新增 GS 表面约束：短序列减少浮点，但拟合收益仍不足

日期：2026-10-25。实验已完成；不进入长序列，继续改进候选点选择。

## 想法与代码

第一轮中，大量新增点沿源 GS 很薄的法线方向离开表面。保留 gate 和 200 步运动优化，在 `pipeline/module.py` 对每次新增点位置更新施加源旋转/尺度坐标下的逐轴投影约束，最大偏移为每轴 2 个源尺度。这里是源椭球主轴坐标中的盒约束，并非球形距离约束。

候选上限从 1400 降至 600，初始透明度从 sigmoid(0.1)≈0.525 改为实际 alpha=0.1，初始化扰动为源尺度的0.3倍；位置学习率0.00008、透明度学习率0.03，新增阶段维持600步×3个训练视角、学习率衰减至0.1倍，前160步允许增点。新增弱透明度稀疏项，权重0.01，按旧GS数归一化。默认关闭新机制时兼容旧配置。

## 原因分析与下一步

表面约束确实生效：第1帧偏离源点超过3个主轴尺度的比例由第一轮57.46%降至0.84%。剩余越界可能来自世界坐标量化网格和浮点误差；很薄的源尺度小于量化步长，不能期待导出后严格满足原始连续约束。

但是新增点在测试视角的即时收益仍几乎为零，仅延长训练和限制离面不足以解决拟合问题。

进一步用第1帧4个训练相机（cam01/07/14/20）计算固定场景颜色DC的梯度探针：原有1400个位置梯度候选仅覆盖0.342%的总颜色梯度范数；颜色梯度最大的600个源点全被“小GS才可克隆”条件排除，其中84.5%还会触发新增点的大世界尺度剔除。这是训练信号诊断，不能等同于对应比例的图像误差，但揭示了候选机制的覆盖盲区。

下一轮加入少量按跨训练视角一致颜色梯度选择的新增点，保留原位置梯度候选与总数量预算；对外观候选保留源点覆盖范围，测试相机不提供优化或候选选择信号。需继续核验画质、真实码流与FPS。
