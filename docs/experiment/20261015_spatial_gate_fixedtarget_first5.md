# 固定完整 GS 运动后学习 gate：前 5 帧

运行：`fs_spatial_gate_fixedtarget300_first5_20261015/20261015T014956_90085c`，动态 frame1–5 已完成。未启用透明度修正。

核心机制：以前在切换区域后对相对 GS 残差做稀疏投影，会改变已经拟合的完整运动；下一步 gate 又用被改变的运动评估候选，形成偏向粗区域的闭环。现在将运动拟合和表示选择分开。

步骤：1–20 自由 GS 运动；21–60 用空间候选的软估计继续拟合运动，gate 参数暂时固定；60 从完整运动的量化离散量重估各区域的完整运动众数；61–90 固定完整 GS 运动和候选统计量，仅训练 gate，选择时重编码相对 GS 残差，保持位姿不变；91–100 固定硬区域并拟合运动；101–200 新增 GS；201–300 固定树与量化新 GS，细化旧 GS 运动。

代码改动：新增 gate 编码阶段的运动保持约束；该阶段禁止 GS/区域的 Adam 更新及 sparse proximal 改写目标。候选区域由完整运动重估，解决候选只拟合软混合补偿项的问题。重编码保留 GS Adam 历史，因为相对坐标的原点改变不改变 GS 位姿的图像导数。仍只传区域绝对运动、硬开关以及 GS 相对残差，完整 GS 运动仅是临时计算量。73 项检查通过，包括编码阶段的位姿保持。

结果：动态平均 PSNR 34.294695 dB，motion+birth 增量平均 98.535 KB；新增 1088 GS。有效区域数 [2468, 2965, 2986, 2986, 2893]。各帧增量分别为 [190.018, 100.972, 76.535, 63.629, 61.52] KB。首次验证到 gate 在实际序列中启用了细分，画质恢复并达到短前缀 34.2 dB；尚不代表完整 300 帧达标。

分析：区域选择终于没有改写自己的运动目标，候选也确实代表完整运动。初期编码较大，后续帧明显下降；细层数量较多，需要继续看长前缀是否稳定、相对残差和区域参数分别占多少存储。下一步验证 30 帧，沿用已完成前缀，不重写旧包。

码流验证与速度：6 / 6 帧含共享 frame0 均完整解码并通过原始状态及图像验证；全前缀 PSNR 34.247466 dB，动态帧 34.294695 dB。纯渲染聚合 202.009 FPS，动态 202.084 FPS；完整增量含必要帧索引均值 98.971 KB。FPS 范围仅为物化后的渲染，不含逐帧文件解码验证或上传。详见运行目录的 `benchmark_sequence.json`。
