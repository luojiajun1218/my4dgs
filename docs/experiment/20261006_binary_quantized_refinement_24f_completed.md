# 二叉空间树、量化残差与停止/细化门：24 帧完成记录

这轮先把“粗层够用就停止，局部不足才进入子层”的链路跑通。采用简单空间二叉树，子层只补父层之外的运动，训练时直接使用量化值。

**结果：深度选择已经生效，平均 93.33% 的旧 GS 停在粗层。但本版没有获得存储收益。** 相比历史稀疏三层配置，PSNR 低 0.09457 dB，必要文件增至 5.03 倍。主要成本是显式保存的 GS 归属，运动整数本身只占较小部分。

## 本轮做法与代码

- [配置](../../config/fs_binary_quantized_refine_24f_20261006.yaml)：共享首帧，动态帧 1–24，seed=0，resolution=-1，实际 1600×1199。数据集原生划分为 cam01–20 训练、cam00 测试。
- [binary_refinement.py](../../pipeline/ReCon-GS/model/binary_refinement.py)：粗区约 96 个 GS；沿最长轴按中位数二分，原始行号打破坐标并列；子区至少 12 个 GS，最多三层。每帧从删除后的上一帧基底重建。
- 内部节点只有一个停止/细化门。关闭后，整个后代路径关闭，成员继承当前父预测。父运动量化为零时仍允许细化，例如两个子区反向移动。
- 当前运动参数为三维平移和三维旋转向量，围绕父运动带动后的区域中心组合。共享区域承担全部旧 GS 运动，终端区域继续共享变换。
- [module.py](../../pipeline/ReCon-GS/module.py)、[trainer.py](../../pipeline/ReCon-GS/trainer.py)：接入新模式，复用补点与删除路径，新增粗层结束评测、实际深度、存储和计时报告。
- [数值测试](../../tests/test_nested_prototype.py)：覆盖二叉归属、停止后继承、零父运动继续细化、关闭门的 STE 梯度、联合优化恢复、导出成本与解码。另修正了已有 flat 配置测试的过期文件名。

每帧 300 步：

| 步数 | 操作 |
|---|---|
| 1–50 | 只拟合粗层共享运动 |
| 51–100 | 开放子层残差，继续拟合运动 |
| 101–180 | STE 硬前向，联合学习运动和停止/细化门 |
| 181–200 | 固定门，只精修保留的运动 |
| 201–300 | 冻结旧 GS，拟合补点，最多保留 200 个 |

平移量化步长为 extent×1e-4，旋转为 1e-3 rad。storage 权重 0.001，预热 100 步、渐增 20 步。门初始概率 0.5，阈值 0.5，温度 1，学习率 0.05；门 Adam eps 单独为 1e-15。运动学习率和补点参数沿用此前配置。所有数值在 YAML 中。

借鉴 [QuARC-GS](https://arxiv.org/html/2608.18285v1) 的前向量化与零桶思路；[HEIR](https://arxiv.org/html/2510.26786v1) 提供了父运动继承与局部残差的参考。这里的候选树由空间包含关系确定，存储使用普通 NPZ 整数数组，关闭路径和零运动记录可省去。

## 深度选择与成本

全体旧 GS 的平均终止深度为：粗层 **93.33%**，中层 **3.26%**，细层 **3.40%**。这描述模型选中的路径深度，与该路径是否有非零运动分开统计。

精确保持上一帧的旧 GS 平均为 **10.00%**；约 **90.05%** 的粗节点仍有非零量化运动。因此，“停在粗层”大多表示使用粗层运动，不表示静止。历史参照中 m 关闭比例约 96.03%，当前的静止复用行为明显较弱。

| 参数组成，动态帧均值 | 字节 |
|---|---:|
| 参与运动 GS 的行号、终止层号和节点归属 | 1,741,423.5 B |
| 运动整数值 | 63,563.0 B |
| 运动记录编号与旋转中心 | 42,375.3 B |
| 其余树结构、细化门与必要元信息 | 26,802.8 B |
| 新增属性与删除编号 | 1,887.3 B |

GS 归属占硬参数成本 **92.82%**。每个参与行保存 4 B GS 编号、1 B 终止层号、4 B 节点编号。多数粗区运动非零，这个 9 B/GS 成本覆盖了多数旧 GS。

训练探针中，50 步粗层结束至 100 步候选拟合结束，PSNR 平均提高约 0.10013 dB。这包含额外优化和粗层继续更新，不能解释成子层的独立反事实收益。

## 原因与下一步

本轮证明了量化、父子继承、可学习停止/细化、保存和恢复可以接在一起。它没有证明便宜的细化收益估计器，也没有证明比此前配置更好的率失真表现。旧 z 全开仍可能包含初值、学习率、eps 和调度的影响，本轮同时改变这些因素，无法单独归因。

画质下降可能与终端共享区域的表达能力、较粗量化、关子路径后的精修预算，以及门和共享运动如何重新分配有关。当前结果无法区分这些原因。

下一步优先检查确定性归属重建：从上一帧基底重建相同二叉树，减少逐 GS 归属传输，并同步修改真实存储成本。QuARC-GS 的 [zero-cost binding](https://arxiv.org/html/2608.18285v1#S3.SS3) 也采用确定性重建归属的原则。这里只有建议，还没有实现或验证节省后的字节数。

随后应检查粗节点非零比例为何接近 90%，再决定静止选择和量化校准。细化门已经能停止，但让无需变化的区域保持原位、让细化收益对应到实际成本，仍是需要继续解决的问题。

## 核验与复现

- 训练前完整测试：146 项数值检查、32 项其他测试通过。
- 零运动测试覆盖非单位原始四元数。底层四元数乘法会归一化输入，零路径必须精确返回原始姿态，同时保留 STE 梯度。
- 24 个 NPZ 的数组参数字节与硬成本一致；必要文件大小逐一核对。
- 从共享首帧开始，逐帧应用删除编号、解码运动、追加补点。24 帧完整原始状态的 SHA256 与训练记录一致；第 5、10、24 帧 checkpoint 中旧点和补点的六类原始属性逐元素完全一致。
- 启动快照位于 `output/fs_binary_quantized_refine_24f_20261006_exact_keep/source_snapshot/`。训练期间核验的 30 个源码和配置文件变化数为 0。训练完成后，分析脚本补了旧汇总缺少尺寸字段时的图片核验回退。
