# GMM：有效划分后共享与 GS 残差联合细化

## 核心想法、代码与运行

采用统一 **100 步自由 GS → 分区一次 → 100 步区域共享+GS 残差联合细化 → 100 步 births** 协议。`online_partition_policy=accept_valid` 接纳量化有效的非空候选，即使即时整包增大，真实字节继续记录；不建树，不使用未来帧。GMM 提议区域及概率过滤，其余训练、量化与细化设置同本轮 Kmeans/HDBSCAN/greedy。

`post_partition_steps=100` 使 motion 总阶段为 200 步；自由阶段共享参数保持零，细化时成员固定，relative loss 针对 GS 残差平移/extent+旋转 rad，而不是惩罚共享变换。存储 proximal 继续作用；第 200 步后冻结运动并开始 births，最终导出解码后再记因果历史。核心代码位于 `rigid_residual_tree.py`、`online_flat_motion.py` 和 `online_motion_diagnostics.py`，本次运行没有针对 GMM 另调 loss 或预算。

- 配置：`config/fs_online_flat_gmm_refine_first5_20261013.yaml`
- 完成 run：`output/fs_online_flat_gmm_refine_first5_20261013/20261013T190504_bff46c`
- 命令：激活 ReConGS 后 `python main.py --config=config/fs_online_flat_gmm_refine_first5_20261013.yaml`
- exit=0，wall 139.42 s；resolution=-1、种子 0、共享 frame0+动态帧 1–4。

## 残差分布与解释

按各区域有观测存活 GS 数加权的均值如下；平移单位为世界坐标，旋转为组合后的最短角度 rad。区域分位数不能平均成全局分位数。

| 帧 | 平移均值：前→后 | 旋转均值 rad：前→后 |
|---|---:|---:|
| 1 | 0.00049192 → 0.00028237 | 0.00038174 → 0.00029837 |
| 2 | 0.00056674 → 0.00066036 | 0.00013535 → 0.00014395 |
| 3 | 0.00031070 → 0.00033057 | 0.00010009 → 0.00009603 |
| 4 | 0.00026951 → 0.00029344 | 0.00007088 → 0.00006400 |

非零行减少并不保证残差均值下降：帧2平移和旋转均值上升，帧3/4平移均值也上升，说明更多点归零同时少数点承担更大尾部。

例如帧1最大运动区域 id=1，6998 GS，占存活点 3.39%。共享 affine 平移从 `[-0.002961,-0.002827,0.002897]`（norm=0.005015）变为 `[-0.003619,-0.009405,0.003389]`（norm=0.010632）；旋转角从 0.00405° 到 0.02182°，最终轴约 `[-0.3939,0,0.9191]`。平移 mean/p50/p90/max 从 `0.002138/0.002048/0.003482/0.008862` 到 `0.000812/6.58e-7/0.003929/0.016658`；旋转 rad 从 `0.001514/0.00007071/0.006929/0.013857` 到 `0.001011/1.91e-8/1.12e-7/0.025456`。共享平移遵循 `R*x+t`，完整逐区域共享变换与独立 mean/p50/p90/max 保存在每帧 `refinement.before/after.regions`。

相比本轮 Kmeans，GMM 平均最终 payload 大 8.84 kB、平均 PSNR 低约 0.01985 dB；两者协议相同，但只有早期四帧、没有重复试验，不能推广为普遍算法排序。帧2 GMM 独立活跃行还少于 Kmeans，整包却更大，说明码流收益不能只看 GS 活跃行，归属/layout 及符号压缩结构也重要。

相比旧 GMM strict、200 步协议，当前平均 PSNR 增加约 0.10571 dB，payload 从 83.44 增至 94.67 kB。当前同时改了接纳策略、增加优化步数、改 GS 残差目标，不是单因素消融，质量差不能单独归因于共享聚类。未启动全 300 帧；完成后的速度如下，不沿用旧 root-only FPS。

## 统一速度测量

全部训练结束后顺序在 RTX 3090 Ti、1600×1199 cam00、冻结属性缓存开启的条件下测量。每帧 10 预热+50 CUDA 同步完整渲染+clamp，动态帧 1–4 **201.386 FPS**，最低单帧 200.655 FPS；含 frame0 为 201.257 FPS，排除解码/上传。2 轮依次读取、校验 CPU 解码、上传、渲染动态帧 1–4 的播放为 **2.880 FPS**，排除一次性 reference、相机/GT 加载和预检查，文件缓存可能影响，不能称为 201 FPS 的播放。

含共同 frame0 的五帧平均 PSNR 为 **34.31743 dB**；动态平均仍为 34.39395 dB。报告位于 output/online_flat_refine_first5_benchmarks_20261013/gmm_sequence.json 和 gmm_frame4_playback.json，精确命令见 benchmark_commands.json，exit=0。测量只覆盖短序列。
