# 持久局部运动区域：100帧完成，后段质量仍退化

## 核心idea与改动

让大区域中的少数持续高残存GS有机会形成自己的共享运动区域，避免被多数静止GS稀释。基于稳定GS ID与逻辑leaf ID，使用已完成step200的残存证据：平移/旋转各自GS量化单位下的L2最大值>4，连续3次有效观测才进入候选。当前step100只复查，不提前累积当前帧证据。每10帧维护，最多接受2个局部subset。

维护顺序为world-zero回收→原有merge→局部subset→原有整leaf split→root discovery→tree。新subset严格要求共享符号折算为GS步长后，加受影响GS整数残存的L1下降，并验证解码pose；不硬性拒绝初始化包增大。对应改动集中于`pipeline/ReCon-GS/model/sustained_residual_subset.py`及持久区域维护接入，配有局部运动数学/集成测试。

保留100步自由GS→100步共享/GS联合→100步birth+稀疏旧opacity。量化、预算及旧opacity机制未在本轮叠改；没有启用causal translation初值。源码与配置冻结至训练、两项独立benchmark结束。

## 机制证据与可能原因

局部subset共19次尝试、18次接受，累计3561次GS归属分配（跨维护可能重复，非去重GS数）；每次维护均接受2项，80帧有一项因统一整数成本不降被拒绝。说明新路径确实运行，但这些准入指标并不保证后续图像质量或压缩包改善。80帧新logical99/100分别104/92GS，准入L1改善495.15/380.30，初始包却增加440/256 B；joint后仍有88/85个GS非零独立残存。logical99旋转残存支持104→31，说明部分初始化补偿会被joint消去，区域化尚未让大多数局部残存归零。

world-zero回收全程0次。最终证据中可出现长期全零leaf（例如90帧logical85 streak20），但当前自由100步refit微小非零共享运动仍会阻断零运动回收判据；较细的区域量化步长与回收时刻之间存在不匹配。叶容量长期达到64，容量主要依赖legacy merge腾出。90帧6merge→2subset→2split后剩2slot，root discovery又接受230/136GS两组并用满。该瓶颈值得后续处理，但本轮不据此混改下一实验。

40帧首次建立非root内部节点，50起保持2个内部节点、最大depth2，最终逻辑ID82/88。80/90树候选主要被当前位置或历史位置拟合拒绝（80为309/42，90为301/57），不能仅凭“建树开启”宣称已有充分共享层级。统计中的`region_id`可能是slot，应以`logical_region_id`识别实际区域。

更直接的质量证据是自由运动阶段自身随时间下降。下一步优先只改运动初值：尝试由已完成过去帧生成因果平移预测，检查能否改善自由阶段跟踪，然后再看最终质量/完整字节；当前结果只支持这个待验证假设，不能证明zero-start就是唯一原因。维持严格online，不使用未来帧或heldout指标做训练选择。

“有效观测”仍是renderer visibility/radii代理，不等同遮挡后真实像素贡献。共享translation范数是affine offset，不能直接当物理位移。没有重跑旧方法对照，也没有用短段结果替代全300验收。
