# α 空间量化与关闭旋转：后期三帧验证

## 结论与比较口径

本记录只覆盖 **270–272 三帧**，全部从相同旧第 269 帧检查点恢复，数据配置仍为 300 帧、1600×1199、2 个训练视角。不能用这些均值代替完整 300 帧，也不能直接与后 30 帧的 87.874 KB 均值比较。

关闭旋转相比直接 α＋0.05 收缩版：PSNR 低 0.019093 dB，完整更新少 3.52%，训练时间 26.773→23.302 秒/帧。纯渲染 204.780→203.922 FPS，未观察到明显渲染提速。它相比原 logit 基线提高 0.218562 dB、完整更新少 25.32%，但这些收益主要来自 α 方案，不能全部归因于关闭旋转。

## 核心想法与实现

旧实现量化 logit：同一格更新在 α≈0.99 时影响很小，在 α≈0.5 时影响更大。现在可选 `opacity_update.mode: alpha`，直接使用 `clip(α_prev + round(δα/step)·step, 0, 1)`；step=0.01，学习率=0.01。STE 将图像梯度直接传给 α 增量，避免 sigmoid 饱和抑制旧点降 α。

只去掉 Adam 中的稀疏梯度会让更多小更新保留下来，表中第一种尝试因此失败。最终短测组合对 α 增量加入 `0.05·mean(|δα|)`，Adam 只保留图像梯度；之后按图像二阶矩做连续软阈值收缩，周期性做稀疏块归零。`decay_with_motion: true` 复用运动阶段后半程的学习率衰减。原 storage 权重仍为 0.003，GS 近端、70＋30 步 gate 调度与 100 步新增阶段保持原配方。

源码改动简表：

- `pipeline/model/sparse_updates.py`：α/logit 可选量化、α 的 STE、可选连续收缩和学习率倍率；旧配置默认仍为 logit、不增加连续项。
- `pipeline/model/legacy_opacity_codec.py`：新 OPD4 格式用 float64 sigmoid 后一次舍入，定义与张量长度、删点顺序无关的 α。旧 OPD1/2/3 解码保持原定义。
- `pipeline/module.py`、`pipeline/model/gaussian.py`：训练中直接渲染量化 α，运动结束后按解码器规范物化 logits；α＜0.01 仍删除。
- `RigidTreeConfig.rotation_updates`：默认 true；实验 false 时清空并冻结区域及 GS 的旋转增量，热启动和恢复也执行同一策略。**保留旧点原始朝向，新增点仍正常拟合初始姿态**，没有把椭球强行改成无朝向的球。

初版直接 α 短测在导出时被精确校验拦住：torch CPU sigmoid 的向量尾部对少量值有 1 ULP 差异，删点后的子集计算会改变结果。OPD4 修复该问题，新增删点子集、排列和 SIMD 长度回归；失败初版没有结果进入上表。

## 解释与限制

强度 0.05 的 α 收缩去除了大量弱更新，能保留直接 α 量化的一部分画质收益。关闭旋转的单独存储收益较小，运动包中的平移仍是下一处主要开销。短窗口尚不能确定长期累计误差、旧点持续删除后的覆盖能力，也未达到 34.2 dB /约50 KB 的完整目标；保留原默认配置，继续验证新配方。
