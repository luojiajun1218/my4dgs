# 同一层级联合学习运动与区域颜色：210–212帧短测

## 核心想法

此前区域共享颜色直到gate固定后才训练。gate选择运动表示时，图像中仍包含未解释的外观误差，可能影响区域划分和个体运动。本次让同一套采样离散路径同时渲染运动与区域DC颜色，使gate接收两者的真实图像反馈。

新增`feature_dc_update.gate_joint`，默认关闭，仅支持区域共享及随机离散图像gate。颜色复用运动当前step缓存的采样噪声，不另外抽样；每个视角的图保持独立，两个视角仍使用同一离散路径。推理、固定gate后的训练和解码都采用确定的owner。

颜色成本用选中节点的非零通道数估计，沿区域选择概率给gate梯度；颜色参数本身继续使用图像Adam和标量近端。每个标量约3字节及头部只是原始字节代理，不能当作真实压缩长度。最后一律按实际码流统计。

## 实现和核验

提交`1d1d9a7`：运动模型抽出缓存路径权重；颜色模块增加联合前向、选择条件成本和未使用节点清理；Module传入训练模式。固定后清除未选中颜色参数、梯度和矩，仍复用原有`SDR1`和motion owner，不额外传GS归属。

9项新检查覆盖同路径与无额外RNG、纯颜色图像误差的gate梯度、字节项gate梯度及颜色Adam隔离、零位保留、冻结清理、恢复后下一次更新、退休与出生回放、Module辅助提案的外观detach及旧配置兼容。306项完整检查通过，耗时45.757秒。

三帧独立顺序解码通过，PSNR差与缓存逐像素差均为0；首尾终态checkpoint原始属性一致，来源和67个冻结Python文件哈希通过。

帧210的step70 checkpoint已有394个非零颜色通道，涉及199个区域；原候选同一阶段仍为0。这验证了真实训练中的颜色更新已进入gate选择阶段，不是仅在固定后补外观。该检查本身不是PSNR因果归因。
