# 4DGC：sear_steak 的 300 帧码率实验

按作者公开代码训练独立 SH1 首帧 10000 步、运动阶段 400 步和增量高斯阶段 100 步，运动与外观码率权重为 1e-5，量化参数 q=1。输入使用半分辨率去畸变 N3DV 图像和 cam00 测试视角。将浮点权重入口修为 float，修复解码路径的存在性检查错误，补充实际熵码流解码、测量和指标记录。

| 指标 | 结果 |
|---|---:|
| 训练评估动态帧 PSNR / SSIM / LPIPS | 34.0669 / 0.96631 / 0.11427 |
| 真实连续解码动态帧 PSNR / SSIM / LPIPS | 30.8106 / 0.94613 / 0.15147 |
| 含首帧 300 帧解码 PSNR / SSIM / LPIPS | 30.8146 / 0.94619 / 0.15139 |
| 真实动态码流 | 822.61 KB/动态帧 |
| 首帧码流 | 14047.84 KB |
| 动态帧训练墙钟时间 | 49.31 秒/帧 |
| 已解码渲染 / 完整播放 | 145.59 / 1.33 FPS |
| 解码画面与训练输出 PNG 的平均 / 最大 MAE | 0.01520 / 0.01722 |

动态大小计入 MEM 网络、熵码和频率表，以及新增高斯几何、特征和频率表；不计训练产生的完整中间 PLY。首帧单列。完整播放为单机 Python 读取、解码、更新和渲染，操作系统缓存未清空，不含相机图像读取与显示。作者训练代码用未完全解码的上一帧作为参考，解码器用真实已解码参考连续重放，二者画质应分别报告。不同首帧、数据处理和测速实现限制与 baseline、论文的直接比较。数据、配置及日志见 `/mnt/SSD500GB/n3dv/4dgc/experiments/n3dv_q1_l1e5_20261119/sear_steak`。
