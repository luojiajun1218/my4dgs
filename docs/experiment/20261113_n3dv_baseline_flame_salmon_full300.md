# flame_salmon：当前代码的 300 时间点 baseline

## 设置

共享首帧 frame 0 和动态帧 1–299；候选空间层级、区域共享运动与逐点残差，每动态帧 200 步，区域与逐点属性联合更新。沿用场景现有参数，本次没有改动训练代码。短实验为 30 个时间点（29 个动态帧），平均 PSNR 30.3849 dB、动态存储 44.19 KB/帧，未据此改参。完整配置 `config/n3dv_baseline_flame_salmon_300frames_20261113.yaml`；结果 `output/experiments/n3dv_baseline_flame_salmon_300frames_20261113/20261113T071831_4af4a0`。

## 结果

测试视角逐动态帧算术平均；KB=1000 B。动态存储包括完整动态帧包、不含共享首帧；分段值由日志中的逐帧小数计算。

| 动态帧 | PSNR / dB | 动态 KB/帧 |
|---|---:|---:|
| 1–299 | 30.4316 | 37.17 |
| 1–100 | 30.4511 | 39.12 |
| 101–200 | 30.4047 | 35.62 |
| 201–299 | 30.4390 | 36.78 |

总体 SSIM 0.9287、LPIPS 0.1374；3/299 帧超过 50 KB，最大 65.65 KB。共享首帧约 11.764 MB，动态总计约 11.11 MB，合计约 22.88 MB；平均训练 18.99 秒/动态帧。日志包含 1–299 共 299 个不同的帧并正常结束；本次未独立顺序回放，也未测已解码渲染 FPS 或包含读包和解码的完整播放 FPS。

全序列动态帧 PSNR 低于 34 dB，动态码率低于 50 KB。`output/best/index.json` 的旧方案历史记录为 30.2782 dB、49.87 KB/帧，原结果目录已失效；本次高约 0.1534 dB 且每帧少约 12.70 KB，但两次方案和代码版本不同，不能将差异归因于单个机制。该对照也不足以证明本方案超过 SOTA。

本次沿用短实验配置中的 checkpoint 保存帧列表，因此没有保存 frame 299 的训练 checkpoint；完整 1–299 动态帧码流及首帧参考均已保存。
