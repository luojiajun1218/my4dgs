# 固定gate后允许各级GS例外：210–212帧短测

## 想法与实现

原候选只允许最深叶子中的GS保留个体运动，可能限制必要修正。本次保持gate学习阶段，在固定gate后允许所有选中区域中的GS学习残差，并继续使用量化、L1近端和块稀疏约束。

新增默认关闭的`fixed_gate_all_gs_residuals`，要求先使用完整提案并在gate固定时转换为残差坐标。原先未渲染的粗区域个体提案仍先清零，再开放它们的梯度，避免转换瞬间凭空引入运动。既有解码器本身支持粗区域的GS残差，无需新码流或归属表。

实现为`bc73ee0`；7项新检查覆盖冻结转换的位姿与包精确保持、粗区域图像梯度、平移与旋转例外回放、阶段恢复、跨帧和出生继承、旧配置兼容。304项完整检查通过（46.999秒）。

## 分析与核验边界

新增约1.69万个非零GS平移块，没有带来相应的PSNR收益。当前图像目标和优化参数下，简单放开例外容易保留大量零散更新；扩大个体容量不能直接解决质量与码率矛盾。

对匹配帧210的step70做只读跨run检查：gate位、owner、参考位置相同，私有采样器状态与采样噪声也相同，但区域/GS参数、最终位姿和运动包并非逐位相同，最大坐标差约0.003117。该差异来源未定位，不能把单次三帧0.0143dB当作稳定收益，也不将它表述为严格张量复现实验。上述跨run比较与同一状态的冻结转换保持检查是不同范围；后者已由针对性检查验证。

三帧正式码流独立顺序解码全部通过，PSNR差、缓存逐像素差均为0，首尾终态checkpoint原始属性一致，来源与冻结源码哈希通过。实际负载包括运动、α、DC、新增及manifest。
