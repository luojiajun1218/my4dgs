剪枝移除 8,759 个低透明度点。保留点的 xyz、旋转、scale、opacity 和两部分 SH 与共享参考六字段逐值完全相同。剪枝模型与参考模型在全部 21 个视角的渲染像素也完全相同。原始模型的重测结果复现原生训练日志：训练平均 36.7474，测试 34.0047。

训练视角平均比 cam00 高约 2.74 dB，但原模型也没有均匀拟合好全部训练角度。训练 cam09 的 PSNR 为 31.88568，其他训练视角约为 35.26–39.12。因此不能把首帧误差全部归为未见视角问题，也不能仅凭平均值判断原训练已充分收敛。

## 初始化与数据核对

第 0 帧加载共享的原生 `ckpt-0-15000.pth`，没有重新训练。当前树的初始归属与父节点仅作为后续运动的元数据；第 0 帧直接渲染基础 GS，没有运动残差量化、旋转合成或 SH 阶数切换。

原生和当前配置都使用 SH1、黑背景和 `resolution: -1`。原图和 COLMAP 标注均为 2689×2016，自动缩为 1600×1199。cam00 的主点为图像中心，姿态、焦距及图像路径与原实验一致；没有找到加载错帧、相机结构错配的证据。

原首帧训练设置为 15,000 步，密化到第 5,000 步结束，SH 阶数为 1。这些是可能限制拟合能力的设置，尚不能由本次只读对照确定哪项是主要原因。误差图能看到细节与反光区域的拟合误差，没有整体图像错位；视觉观察只作辅助。
