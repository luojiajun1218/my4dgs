# 历史50帧结果：静态残差与出生点生命周期诊断

完成日期：2026-10-26。只读分析已完成的历史结果，不更新模型、不改历史文件、不用测试图选择候选。取frame1、10、29、49，分辨率1345×1008。

## 问题

如果剩余误差主要来自刚出现的内容，新增点应补动态缺失覆盖；如果很多误差从首帧延续，就需要能长期保留的修复，并按实际生命周期衡量一次出生成本。此前逐帧固定小候选池不一定适合后一种情况。

## 证据

以GTt相对GT0的逐像素RGB均方根变化不超过阈值定义“图像稳定”。下表每格为稳定像素占比 / 该区域承载的baseline SSE占比。

| 阈值 | frame1 | frame10 | frame29 | frame49 |
|---|---:|---:|---:|---:|
| 0.01 | 86.9% / 81.8% | 76.5% / 70.8% | 74.2% / 64.8% | 66.1% / 58.2% |
| 0.02 | 98.9% / 95.6% | 95.4% / 92.0% | 94.1% / 86.3% | 89.2% / 81.3% |
| 0.04 | 99.7% / 97.0% | 98.1% / 96.0% | 97.4% / 90.9% | 93.7% / 86.8% |

阈值0.01下，四帧共同稳定区域占47.3%像素，却承载各帧40.2%–44.9%的SSE；残差的时间恒定分量占该区域残差能量93.9%。frame1与frame49的有符号RGB残差Pearson相关性0.890。

从历史码流共享reference0只读解码128963个GS，用冻结v4渲染路径重渲染。初始残差与frame49共同稳定区域的余弦相似度0.886（阈值0.01），说明大量误差延续自首帧，而不是新内容带来的全部误差。

## 对新增机制的含义与局限

这为“长期保留修复、摊销一次出生成本”提供依据，尚不能证明应新增几何还是更新已有点属性。固定首帧13万GS保持不变；任何后续修复都应写入真实动态码流计费，不能当作共享首帧免费内容。也不能直接放宽逐帧预算而不核验300帧真实平均存储。

下一步先完成全部20训练相机及最终结构一致拟合的机制验证；如果候选已有正收益但容量不足，再考虑按长期残差分配持续存活的出生容量。不能将本次测试图的稳定mask用于训练或选择点。

这些只是cam00上4个时刻的图像诊断，不能直接外推300帧。PNG为8位，阈值受量化影响；曝光/光照变化会排除物理静态区域，同色运动物体也可能通过稳定mask。图像误差的恒定分量不等于可由3D GS实现的改进上限。
