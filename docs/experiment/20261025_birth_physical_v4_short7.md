# 限制新增外观候选的源尺度：存储达标，画质仍不足

日期：2026-10-25。本轮7帧实验已完成并重新解码核验。

## 想法与改动

第三轮复制了超大源椭球，产生跨视角重影。本轮增加`birth.appearance_source_max_scale_extent`：外观候选的源点最大轴尺度不超过场景extent的0.05倍（约0.325世界单位）。只过滤外观候选，原位置候选不变。实现位于`pipeline/module.py`；候选预算与码流格式不变。

外观候选额度160，总候选上限600；恢复新增点大尺度异常剔除，最大屏幕半径64；透明度稀疏权重0.05、剔除阈值0.02。继续200步运动+600步新增阶段，每个新增训练步3个视角，RMSE+SSIM、源尺度约束、联合旧点透明度拟合。没有改变learnable gate机制或旧点颜色。

输入仍为132586 GS首帧checkpoint，初筛后128963 GS解码参考；1345×1008半分辨率监督，数据保持链接访问。

## 分析

约束源尺度并加强弱点剔除后，大范围重影受到抑制，存储降到50KB以内、渲染超过200FPS，但新增点本身的平均即时拟合收益仍接近零，画质目标尚未达到。

检查第1帧中间checkpoint，同样不渲染新增点的诊断PSNR依次为：运动结束33.5747、总第400步34.0485、结束34.0042 dB。当前旧点透明度在新增阶段仍以固定的运动末期学习率更新，而新增参数已衰减，存在末期拟合振荡或过拟合风险；该单帧检查提示调度需要改进，尚不构成充分因果证明。

另一个限制是极薄源GS的逐轴位置约束可能小于旧运动量化误差，挡住新增点应有的精细位移。下一轮按运动量化步长保留最小几何余量，联合透明度同样逐步衰减；利用当前存储余量放宽稀疏压力，并允许新增点调整方向，继续短序列验证。
