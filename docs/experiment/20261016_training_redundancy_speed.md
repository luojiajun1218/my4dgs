# 训练冗余清理：同条件单动态帧耗时降低 13.1%

本轮只检查实现冗余，不改变训练方法、损失目标或步骤划分。已完成 GPU 单帧性能核验，没有完成新配方的正式质量评估或全序列训练。

## 核心想法与代码改动

当前前 100 步每步使用 4 个训练视角，与相机无关的运动正则原来重复构建 4 次；前 40 步正则权重为零仍会计算候选项；gate 冻结后仍遍历所有候选层级，其中每个 GS 只有一个层级实际生效。

- `pipeline/module.py`、`pipeline/trainer.py`：每个 optimizer step 只构建一次运动正则，通过最后一个视角的等效权重保持四视角平均目标不变。训练指标与观测计数合并传回 CPU，减少 CUDA 同步。
- `pipeline/model/spatial_gated_motion.py`：自由运动阶段直接返回零正则；共享场阶段不构建没有参与目标的点残差图；gate 冻结后只计算实际 owner 对应的残差项。
- 冻结分支仍保留 `point_t + shared_t.detach() - region_t[owner]` 的梯度结构，不能仅按数值相等简化成点残差而丢失区域梯度。
- 未加入 SSIM 目标缓存，未修改量化、码流、学习率、视角顺序、100 步运动加 100 步新增的调度。

## 测量条件

RTX 3090 Ti，350 W 功率上限；同一原生共享首帧、同一第 1 动态帧、随机种子 0。配置沿用 `config/fs_spatial_gate_depth4_200_full300_20261016.yaml` 的四层树、storage 权重 0.002 和默认 median 初始化。

每次总计 200 步：100 步运动各使用 4 个视角，100 步新增各使用 1 个视角，共 500 个视角。为隔离训练计算，关闭测试评估、阶段截图和中途 checkpoint 写入；最终运动导出仍执行。CUDA 上下文在计时前初始化。

第一次复测与独立 CPU 码流解码存在竞争，未用作最终比较。暂停该解码任务后，使用无竞争的新实现测量及补跑的原实现测量形成最终成对结果。原实现通过测量脚本加载清理前的三个模块快照，工作区源码没有临时回退。

## 已完成结果

| 阶段 | 原实现 / 秒 | 优化后 / 秒 |
|---|---:|---:|
| 1–40，自由运动 | 9.3170 | 8.5589 |
| 41–60，共享场与 gate | 5.4927 | 5.0838 |
| 61–100，区域与 GS 残差 | 13.9532 | 10.6551 |
| 101–200，新增 GS | 5.2329 | 5.2319 |
| 完整动态帧 | **34.1306** | **29.6699** |

耗时减少 **13.069%**，对应训练吞吐约 **1.1503 倍**。最大收益来自冻结 gate 后的区域与点残差阶段，符合移除全层候选计算及重复正则图的预期；新增阶段基本不变。

PyTorch 峰值 allocated 为 1,386,968,576 / 1,386,970,624 B，基本不变。此数值只统计张量分配，不能当作整张显卡的总占用。

## 数值、存储与限制

定向检查覆盖正则每步只计一次的权重、设备标量返回 Python、冻结后单 owner 与全层目标及四组运动参数梯度的一致性，以及零权重分支跳过无用计算。整合清理后的完整 CPU 回归为 145 项，141 项通过、4 项 GPU 检查跳过；真实 GPU 训练验证另由上述成对测量完成。

浮点梯度累加顺序改变后，量化和新增阈值附近可能出现离散分叉，不能声称结果逐位一致。最终成对测量的运动与新增属性 payload 为 178451 / 178318 B，不含 manifest；最终新增点数为 86 / 92，末次训练视角图像损失为 0.01189594 / 0.01187811。这些是训练诊断，不是独立测试 PSNR，也不证明全序列质量无损。

该第 1 动态帧在较低 storage 权重下约需 178 KB，超过 50 KB 目标；它不是全序列均值，仍需后续真实序列评估。13.1% 是上述单帧、关闭评估和部分 I/O 条件下的实测，不应直接替代完整训练耗时或外推到全部 300 帧。

## 证据

派生汇总 JSON、测量脚本、原/新三份模块快照和 diff 保存在 [轻量证据归档](../archive/training_speed_20261016.tar.gz)，不含原始训练模型、数据或日志。原始临时日志与单帧产物位于 `/tmp/my4dgs_training_speed/`，不作为长期依赖。

本轮优化没有改变 gate/区域/GS 的训练阶段，也没有启用 robust_median 或删除远处 GS；调度与初始化讨论需要单独验证。
