# 近期训练帧监督共享 DC：Sear 30 帧

## 思路与实现

保留原有运动 gate、逐点运动/透明度及区域共享 DC 码流。实验入口位于 `output/experiments/recent_shared_dc_20261108/run_recent_dc.py`，通过环境变量 `RECENT_DC_MODE` 显式启动；`off` 不安装任何运行时钩子，未修改生产训练源文件。`control` 只从现有选点渲染中记录支持度；`recent` 额外替换后 100 步中 25 次当前训练视角为同相机最近 1–3 个已解码帧，单步一个视角，其他 75 步为当前帧。历史图像梯度只进入当前帧量化区域共享 DC；对应点需通过完整 survivor 身份映射、当前视角合成权重支持至少 1，历史渲染中的遮挡由真实合成处理。历史帧状态与码流均只读，不依赖未来帧或 test 视角。此设计导致逐点属性在这 25 步没有当前图像梯度，不能把差异全部归因为历史监督本身。

## 配对条件和核验

Sear 帧 201–230，两个分支同一个第 200 帧前驱、相同首帧参考、相同随机种子、训练相机池、优化步数、量化和编码器；各自继承本分支的实际解码状态。训练使用全部训练相机并每步抽一个；cam00 只评价。共同比较自 `sear_shared_dc_step0025_full_20261107` 的帧 200 开始；共同参考实际 11,299,285 B，结果中的动态包不含参考。每帧 25 次历史监督及帧标识、相机、可见支持均有记录，历史包和每一帧解码摘要核对通过；两条 201–230 连续流均从参考独立重放，逐帧训练前向与解码渲染最大差异 0。

CPU 测试覆盖零更新与 STE、点身份不匹配拒绝、时间窗口以及真实共享 DC 两帧往返；既有 RegionalDCUnitTests 7 项全部通过。关闭原型和支持采集对照的两帧烟测并非逐位一致：frame201 test PSNR 差 0.00777 dB，step60 的损失已有微小分叉，早于 step200 的支持采集。代码中的 `off` 不安装实验钩子，但不能把两次独立运行解释为数值逐位复现。

近期监督 test PSNR 平均下降 0.10022 dB，26 帧下降、4 帧上升。201–210、211–220、221–230 分别下降 0.04870、0.14568、0.10630 dB；最大下降是 frame214 的 0.19565 dB。记录的 cam06 训练视角平均下降 0.06532 dB，不能将 cam06 当作全部训练视角。压缩仅少 91.5 B/帧，不能证明率失真改善。编码字节包括所有动态包与 manifest；训练损失及相机均无 test 选参。

## 结论与边界

该固定三帧窗口和 25% 替换训练预算的方案在 Sear 此段明显不利，不建议作为默认；由于损失训练当前视角的逐点图像更新、实际动态变化及时间不一致等因素无法隔离，尚不能说明是哪一项造成下降。按“前期结果不适用即停止”终止本次队列；Flame Salmon 对照刚开始训练第 201 帧，未完成，不能报告其效果。既没有覆盖整个 N3DV，也没有运行 300 帧，不支持跨场景结论。
