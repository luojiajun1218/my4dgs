# flame_steak：当前代码的 300 时间点 baseline

## 设置

使用共享首帧 frame 0 和动态帧 1–299；候选空间层级加区域共享运动与逐点残差，每动态帧 200 步，区域与逐点属性联合更新。沿用场景现有超参数；本次没有改动训练代码。短实验是 30 个时间点（29 个动态帧），平均 PSNR 34.2225 dB、动态存储 42.61 KB/帧，未据此调整参数。配置见 `config/n3dv_baseline_flame_steak_300frames_20261113.yaml`，运行结果为 `output/experiments/n3dv_baseline_flame_steak_300frames_20261113/20261113T010338_27b49b`。

## 结果

以下为测试视角逐动态帧算术均值；KB=1000 B。动态存储包括完整动态帧包、不含共享首帧。分段值由逐帧日志中保留的小数计算。

| 动态帧 | PSNR / dB | 动态 KB/帧 |
|---|---:|---:|
| 1–299 | 34.1701 | 36.49 |
| 1–100 | 34.2334 | 40.08 |
| 101–200 | 34.2702 | 36.54 |
| 201–299 | 34.0049 | 32.82 |

总体 SSIM 0.9656、LPIPS 0.1225；3/299 帧超过 50 KB，最大 85.17 KB。共享首帧 12,299,793 B，动态总计约 10.91 MB，首帧加动态总计约 23.21 MB。平均训练时间 17.93 秒/动态帧。日志包含 1–299 共 299 个不同的帧并正常结束；本次没有单独测量解码后渲染 FPS 或完整播放 FPS，也没有独立顺序回放核验。

全序列动态帧 PSNR 超过 34 dB，但未达到 34.2 dB 目标；动态均值低于 50 KB。历史 `output/best/index.json` 的 flame_steak 记录为 34.2714 dB、42.22 KB/动态帧，该历史结果路径已失效且采用旧方案；此次码率较低、PSNR 也较低，不能仅凭这两个数字判定整体超越。前后段 PSNR 和码率变化可能与画面内容、运动及训练状态有关，单次实验不能证明原因，也不能将结果归因于自适应层级。

本次沿用短实验配置中的 checkpoint 保存帧列表，因此没有保存 frame 299 的训练 checkpoint；完整 1–299 动态帧码流及首帧参考均已保存。
