# Coffee：SH 方向系数学习率初始化实验（未生效）

本实验原计划将逐点方向相关 SH 系数的学习率从 DC 的 1/20 提到 1/5，沿用 80% RMSE、运动收缩 1.0 和每步一个训练视角。实现时只改了属性优化器的初始化学习率，遗漏 `full_update_prepare_step` 每步重设学习率；因此实际训练仍使用原来的 1/20。结果不能作为提高学习率的实验结论。

动态帧 1–30：cam00 平均 PSNR **29.68631 dB**、SSIM 0.925745、LPIPS 0.139501、动态包 54.803 KB/帧；每帧最多选 1600/160000 点。对照的原 1/20 学习率短运行分别为 29.70930 dB、0.925767、0.139335、54.676 KB/帧；两条轨迹不同，仅说明本次重复运行结果，不代表高学习率效果。cam00 已用于开发选型，不是独立最终测试视角。
