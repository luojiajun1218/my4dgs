## 核心想法与实现范围

作者允许重新考虑区域旋转语义后，让区域同一组平移/旋转共同解释GS位置与朝向。选中区域仍是绝对运动，父子运动不累加；GS仍存区域预测之外的残差，gate决定是否细分。

位置预测、数值原点、量化、Kabsch初始化及保持姿态的重编码见 [第79帧局部验证](20261015_spatial_gate_shared_transform_frame79.md)。本次保持空间树候选、gate学习规则、100步运动+100步新增GS、量化步长、rate/relative权重、4视角/step及原有新增GS规则。原点从已解码位置和成员确定，没有增加传输参数，没有透明度修正。

采用隔离运行器而非替换生产模型。配置 `config/fs_spatial_transform_probe_200_first5_20261015.yaml` 必须通过本实验运行器使用，直接传给普通main.py会执行原生产算子，不能复现本实验。

## 机制分析：先纠正共享旋转估计目标的不一致

本候选用Kabsch只拟合GS中心的位置运动，却把得到的R同时用于协方差朝向。它没有要求这同一R能解释自由拟合的GS朝向运动。两者目标不一致，不能把“位置刚体拟合好”直接等同于“渲染共享运动好”。此外L2均值平移也不同于原量化残差统计，候选代表值不能脱离实际残差成本来判断。

对第1帧保存的step40和60做只读检查：两次实验上一帧位置及空间路径逐项完全一致。在候选step60实际选中的cut上，step40初始共享旋转有3045个点超过0.01 rad，100个超过0.1 rad；在同一cut读取原初始化，最大仅0.003742 rad。候选最大初始旋转0.95211 rad，step60仍0.95211 rad。例如节点33399只有5个点，初始R为[-0.264, 0.913, 0.057]，原统计值为零，该节点位置散布第二/第一特征值比约0.00230。

这支持检查“小区域位置拟合的旋转是否可靠、是否也符合朝向证据，以及它能否在gate窗口内纠正”。但这些点可能可见性弱，且这里只读参数，没有将旋转单独干预并做图像归因；不能断言它解释全部画质下降，更不能据此解释原方法长程退化。其他较大旋转区域并不都几何病态，单加条件数阈值也没有充分依据。

下一步规则应是：**同一候选共享运动，必须按位置和朝向共同产生的量化残差来估计和评价。** 不应只拟合位置后期待gate和少量优化步数自动修正不一致的朝向。不追加无关机制或直接拉长训练。本次保留原生产表示，不推进长序列。

一个记录限制：隔离实现继承了生产 `flat_region_diagnostics` 中“orientation-only / median initialization”的文字标签，这两个文本字段在本实验不适用；实际算子以 `experimental_operator.json`、motion导出语义、私有码流及独立解码核验为准。数值区域/残差统计可用，勿据继承的文字标签误判实验方法。
