# Cook Spinach：固定与自适应层级消融（冻结 gate 的附加对照），300 时间点

## 共同设置

共享首帧、同一候选树和每帧 200 步训练顺序；首 100 步仅共享平移及自适应 gate，区域旋转在这一阶段沿用原方案冻结；后 100 步训练区域运动、逐点运动和属性，gate 固定。固定深度组每帧按上一解码位置路由到指定层，200 步内归属不变。四组独立从首帧递推，不复用历史动态前缀。

## 画质与存储

- 相对 depth2，自适应 PSNR +0.3478 dB，动态存储 -0.299 KB/帧，活动区域 +138.2。
- 相对 depth3，自适应 PSNR +0.1510 dB，动态存储 -1.584 KB/帧，活动区域 -296.3。
- 相对 depth4，自适应 PSNR +0.1251 dB，动态存储 -20.517 KB/帧，活动区域 -3211.8。

码率为实际文件大小与 manifest 的总和，KB=1000 字节，不含首帧；motion、区域属性和逐点属性只列主要分量。计时为项目 `training_seconds`，包括验证并扣除诊断日志，排除最终 checkpoint 写入。逐帧相机顺序、参数冻结、固定层归属、训练/解码渲染一致性、逐帧实际字节和独立顺序回放摘要均已核验。
