# 区域颜色与gate联合学习：共享首帧起步的早期核验

## 范围和结论

使用[已完成晚期短测](20261018_joint_regional_dc_first3.md)的同一67文件冻结源码，从原始共享第0帧训练1–3帧，再独立顺序解码。数据配置仍为300帧，原始图像通过软链接访问，实际1600×1199。

**联合颜色在早期也有小幅收益，但仍低于同范围基线，没有直接续跑前30帧或完整300帧。**

## 配方与实际负载

仅启用`feature_dc_update.gate_joint=true`，保持提案图像监督权重1、storage0.002、运动L1=0.5。70步随机gate联合、30步固定gate稀疏优化、100步固定支持精修，再100步新增GS；运动每step2视角，全部旋转关闭，保留量化、近端和低α删除。

动态帧更新均值：运动16.259KB、α10.982667KB、区域DC0.308333KB、新增属性2.456333KB、manifest0.658333KB。KB=1000B，一次性参考另计；区域均值186.67。训练约38.48秒/动态帧；0–3独立纯渲染208.364FPS，不含解码与上传。

早期GS残差数较原候选减少，但晚期短测没有同样下降，因此尚不能概括为整序列减少零散运动。下一步检查图像目标和近端稀疏的配合：当前像素L1部分对不同大小的非零误差给出同样大小的梯度；将保留本次gate/颜色机制，短测与PSNR更一致的全图RMSE像素项，SSIM权重保持不变。该方向尚未取得实验结果。
