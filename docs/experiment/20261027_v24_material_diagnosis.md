# v24 全序列误差定位与新增点材质检查

这是已完成v24实验的只读诊断，未训练、未调整参数，也未修改历史输出。运行：`output/flame_steak_1026/fs_v24_300/20261027T025304_49567c`。

## 误差并不只来自火焰

对全部299动态帧的保存PNG，在cam00用人工矩形粗分区域并累计RGB平方误差：锅/火焰区9.75%，人物10.88%，狗/椅区4.77%，其余74.60%。frame172的火焰矩形约占23.11%，frame257约24.17%。不能把单个火焰案例代表为全部误差。

这些矩形只用于诊断，不参与训练或阈值选择。PNG有8bit量化，数值不替代正式float PSNR；“其余”包括未覆盖的动态内容、阴影和遮挡，不能直接称为静态背景。

原保守颜色初始化并非完全不生效：全序列平均每1000个候选中157.68个得到非零颜色修正，最多380个。是否应改进它，需要进一步判断其可见响应和实际图像收益。

DC变化为相对自身初始化值的三通道RGB向量L2范数，换算系数C0=0.28209479；不是逐像素颜色误差。step200为未量化参数，最终结果为真实量化后的完整属性，二者不能视为同一个测量阶段。

解释与边界：大量候选在step200时已接近透明；存活点确实学到了颜色变化，不能说颜色没有学习。少数候选全部通道被SH clamp截断，但它们不足以单独解释绝大多数退出。单通道被截断较多也可能是合理的饱和颜色。当前检查没有可见性加权，不能把每个截断通道认定为有害，也不能由颜色变化幅度推断梯度不足。

因此，下一步应检查候选在当前完整混合图像中的可见响应和有用残差方向，确认是几何支持、初始化外观还是缺少有效收益；不直接提高候选数、不由此改变统一删除阈值。已有旧实验中跨视角共同DC拟合曾出现训练提高而测试下降，见`20261026_support_reincarnation_v9_short3.md`，也不应仅凭背景误差占比就全面开放旧颜色。
