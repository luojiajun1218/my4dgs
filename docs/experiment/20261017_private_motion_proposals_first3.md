# 个体完整运动提案与预测器中心近端：三帧短测

## 想法与实现

原相加参数化下，共享区域与GS残差可能同时追同一图像误差。本次把个体参数改为完整运动提案：gate停止细分时使用共享运动，到最深叶子时使用个体完整运动。叶子的绝对区域运动作为编码预测器，通过残差成本学习；GS码流仍只传“个体提案减去区域预测”的整数差。

新增默认关闭的 `spatial_gate.private_full_motion`，要求层级个体许可和联合图像拟合。区域仍使用绝对运动；共享、个体提案是互斥备选，叶子预测器不重复接收图像梯度。图像Adam只优化个体提案的图像部分；连续近端和块近端将它拉向量化区域预测，而非零运动。候选编码目标使用整目标STE，确保关闭叶子也能学习预测值。

编码在int32中计算整数差，范围检查后再转为int16。硬渲染沿用编码器“base＋区域＋残差”的相加顺序，保留既有SPG解码格式。跨帧先读取旧策略下已应用运动，再迁移为新的完整提案，保存出生来源和热启动。新增checkpoint语义标签，保留旧默认行为。

## 硬化诊断

细网格实验在第70步冻结前记录连续场转为离散场的平移差：

| 帧 | 平均跳变/world | 95%分位/world | GS量化步长/world |
| --- | ---: | ---: | ---: |
| 210 | 0.000309422 | 0.001392655 | 0.000194809 |
| 211 | 0.001356690 | 0.004917070 | 0.000194809 |
| 212 | 0.001092125 | 0.003639609 | 0.000194809 |

95%分位约为量化步长的7–25倍。它是运动场差值，不直接等于PSNR损失；但表明连续训练解与最终硬模型之间存在明显落差。一个可能原因是小开关概率可以被较大的候选运动补偿，连续图像仍能拟合，硬化后该组合却不存在。下一步考虑使用训练期随机离散gate，令候选在实际选中时接收自己的图像误差，而不是继续增加连续模型容量。
