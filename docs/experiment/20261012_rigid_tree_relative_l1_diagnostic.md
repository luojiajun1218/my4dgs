# 用 L1 鼓励共享相对运动

[HEIR 式 (5)](https://arxiv.org/html/2510.26786v1) 对相对速度使用 L1 正则。这里借鉴这一动机，将区域惩罚统一为归一化平移各分量绝对值之和，加旋转向量各分量绝对值之和，再对非根区域取平均。这是本项目的 SE(3) 残差处理，不是 HEIR 图网络或旋转建模的完整复现。

训练损失、换父节点的原状态评分与候选评分共用同一函数，候选排序也使用同一 L1 大小。不新增运动模式，近端稀疏和码流不变。L1 在零附近的梯度比原平方项强，因此权重从 0.2 降为 0.006；不能把两个权重数值直接比较。

从上一轮 3072 区域诊断的同一 frame49 bootstrap 副本开始，全部张量保持相同，只修改三处对应配置权重。仍为 600 步运动、200 步共享预拟合、200 步新增 GS、每次 32 个换父节点候选，仅运行帧 50–52。完整检查通过：296 项数值检查、46 项 unittest、11 项压缩检查。

| 帧 | 3072 区域 L2 PSNR | 本轮 L1 PSNR | 本轮增量字节 | 可动区域数 |
|---|---:|---:|---:|---:|
| 50 | 33.20826 | 33.20445 | 45,611 | 2,176 |
| 51 | 33.44558 | 33.38559 | 38,873 | 1,775 |
| 52 | 33.39565 | 33.19198 | 35,819 | 1,416 |

平均 PSNR 33.26067，比上一轮低约 0.089 dB；平均增量 40,101 字节，比上一轮减少约 14.2%。第 50 帧接受 32 次换父节点，没有 GS 改归属，编辑瞬间原始流增加 127 字节。L1 使更多区域归零，但第 52 帧画质损失较大，不能只报告平均存储收益。

本轮没有测 FPS，不代表全 300 帧达到目标。完整基线在诊断完成后恢复运行，使用原冻结版本。
