# 区域代表和 gate 使用同一个目标：前 5 帧

运行：`fs_spatial_gate_objective_300_first5_20261015/20261015T063146_bf07a8`。共享首帧起跑，动态 frame1–5 正常完成，源码冻结在 `source_snapshot`。

核心 idea：对固定完整 GS 运动，区域代表和 gate 都比较同一个稀疏块字节代理加相对残差 L1。完整六维众数只优化精确联合匹配数量，未必最小化这个目标；平移一致但旋转不同的点也应能共享平移。代表改为该目标下的合法整数最优解，用块匹配计数、坐标中位数和已有联合向量求解，不遍历六维整数空间。统计重编码保持完整位姿不变；区域仍不接受直接图像梯度，gate 仍学习是否细分，没有新损失或透明度模块。

保留前 40 步完整点运动拟合及绝对稀疏化，建立区域后再约束相对残差；每帧 100 motion + 100 birth + 100 refinement，运动更新平均 4 个训练视角。100 项检查通过，包含与小范围穷举最优值一致、共享平移不被不同旋转符号掩盖、整数范围、重编码位姿与优化累积量，以及静止多数点不被误带动。旧代表目标 checkpoint 仅回放，不能静默续训为新目标。
