# gate未来残差估计：连续5帧过度细分，未采用

## 结论

[第79帧局部检查](20261015_spatial_gate_future_residual_frame79.md) 的弱正向收益没有在连续短序列复现。动态帧平均PSNR **34.443086 dB**，原方法同范围 **34.486189 dB**；完整增量 **58864.25 B/帧**，原方法 **46480.25 B/帧**。不接入生产，不扩大长实验，不扫描未来成本权重或稀疏阈值。全300帧目标未完成。

## 核心规则

保留40步自由提议、41–60共享场+learnable gate、61–100零起点GS残差、101–200新增GS。区域仍存绝对运动、GS存区域残差，不累加父运动。

区别仅为gate在共享阶段估计未来点残差成本：临时保留40步完整量化运动，对每个候选区域的假设残差，用现有Adam二阶矩及已知首次残差prox窗口学习率，执行与现有代码相同的T/R四块保留/清零选择，再计算原有rate与relative项。梯度只进入gate概率，区域参数仍由图像拟合；实际GS残差保持零，60步丢弃参考及metric，不恢复自由运动位姿。

没有新增损失、模块、透明度修正、播放数据或优化外层步数。它不是未来码量真值：warm运动和梯度统计与后续真实拟合会不同。本次验证的正是该近似是否足够支持有用的gate决策。

## 为什么“现有prox一致”仍不足以预测未来残差

从保存的40步参考/metric和60步选中区域重新计算预测，与记录中的预测字节逐项一致，说明实现不是用了另一套阈值。但100步真实残差与它差异很大。下面两边使用**同一绝对行号稀疏字节代理，仅点残差，不混入区域/出生/索引或压缩差异**：

|帧|60步预测点代理 / B|100步实际点代理 / B|高估倍率|预测点行|实际点行|
|---|---:|---:|---:|---:|---:|
|1|728207|175425|4.15|66845|17056|
|4|610685|25154|24.28|54498|2445|

第4帧预测T/R残差行分别52302/14683，实际仅2222/381。预测相对T/R的L1约0.0007245/0.0005743，实际约0.00001178/0.000002891。两种分量都明显高估，不应只删除旋转预测或扫描一个比例来掩盖问题。

后续区域拟合会吸收运动，点残差也会重新优化并被稀疏裁决，40步自由提议不等于它们的最终结果。因此这套冻结参考即使按相同局部prox规则处理，仍将许多不会保留的点变化视为开细层的收益。结果与“区域过多、真实总码量增加”相符，但没有通过单独干预证明它解释全部PSNR损失。

也不能据此推导“细分越少越好”：局部第79帧确实有收益。正确边界是，此近似不能作为正式gate成本目标。它没有解决如何让区域共享运动、点例外与gate最终决策互相对齐的问题。

下一步回到实际共享运动的学习和真实残差反馈，避免继续把未约束自由GS运动当作未来真值；不以更多静态约束、额外模块或更长序列替代该问题。
