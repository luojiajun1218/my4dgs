# cook_spinach：当前代码的 300 时间点 baseline

## 设置

共享首帧 frame 0 和动态帧 1–299；候选空间层级、区域共享运动与逐点残差，每动态帧 200 步，区域与逐点属性联合更新。沿用场景现有参数，本次没有改动训练代码。短实验为 30 个时间点（29 个动态帧），平均 PSNR 33.7916 dB、动态存储 45.64 KB/帧，未据此改参。完整配置 `config/n3dv_baseline_cook_spinach_300frames_20261113.yaml`；结果 `output/experiments/n3dv_baseline_cook_spinach_300frames_20261113/20261113T041029_b6e769`。

## 结果

测试视角逐动态帧算术平均；KB=1000 B。动态存储包括完整动态帧包、不含共享首帧；分段值由日志中的逐帧小数计算。

| 动态帧 | PSNR / dB | 动态 KB/帧 |
|---|---:|---:|
| 1–299 | 33.6052 | 38.67 |
| 1–100 | 33.7147 | 40.67 |
| 101–200 | 33.6912 | 37.87 |
| 201–299 | 33.4078 | 37.46 |

总体 SSIM 0.9574、LPIPS 0.1363；4/299 帧超过 50 KB，最大 75.69 KB。共享首帧约 12.419 MB，动态总计约 11.56 MB，合计约 23.98 MB；平均训练 18.58 秒/动态帧。日志包含 1–299 共 299 个不同的帧并正常结束；本次未独立顺序回放，也未测已解码渲染 FPS 或包含读包和解码的完整播放 FPS。

全序列动态帧均值低于 34 dB，动态码率低于 50 KB。历史同方案完整实验为 33.6076 dB、38.686 KB/帧，本次数值接近；`output/best/index.json` 的旧方案历史记录为 33.9218 dB、约 50.08 KB/帧，但其原始目录已失效且方案不同，此次 PSNR 低而码率也低，不能直接判定整体超越。末段均值低于前段，画面和运动随时间变化，单次结果不能证明累积漂移或归因于自适应层级。
