# 第79帧运动RMSE目标：训练MSE改善，测试与码量变差，未采用

## 出发点

[累计误差定位](20261015_spatial_gate_cumulative_error_localization.md) 显示，第49→79帧约97.92%的新增训练像素SSE位于画面变化区域；同帧已有原生训练视角PNG比较，第79帧约96.11%的额外SSE也位于变化区域。恢复多视角疑似静态GS的首帧姿态反而变差，不支持优先添加背景冻结。

现有L1对大/小像素误差的单像素梯度幅度相同，可能不足以优先处理大错位。此次有界候选将运动阶段现有L1项换成RMSE，SSIM保留，不新增损失项或模块，也不使用上一项诊断的掩码。

## 改动与范围

运动图像目标为 `0.8 * RMSE + 0.2 * (1-SSIM)`，用vector norm除以元素数平方根，精确相等图像处有有限零梯度，不加epsilon参数。保留coarse-to-fine、4视角/step、gate、共享场GS归零及重启、rate/relative原系数、量化与prox窗口。新增GS阶段仍使用原L1+SSIM，本次没有执行该阶段。

RMSE和L1虽同为像素强度单位，数值幅度/梯度分布不同；沿用系数不等于匹配了原目标的有效权衡。没有扫描系数或掩码阈值。

从worldroute第79帧step20恢复至100。前20步与此前状态均沿用原方法，故这是条件局部检查，不能当作从首帧开始的新序列。运行使用原快照，补丁隔离于 `/tmp/my4dgs_motion_rmse_probe_20261015.py`，没有改生产源码或历史输出，不输出可恢复的替代训练checkpoint。

**未采纳，不进入短/长序列，不继续扫描RMSE权重。** 更强的训练像素拟合没有转化为测试画质，不能把“给变化区域更多梯度”直接当成解决方案。需要继续检查共享区域/GS残差所允许的三维运动是否跨视角一致，以及gate是否能真实评价细分对后续残差的收益。这是后续机制问题，不由本实验直接证明具体原因。
