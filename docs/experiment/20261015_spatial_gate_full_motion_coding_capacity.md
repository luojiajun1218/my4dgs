# 总运动约束与编码容量检查：换树不能消除当前场的大量点残差

300步短实验画质未改善后，检查了当前目标定义：小GS相对残差仍允许区域带动全部成员运动。原worldroute frame79-step100，218265个GS都有量化平移或旋转，只有5692个有点残差；总运动六维L1范数均值0.004148415，相对残差0.000044237。这不证明这些总运动都错误，只说明“残差小”和“实际运动少”是两个目标。

## 局部总运动约束候选：未采用

从相同frame79-step20重放至100，已有幅度项替换为实际GS六维分量绝对值均值（平移/extent、旋转/radians），不增加额外损失项；shared阶段给gate预期候选运动成本梯度，实际运动参数只接收当前cut的幅度梯度。仅改变编码原点不改变此先验，因此代表值按码量选择，不再按相对L1选择。系数沿用原值，但归一化和目标含义不同，总目标不得直接横向比较。

原规则训练图像损失0.015249028，候选0.015368753，略变差；测试33.613083→33.620659，几乎不变。量化运动点218265→132652，点残差行5692→16216，区域338→88，纯运动包27651→72295 B。真实运动点减少，但编码代价增加，因此没有采用。session78839正常退出0。

原生reg_loss也包含共享参数偏离identity的约束，实际lambda_deform=1，但原生为原始7维参数，与这里六维归一化向量不等价，不能据此认定同一系数最优，更不能把本检查当作退化因果证明。

## 保持运动完全固定，优化树的编码形式

为了区分运动不易共享和gate未选对，再重放一次候选并仅捕获最终整数运动、空间路径等诊断数据（非可恢复训练checkpoint，session23502退出0）。这次捕获包73139 B，与前次72295 B有非确定性差异，后面的比较只在同一份捕获运动内进行。

CPU检查遍历已有五层候选，按当前加性原始字节代理、现有split eligibility、前8根区域和观测资格，用纯码率代表值及自底向上动态规划选择cut。压缩算法非加性，因此这是“原始代理最优cut”，不是证明压缩后总字节全局最小。两种编码均核验整数运动逐项完全一致、解码位置在既有浮点容差内，没有修改运动或优化图像。

## 表示定义的数值反例：共享位移与共享变换

模拟1024个GS组成的平面刚体，统一旋转0.175 rad并平移0.01，平移量化步长0.0002，朝向也统一旋转。当前区域给所有点一条相同平移、旋转只更新朝向；即使选择最佳常量位移代表，也有1023个点需要位置残差。用同一组6维平移/旋转定义几何变换并解释GS中心，同一模拟目标可以零位置残差表达。

这是构造的刚体例子，不是真实序列改进或码流速度结果。后者会改变作者之前明确规定的“区域旋转只作统计，不改变GS中心”语义，生产代码没有做该改动。此反例用于讨论约束是否需要重新对齐，不能暗中将现有方法改成绕区域中心旋转。

## 真实已学运动的只读几何拟合限制

在同一份已学运动目标上，对当前区域中至少3个点的76组、共218249点，比较最佳常量位移与刚体Procrustes拟合。位置RMS分别0.002932826和0.002891856（场景坐标单位，不是校准米），SSE下降约2.774%。忽略了协方差朝向拟合、量化和完整码量，目标也是已学流而非真实场景流。因此真实目标上的这项结果很弱，不能用前面的刚体数值例子证明换表示就会提高实景画质。

已向作者询问此前“旋转只统计朝向、不改变GS中心”的约定是否仍为硬约束；在回复前保留原规则，不实现几何旋转。可独立继续检查作者最早提出的空间邻域换区规则，先量化当前代表值下的匹配机会，并计入归属信息成本。证据：`/tmp/my4dgs_worldroute79_geometric_coherence_20261015.json`。

## 保持原旋转语义的空间邻域换区机会

没有修改GS位置、朝向或正式树。以此前已解码位置的8个最近GS所对应区域作为邻域，在固定代表值下检查单次局部迁移，分别考察编码成本和作者所说的相对运动幅度；没有实现“每迁移一点立即更新众数”的完整顺序算法。

对总运动先验捕获目标，9506个点能接触其他区域，计入“绝对GS行号varint+1字节邻居序号”的保守归属开销后，没有点能通过迁移降低当前原始编码代理。

对原worldroute frame79-step100目标，按已有extent/radians相对L1最小规则，17个点有更近的邻域代表；相对L1均值0.000044236547→0.000044177491，非零残差行仍5692。点残差原始代理仅少6 B，归属信息代理需67 B，净增加61 B。这是固定当前代表值的匹配机会诊断，不是完整迁移算法或实际压缩码流结果，也不能证明动态重新聚类永远无用。

另一个重要限制：原生ReCon-GS的旋转也主要更新协方差朝向，位置由多层平移场解释。因此不能把“旋转不更新位置”直接说成我们落后原生的唯一原因。讨论共享几何变换的目的，是在低码率下用更少区域表示转动产生的空间变化位移，仍需重新训练和实际序列验证。
