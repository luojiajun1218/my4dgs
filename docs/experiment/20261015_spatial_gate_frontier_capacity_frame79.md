# 第79帧共享场整体细分容量检查：增加细分收益有限

读取已停止worldroute100运行第79帧step60状态，全部GS残差为零且冻结。不是新训练序列，不修改生产gate、不恢复失败长实验。以source_snapshot加载，GPU独占，session8499正常退出0。

当前有351个有效区域，其中140个有效frontier父区域可以细分。诊断将这些区域只展开一层，其子区域全部关闭更深gate，得到1211个有效区域。两种情况都让各自全部有效区域参与优化，使用相同新建局部Adam、现有区域基础学习率、相同20步×4训练视角；子区域复制父区域完整平移/旋转，初始渲染位置和朝向逐项精确相同。点残差全程冻结为零，不靠单点自由运动补偿。

直接打开未拟合的旧子字典，图像损失0.015497891、测试PSNR33.624527，本身也不比原始父场差，不能在此案例中把“子区域未训练导致gate比较失真”当作已经证实的主要原因。整个检查也不能证明任意更深的树都无用，或当前gate全局最优。

当前证据不支持生产中统一打开更多gate、强制加深或增加随机探索机制。候选只测试了相同位姿附近、下一层区域常量运动的局部拟合能力；没有检验从错误时间跟踪中重新建立正确对应的能力，也不是全序列效果。后续先检查第79帧自由运动提议→共享切换→残差拟合的图像损失变化，确认误差是否在当前切换前已经出现，再决定下一项修正。
