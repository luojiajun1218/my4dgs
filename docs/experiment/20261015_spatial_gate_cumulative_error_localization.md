# 长程误差定位：增长集中在画面变化区域，恢复疑似静态点反而变差

## 结论与边界

本轮没有训练新方法。对原worldroute已完成0–79帧做逐点运动分解，再用训练相机的图像变化定位误差。第49→79帧，按固定图像变化掩码统计，约 **97.92%** 的新增像素平方误差位于变化区域。与已有原生第79帧图片比较，约 **96.11%** 的额外平方误差也在变化区域。

把多视角疑似静态GS的位置恢复到首帧，训练画质反而降低。因此当前证据不支持“背景被共享运动带偏是主要退化原因，先加强静止约束”的方向。重点应转向变化区域的运动拟合。图像变化并非真实运动/物体分割，不据此宣称某个具体树规则已被证明是根因。

## 下一项有界改进

现有gate和运动拟合使用全图L1+SSIM。L1对小误差像素和大错位像素的单像素梯度幅度相同，可能使面积更大的稳定区域占据较多更新，而目标PSNR更关注平方误差。这是待检验假设，不是已证明的根因。

下一项局部检查仅把运动阶段现有L1项替换为RMSE，保持SSIM、rate/relative、gate、区域/GS关系和100+100步规则；不增加损失项或模块，新增GS阶段仍用原目标。RMSE与L1虽同为强度单位，但幅度与梯度分布不同，不能声称原系数的有效权衡完全等价。先检查第79帧原状态条件下全部训练视角MSE及真实运动包，再决定是否值得从首帧做短序列。
