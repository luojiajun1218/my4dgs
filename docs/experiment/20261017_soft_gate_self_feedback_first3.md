# 候选自反馈与连续选择退火：210–212帧短测

## 问题与方法

整场STE能让关闭区域收到非零图像梯度，但其自身的预测不参与硬渲染。一个受控检查中，将关闭候选的平移从0.02改为0.2，图像误差和候选梯度完全不变；梯度连通不能保证候选获得自身预测的反馈。

新增默认关闭的训练选项 `spatial_gate.image_relaxation: soft_anneal`。训练前70步使用真实连续路径权重，温度从3指数下降到0.3；gate根据图像与存储目标学习，仍以logit符号得到最终离散选择。后30步固定gate，联合拟合区域与GS残差，再训练新增GS100步。评估、物化与码流始终使用离散场，最终不传输混合权重。

## 结果

同一个已完成第209帧checkpoint续跑210–212，所有旋转关闭，T网格6e-5、storage权重0.003、残差L1权重1、运动每步2视角。此候选允许任意选中区域下的GS残差，未启用层级个体许可。初始logit=-0.2，跨帧logit缩放0.1；它与基线存在多项差异，结果用于筛选整体候选。

平均训练约19.05秒/帧，独立纯渲染约243.23FPS。KB=1000B，完整更新含运动、透明度、新增GS与manifest，参考帧另计。三帧结果不代表完整300帧。

**未胜过基线，没有启动新完整300帧。** 该候选已接近基线画质，但更新约增加12.7%，GS残差数量也增加。连续反馈修正了受控例子中的学习方向，仍不足以保证真实区域运动能够高效共享。

## 代码与核验

改动集中于 `pipeline/model/spatial_gate.py`、`spatial_gated_motion.py`。新增训练期连续场、可配置最终温度、固定gate时运动Adam状态重启、独立训练语义标签，以及温度诊断。原始 `hard_ste` 默认和重要基线配置保留。

256项检查通过；新增检查覆盖候选过冲后梯度反向、私有候选自反馈、训练混合与离散码流的分离、退火不改变阈值、软阶段和硬阶段的精确恢复。三帧独立顺序解码的PSNR差与缓存像素差均为0，首尾终态checkpoint原始属性一致，所有源码和来源哈希通过，旧点朝向不变、新点朝向继承。

本地运行：`output/fs_goal_rd_20261017/gate_soft_anneal_late210_212/20261017T231527_20371b/`；配置 `output/fs_goal_rd_20261017/gate_soft_anneal_norot.yaml`。候选反馈检查为 `output/fs_goal_rd_20261017/hard_gate_candidate_feedback.json`。

下一步检查训练参数化：当前相加的共享场和GS残差可能同时追同一图像误差。考虑让个体分支学习完整运动提案，gate在共享和个体提案间选择，再在编码时减去区域预测得到残差。区域仍使用绝对运动，改动不等于把子区域改成父相对表示；该结构尚未实现。
