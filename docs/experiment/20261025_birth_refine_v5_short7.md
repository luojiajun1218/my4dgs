# 新增点细修与联合透明度衰减：短序列略升，存储超标

日期：2026-10-25。7帧训练和重新解码核验均完成。

## 想法与改动

第四轮极薄源点的位置约束可能挡住比旧运动网格更精细的修正，同时旧点透明度在新增阶段末尾仍保持固定学习率。

`pipeline/module.py`增加`birth.source_position_min_extent`，把源坐标中的每轴位移余量设为至少一个运动量化步长（6e-5×场景extent，约0.000389世界单位）。联合透明度的学习率也在新增阶段按相同指数曲线衰减；默认衰减比例1保持历史行为。

配置允许新增点调整方向；放宽新增透明度稀疏权重为0.01、剔除阈值为0.01，并把旧点透明度变化的L1权重从0.05改为0.01，以利用存储余量。该L1变动也影响运动阶段，所以不能把结果变化单独归因于细修余量或学习率。

其他保持：固定132586 GS首帧，初筛后128963 GS参考；1345×1008监督，200步运动+600步新增×3训练视角；物理尺度限制下160个外观候选，总候选600，learnable gate机制不变。

## 分析与下一步

细修和放宽稀疏压力仅带来小幅平均改善，新增点本身的即时收益仍小，且透明度更新、新增属性和方向更新使码流明显超标。不能直接进入300帧。

回看第四轮候选，约40.2%的源点透明度超过0.9，中位数约0.783。直接叠加在源点附近的新点常处于较低透射权重中，既要克服遮挡，还会与源点的透明度优化竞争；这可能解释训练时间增加后仍缺乏稳定收益。

下一步改成源点移交：从源点完整继承新点属性，在新增训练阶段将对应旧点透明度钉到零，使新点获得原有可见性和完整图像梯度；保留旧行作为本帧解码预测器，下帧再按已有低透明度规则删除。这样只让选中区域重新拟合，其他点保持原状，并避免重复点不断累积。该机制尚未完成实验，不能提前声称有效。
