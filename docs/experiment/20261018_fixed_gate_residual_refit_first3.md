# 固定gate后恢复共享残差坐标与精修：三帧结果

## 问题与改动

完整个体提案参数化中，叶子区域只接收编码目标；即使gate已经固定，叶子运动仍不直接拟合图像。本次在学习gate时保留随机离散完整提案，固定gate后将GS参数精确换成相对所选区域的残差，让区域与GS残差按实际相加的物理模型联合训练。

新增默认关闭的 `spatial_gate.reparameterize_after_gate_freeze`，要求随机完整提案。切换利用整数残差和保留bin余量，渲染位置及编码字节完全不变；运动Adam状态在坐标切换时重启。checkpoint保存当前坐标标志，防止把残差误当完整提案；下一帧重新从已应用的完整运动预热，出生来源也同步继承。

固定gate后可接既有的固定更新块精修：只调整已经保留的区域/GS块，不增加非零块位置，运动稀疏惩罚在精修期间关闭。

## 分析

共享叶子图像梯度已恢复，零GS残差也能随共享区域修正运动，代码与受控检查相符。但实际PSNR仅小幅提高；延长拟合再增加约0.001dB，仍比匹配基线低约0.053dB。**未推广至原生前缀或新完整300帧。**

这不足以支持“只需更多训练步数”的解释。此前随机提案第210帧仅8335个GS到达最深叶子、3930个带非零GS残差；其余GS若停止在粗区域，就无法使用个体残差。下一步优先恢复任意选中区域下的GS残差，再由量化及近端收缩决定哪些更新值得保留，避免把结构许可当成稀疏化的替代。
