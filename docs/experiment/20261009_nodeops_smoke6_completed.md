# 节点操作编码与提前学习gate：6帧检查完成

上一轮30帧中，结构编辑按GS逐项记录，候选费用达到约2.8 MB；新gate又被直接冻结。5次调整全部回退。这次先修编码与训练顺序，确认树真的能变化。

## 怎么改

- 新增`tree_edit_codec.py`：交换、合并传节点ID；拆分传区域内的归属位图。v4码流可重放这些操作，兼容读取旧码流。
- 将候选提出时点从180步移到100步。原树与候选各完成后续80步gate压缩、20步精修，预算一致。
- 固定树对照在同样的更新时点重置优化器，避免把优化器重置收益误认成结构收益。
- 新拆分每侧最少6个有效观测GS，与初始建树的12个GS限制分开。
- gate学习结束后，移除关闭或不可达的新拆分。数值检查要求移除前后最终姿态完全一致。
- 新拆分的结构费用进入可微存储估计；最终费用仍按真实文件计数。
- 初始化以量化后的运动为依据，减少重编码前后的姿态差异。
