# HDBSCAN：有效平面区域后联合细化

## 想法、实现与完成范围

四方法统一采用 **100 步自由 GS → 第 100 步分区一次 → 100 步区域共享和 GS 残差联合细化 → 100 步 births**。默认 `accept_valid` 接纳量化有效的非空划分，真实完整压缩字节继续记录；此次没有层级树和未来帧输入。

共同代码增加 `post_partition_steps=100`，自由阶段冻结共享参数，细化阶段成员固定；relative loss 针对 GS 残差平移/extent+旋转 rad，保留稀疏存储 proximal，第 200 步记录最终残差/码流后才冻结运动并开始 births，历史只在导出解码后更新。HDBSCAN 根据完整历史位移密度分组，最小区域和 min_samples 均为 8，不使用统计方法的 8192 点抽样限制。本轮没有独立调参。

- 配置：`config/fs_online_flat_hdbscan_refine_first5_20261013.yaml`
- 完成 run：`output/fs_online_flat_hdbscan_refine_first5_20261013/20261013T190751_b853aa`
- 命令：激活 ReConGS 后 `python main.py --config=config/fs_online_flat_hdbscan_refine_first5_20261013.yaml`
- exit=0，wall 263.81 s；resolution=-1、种子 0、共享 frame0+动态帧 1–4，每动态帧 300 步。

## 残差和原因分析

各区域按有观测存活 GS 数加权的均值如下；平移是世界坐标，旋转是组合后的最短角度 rad。区域 p50/p90 没有被误合并成全局分位数。

| 帧 | 平移均值：前→后 | 旋转均值 rad：前→后 |
|---|---:|---:|
| 1 | 0.00041761 → 0.00039940 | 0.00037280 → 0.00028766 |
| 2 | 0.00034190 → 0.00043463 | 0.00012225 → 0.00013308 |
| 3 | 0.00026750 → 0.00034356 | 0.00012667 → 0.00012683 |
| 4 | 0.00023772 → 0.00030334 | 0.00009181 → 0.00008305 |

包和活跃行减少不等于残差幅值处处下降，帧2/3旋转均值及帧2–4平移均值上升。细化把许多点变为零残差，仍需改变的少数点可能承担更大幅值。

帧1最大运动区域 id=807 仅 115 GS，占存活点 0.0558%。其共享 affine 平移从 `[0.003896,0.003896,-0.003896]`（norm=0.006748）变为 `[0.003571,0.006916,-0.004935]`（norm=0.009216），旋转保持 identity wxyz=`[1,0,0,0]`、0°。平移 mean/p50/p90/max 从约 `4.29e-7/4.29e-7/4.29e-7/4.29e-7` 到 `1.80e-7/1.84e-7/1.84e-7/1.84e-7`（数值组合误差量级）；旋转 rad 从 `0.000831/0/0.005831/0.007874` 到 `0.000124/0/0/0.007810`。完整每区域共享 xyz/norm、轴角/四元数和残差分布均在 `refinement.before/after.regions`。

相比旧 strict 的 HDBSCAN，PSNR 从 34.29959 到 34.41772 dB（+0.11814），payload 从 83.79 到 105.27 kB；增加步数、接纳策略及 GS 残差目标同时变化，不能单因子归因。当前上千个小区域和逐帧增加的保留槽位产生明显布局/归属成本；许多当前不再移动的历史组细化后虽归零，槽位与成员仍保留，未自动形成紧凑的大共享区域。

本轮验证了共享机制实际启用且细化可减少独立支持，但平均存储仍显著高于目标，不能以极小 PSNR 差称为最佳方法。这里只分析完成实验，没有修改算法或追加消融；同协议速度如下，不沿用旧 root-only FPS。

## 统一速度测量

所有训练结束后顺序测量，RTX 3090 Ti、1600×1199 cam00、冻结属性缓存开启。每帧 10 预热+50 CUDA 同步完整渲染+clamp：动态 **202.694 FPS**，最低动态单帧 201.907 FPS，排除解码和上传；含 frame0 为 202.619 FPS。2 轮动态帧 1–4 的本地读取、CPU 校验解码、上传、完整渲染播放为 **3.883 FPS**，排除一次性 reference、相机/GT 加载和预检查，文件预读可能受 OS 缓存帮助。两类 FPS 不混用。

包含共同 frame0 的五帧平均 PSNR 为 **34.33644 dB**，动态平均仍为 34.41772 dB。新报告在 output/online_flat_refine_first5_benchmarks_20261013/hdbscan_sequence.json 和 hdbscan_frame4_playback.json，精确命令见 benchmark_commands.json，exit=0。短序列不代表全 300 帧。
