## 分析与撤回

入口确实生效：frame1 生成 228 个小来源、4179 个大来源候选，经过后续 split/prune 最终保留 770 个；之后每帧仍保留约八百个。更多候选没有变成有效画质收益，存储却显著增加，因此不继续延长。

只读检查 frame1 最终新增点在全部 20 个训练视角的实际合成贡献，770 个中只有 **49** 个最终对所有训练视角都无贡献，其中 40 个来自大来源。按训练视角选择移除这 49 个后，训练与测试图像均逐像素不变，但数量太少，不能解释主要存储增长，也不足以作为此次扩大入口有效的理由。该检查只看最终位姿，不证明这些点在训练过程中从未可见；不能据此直接加入“从未训练”的筛选规则。记录：`/tmp/my4dgs_largesources200_frame1_contributions_20261015.json`。

已撤回大点候选实现和对应专用测试，恢复原克隆规则；保留分配策略 checkpoint 标记，防止误续训试验模型。恢复后 **114 项检查通过**。没有把零贡献筛选、颜色预热或透明度补偿加入正式训练。

## 回到运动机制

另对已完成的原 200 步版本做只读残差幅度检查：固定区域、方向及非零平移块，统一缩放平移残差，重新量化并验证编码位姿。frame29 scale1 → 1.2 时训练图像损失 **0.0130073 → 0.0129874**，测试 PSNR 却 **34.123787 → 34.072205 dB**；scale0.8 测试为 34.164070 dB，但训练更差。frame9 的趋势不同。没有将任何测试视角选出的缩放值用于训练；该诊断不支持单纯放大残差去偏，而提示独立点运动存在泛化问题。记录：`/tmp/my4dgs_residual_amplitude_profile_20261015.json`。

当前树往往在点运动已经拟合后作编码选择，无法充分约束主要运动的自由度。下一步优先验证优化分工：自由点运动提供初始化线索；区域与细分 gate 承担主要运动拟合；最后才开放稀疏点残差补充。先做数值机制检查，再决定具体训练规则，不增加补偿模块。全 300 帧目标仍未达到或验证。
