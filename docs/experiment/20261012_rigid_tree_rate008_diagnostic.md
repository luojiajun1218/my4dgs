# 放松存储惩罚的单变量对照

从 3072 区域 L1 诊断的相同 frame49 bootstrap 开始，仅把存储权重从 0.015 改为 0.008，其他模型、步数和量化设置不变。希望利用新 codec 节省的空间保留更多逐 GS 残差，提高画质。对照大小采用原实验无损转成同一新格式后的真实字节。

| 帧 | 原 L1 PSNR | 本轮 PSNR | 原 L1 新格式字节 | 本轮字节 | 新增 GS |
|---|---:|---:|---:|---:|---:|
| 50 | 33.20445 | 33.27695 | 36,082 | 64,896 | 129 |
| 51 | 33.38559 | 33.59929 | 29,952 | 51,118 | 131 |
| 52 | 33.19198 | 33.46505 | 27,574 | 46,333 | 130 |

平均 PSNR 为 33.44710，比原 L1 高约 0.186 dB；平均增量为 54,115.67 字节，比原 L1 多约 22.9 KB。首帧有局部残差的旧 GS 增至 6,544，符合放松稀疏约束的预期。

这一候选同时比 8192 区域长拟合候选的 33.53155 dB 更低、37,088.67 字节更大，因此不选作下一轮完整配置。这里只说明这三帧上的结果，不能推断完整 300 帧。未测 FPS。

模型代码未改。Checkpoint 仅三处保存的存储权重变化，其他值与来源递归一致；CPU 严格恢复和下一帧初始姿态检查通过，沿用此前完整测试结果。
