# 空间 gate 量化代价迭代：连续区域优化仍制造共享运动

运行：`fs_spatial_gate_quantized_first5_20261014/20261014T220804_b40b39`，动态帧 1–5，100 motion + 100 birth step，无旧透明度修正。

核心改动：gate 比较量化区域运动的代价；参考空间候选深度提高至 4；共同平移网格 3e-5 × scene extent，旋转网格 0.001 rad，使相近运动可以共享离散符号。

结果：PSNR 34.181086 dB，motion+birth 平均 151.37 KB，新增 1061 GS。有效细分仍为零；所有帧八个大区域都携带非零共享运动，几乎所有旧 GS 都发生运动。

机制分析：
- 连续区域参数在离散零附近仍会发生梯度漂移。点残差的 proximal 又把 GS 完整运动拉向该共享量，把区域代表量的误差变成整个区域的运动。
- 因为粗区域已经把大量 GS 拉向自己的运动，gate 看到的候选运动也被污染。增大候选深度并不能解决这一闭环问题。
- 量化众数和 learnable gate 的职责应明确区分：众数估计一个空间集合共享什么运动；gate 决定采用哪个空间粒度。让这两个环节同时自由优化，当前代价函数未能保住静止多数。

下一步：恢复量化众数作为区域代表值，定期由当前观测 GS 完整运动更新；只对细分 gate 做结构学习，直接按量化后非零块的编码代价优化。先保证代表量正确，再验证树是否真的细分。未启动长实验。
