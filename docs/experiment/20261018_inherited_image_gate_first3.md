# 继承父预测的图像联合gate：210–212帧短测

## 核心想法

绝对子区域会替换父区域预测；一旦子区域尚未拟合好，打开gate就可能丢掉已学到的共享运动。本次让区域运动以父预测加局部修正表达，随机离散STE依然通过图像和存储目标学习gate。零子修正继承父预测，非零子修正才增加细节，不通过渲染比较或阈值规则选择gate。

联合区域DC颜色也在gate学习期间累积父子修正；固定gate时转成选中节点的绝对DC增量，保持量化颜色不变，继续使用现有SDR1。运动沿用既有相对运动码流。GS依然仅在最细层允许私有残差，这个容量约束没有取消，因此不能把所有残差归零都归功于相关性学习。

## 事前只读诊断

对先前RMSE候选的新增前step200做固定字段替换，保持颜色、α和GS残差：第210帧把共享运动截到前三层，PSNR由33.932751升至34.015011；第1帧相同操作却从33.910614降至33.866978。细分效用随帧变化，不能直接统一减少层数。

再对第210帧**同一量化整数运动**重编码：当前混合层级运动包22.942KB；保留现有八个粗预测器、其余改存无容量限制的GS残差为103.703KB；全改存GS为139.119KB。这说明当前层级确实承担了共享编码，但没有重新拟合粗预测器或固定结构，不能当作learnable gate优于训练充分的固定层级的独立消融结论。不同加法顺序的位置舍入差上限3.815e-6；计数仅为新增前运动包，不能与终态完整帧更新混用。

这些诊断不参与训练或gate选择。文件在`output/fs_goal_rd_20261017/gate_rmse_{late210,native1}_role_audit.json`及`gate_rmse_late210_sharing_codec_audit.json`。

- 区域累积预测接受真实图像梯度；恒等根固定为0，避免出现无法编码的全局参数。相对码率同时计入选中节点与祖先。
