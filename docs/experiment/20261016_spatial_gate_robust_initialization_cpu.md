# 空间树离群点检查与稳健初始化候选：仅完成 CPU 几何和编解码验证

## 问题与实际范围

检查用户提出的两个问题：首帧远点会不会影响现有空间候选树，能否借鉴本地 S²GS 的树初始化。读取既有 worldroute 共享首帧和相机信息，没有复制数据或改写历史输出。

本次完成的是 CPU 诊断和候选实现，不是训练实验。CUDA 不可用、设备数为 0，`nvidia-smi` 无法与 NVIDIA 驱动通信。因此没有启动新的 30 帧训练，没有新 PSNR、SSIM、LPIPS 或渲染 FPS。

结果目录：`output/fs_spatial_gate_initialization_audit_20261016/cpu_robustmedian/`。其中 `audit.json` 保存输入摘要、统计、S²GS 规则对照和编解码检查；`robust_layout_synthetic_motion.bin` 是真实点云上的合成稀疏运动检查包，不是训练结果。

## 本地 S²GS 做了什么

依据 `/home/gamer-02/Documents/DeepLearning/S2GS/scene/gaussian_model.py`：

- `create_from_pcd` 使用全体点坐标的标量最小/最大值，乘 `extend` 后确定体素范围及原点。它本身不是稳健包围盒，也不对所有远点作过滤。
- `set_level` 使用点到训练相机的距离分位数，估计标准距离和 LoD 层数。Flame Steak 配置的 `dist_ratio` 为 0.999。
- `octree_sample` 逐层缩小体素，合并同体素点，建立占用体素和根层归属。
- `weed_out` 根据相机距离预测 LoD，并按视角比例筛选对应层级。这里的判断不是实际光栅化贡献，也不是严格的图像视锥可见性。

这些步骤还会改变原始高斯表示，不能作为单纯的候选分割面替换直接接入现有解码链。本次借鉴距离分位数的统计思想，保留既有 GS 和码流语义。没有声称移植了完整 S²GS 八叉树。

诊断脚本还用独立 NumPy 实现，将该项目的网格/LoD 规则应用到同一个共享 GS 点集上。它不是对 S²GS 的原始 COLMAP 输入或 GPU 浮点实现的逐位复现，也不作为画质对比。

## 数据与原方案的实际问题

共享首帧有 206237 个 GS。到逐坐标中位中心的距离中位数约 10.7371，99.9% 分位数约 32.0012，最大约 91.0268，均为场景坐标单位。

原方案对有点区域使用逐坐标中位数，单个远点不会像包围盒等分那样把整个场景划分一起撑大。但远点仍参与局部统计、占用区域，而空分支分割面还继承全体点的极值范围，所以不能认为所有分割面都与远点幅度无关。

## 候选规则与代码改动

新增可选 `spatial_gate.initialization: robust_median`，默认仍为 `median`：

1. 从共享首帧计算逐坐标中位中心，按距离的 0.999 分位数选择分割面统计支持。
2. 仅用支持内的 GS 计算局部中位数及初始范围。没有支持点的区域使用由支持范围递归得到的几何中点。
3. 所有 GS 仍按实际位置路由，包括未参与统计的远点。没有删除、移动或裁剪 GS。

本次以场景中位中心测距，S²GS 以相机中心测距，这是有意的改编，不把二者当成相同算法。统计支持也不等同于运动可见性、渲染重要性或无效点标签。

简要代码：

- `model/spatial_gate.py`：统计支持和可选初始化，增加输入校验。
- `model/spatial_gated_motion.py`：初次建树传入新配置，诊断记录初始化方式。
- `scripts/audit_spatial_initialization.py`：复现实点诊断、远点压力测试和 CPU 编解码检查。
- `tests/test_spatial_initialization.py`：数值鲁棒性、保留全部 GS、新生点路由、恢复和旧配置兼容。

父子关系、候选深度、运动公式、区域运动的中位数初值、gate 训练、点残差裁决及新增阶段均未改变。固定分割面仍放在一次性参考中，没有新增逐帧码流字段；这不代表真实训练后的总码量不变。

## 已完成结果

0.999 距离支持选中 206030 个点，207 个点不参与分割面统计，排除出模型的点为 0。

|首帧几何指标|原中位数方案|稳健统计候选|
|---|---:|---:|
|GS 数量|206237|206237|
|候选节点|37449|37449|
|占用叶子|28123|28044|
|占用叶子人数中位数 / p95 / 最大值|4 / 25 / 187|4 / 25 / 186|
|可细分 gate 数|3494|3499|
|叶内实际点 AABB 对角线最大值|82.9306|83.1836|

最后一项是每个叶内点集的包围盒跨度，不是候选单元边界长度。大跨度并没有改善，不能因为初始化更稳健就断言运动区域已经更合理。

压力测试将这 207 个远点沿相对于原中位中心的方向推远 1000 倍，其余点保持不动，重新建树：

|人工压力测试指标|原中位数方案|稳健统计候选|
|---|---:|---:|
|分割面发生变化的内部节点|801|0|
|206030 个支持点中树路径发生变化的点|1789|0|

这是对极端点幅度的敏感性检查，不是自然场景性能，也不是累积误差或 PSNR 改善的证明。

S²GS 网格规则对照中，粗体素尺寸由约 0.30708 变成 282.03346，主体点占用的粗层体素由 34545 降至 1；自动 LoD 层数同时由 5 增至 15，后续细层会重新细分。不能据此说 S²GS 所有尺度都坍缩，但说明直接复制其极值体素范围，也不解决这里担心的远点问题，并会改变层数和容量。

## 正确性与兼容

- 默认 `median` 重建出的首帧路径、全部分割面与原保存参考逐项完全相同。
- 稳健候选对全部 206237 个真实 GS 的合成稀疏位移/旋转使用原 SPG 编解码器回放，位姿一致、恢复后下一帧路径一致。该合成运动包 242 B 只用于验证，不作为方法码率结果。
