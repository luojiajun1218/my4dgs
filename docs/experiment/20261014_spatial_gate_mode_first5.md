# 量化众数 + learnable 空间 gate：首 5 帧机制诊断

运行：`fs_spatial_gate_mode_first5_20261014/20261014T221323_78ecc0`。100 motion + 100 birth step，无旧透明度修正。

核心改动：区域代表量恢复为观测 GS 完整运动的联合量化众数，每 15 step 更新；停止区域连续梯度漂移；gate 以量化后非零平移/旋转块的预期编码代价学习。候选深度 4，rate weight 0.03。

结果：动态 PSNR 34.194144 dB，motion+birth 均值 99.50 KB，新生 1153 个 GS。末帧 65.90 KB、非零点残差 12041 个；有效区域仍为八个。

进一步诊断：
- 数值测试已验证可学习 gate 在一个子区域能解释同类运动的案例中确实打开，并保持 GS 姿态。
- 对末帧候选树使用动态规划，仅用于离线诊断：用同一量化众数和绝对行号字节代价寻找最佳细分，最佳 152 个区域只比八区域节省 52 B。它不是用于训练/决策的规则，也不是新对照实验。当前深度内，没有强的共享收益可供 gate 学习，不能仅凭未细分判断 gate 优化失败。
- 仍出现早期共享量被点残差 proximal 强化的闭环。一个粗区域的临时非零众数会把低梯度 GS 的完整运动拉向它，随后它又成为这些 GS 的众数。末帧 27423 个旧 GS 运动，超过非零残差 12041 个。

下一步：在这 100 个 motion step 内，先让完整 GS 运动依图像和稀疏性确定哪些点需要改变，再在末段对最终共享残差施加 proximal；区域统计与 gate 仍在同一 motion 阶段更新，不增加步骤或辅助模块。同时让 gate 看更晚、拟合更充分的运动，避免早期代理量固定整个空间块。先短实验，再更长前缀。
