# 大latent不等于大运动：诊断边界

设S为完整候选树原子叶内常量场的线性空间，P为等点权正交投影。
所有可解码树场z都属于S。当前每通道rho不随点改变，因此

    ||x-z||²_rho = ||Px-z||²_rho + ||(I-P)x||²_rho.

后一项不依赖树/量化符号。所以，在精确算术和同一平局规则下，x与Px的
最优packet相同；前者的包络值可以很大，却不意味着编码运动也很大。

对当前无momentum、共享通道步长eta的SGD：

    x_next = x - eta * [g(z) + rho * (x-z)]
    P x_next = Px - eta * [P g(z) + rho * (Px-z)].

因此每步只保存原子叶均值与保存逐点latent，得到相同的可编码轨迹。
这是给定候选树时的结论；不证明图像STE收敛，不证明原子叶够细，也不
覆盖随点改变的预条件、Adam、非线性梯度裁剪、候选字典更新。
