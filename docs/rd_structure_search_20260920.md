## 路线筛选

1. **朴素 soft gate**：`motion=parent+p*detail`，加 `lambda*p`，存在缩小 p、
   放大 detail 的尺度套利；不用。
2. **随机结构门控的期望 RD**：单节点可写
   `L=(1-p)*(D0+lambda*R0)+p*(D1+lambda*R1)`。对 logit 的梯度是
   `p*(1-p)*[(D1-D0)+lambda*(R1-R0)]`。有正确的局部决策含义，但未成熟
   的细分分支会被过早淘汰，完整树期望也不能廉价穷举。保留为备选，尚未实现。
3. **首选继续研究：渲染梯度驱动的 RD 树投影**。将离散结构选择放入
   loss 优化的近端子问题，而非强行对“创建节点”反传。已完成数学/码流
   CPU 参考原型；优化迭代仍有未解决问题，暂不接入 ReCon-GS 训练。

## 结构投影的核心推导

目标仍是 `F(u,T)=D_render(u)+lambda*R(T,u)`。当前运动为 u，渲染反传
得到稠密运动梯度 g。在一个对空间点共享、可按通道区分的正曲率 rho 下：

    v_ic = u_ic - g_ic / rho_c
    (T_new, q_new) = argmin 0.5*sum_ic rho_c*(decode(T,q)_ic-v_ic)^2
                                + lambda*R_payload(T,q)

v 是局部优化提案，不是光流真值，也不需要预先把细层训练好。一次反传
可以为当前未激活的区域提供提案信号，只要拿到的是每个 Gaussian 的运动
输出梯度，而非仅已激活 anchors 的聚合梯度。

### 当前可精确求解的受限版本

候选几何树由最长坐标跨度上的稳定中位数二分构建，限制最大深度和最小
叶组。实际发出的树是优化选出的非均匀剪枝树，不是完整固定层级。但候选
分组边界仍由几何限定，不宣称任意聚类/拓扑学习；这是当前表达边界。

每个根一份共同运动；每个保留分叉一份差异，左右权重为 nR/nP 与 -nL/nP。
这些基函数在硬嵌套分组和等点权重下相互正交。差异 d_n 的平方范数因子
为 `w_n=nL*nR/nP`。对提案 v，计算每节点均值 m_n 与局部方差：

    E_n = 0.5*sum_{i in n,c} rho_c*(v_ic-m_nc)^2
    d_n = m_left - m_right
    K_n = min_q 0.5*w_n*sum_c rho_c*(d_nc-Q_c*q_c)^2 + lambda*bits(q)

由叶至根递推：

    C_atomic = E_atomic
    C_stop(n) = E_n + lambda*1_bit
    C_split(n) = K_n + lambda*1_bit + C_left + C_right
    C_n = min(C_stop, C_split)

根均值的量化误差与码长另计。内部节点发一个停止/分裂位；细分时发差异
并递归，原子叶无需结构位。即便某个祖先差异为零，整棵子树有收益时仍
能保留该祖先和有用后代。这是限定候选树内的完整递推，不是两层前瞻。

这里“精确”仅指上述二次代理目标、确定码长、硬嵌套候选树；不意味着
真实渲染全局最优。若使用逐 Gaussian Adam 曲率、软重叠基底、上下文
耦合的熵模型或自适应码表，上述可分解条件会改变，不能照搬证明。

### 真 bit，而不是节点数惩罚

参考实现采用有符号 Exp-Golomb 整数前缀码，系数零也需一 bit。每个码长
区间内找最佳整数，再比较所有可能区间，得到精确的标量率失真量化。
这是用于验证闭环的简单真实编码器，不宣称其压缩率胜过 arithmetic coding。

真实包包含：32+8*C 字节头部、根系数、访问节点的结构位、保留差异、末尾
0–7 bit 填充。DP 优化有效 payload bit；头部在同一投影中固定，byte padding
最多差 7 bit，已单独统计，不能声称逐字节最优。

解码还依赖共享候选树/点顺序。包中的摘要仅检查匹配，不能替代发送任意
学习分组。未来实际系统必须明确由上一帧已解码几何确定候选树的数值协议。

### 发现的问题 A：硬量化投影停滞

每步把当前状态替换为硬投影结果，会丢弃未跨过量化门槛的小更新。种子
20260920 的 16 维耦合二次观测，实际 F 从 6.02935 降到 .953532 后停住；
已知有一个可行解 F=.072。因此单调下降不等于好解。其它四个种子也有
不同程度的停滞，更保守曲率会加重。可行参考由合成真值构造，只作诊断，
不提供给优化器，也不是全局最优证书。

### 发现的问题 B：朴素 shadow 累积可能绕过码率约束——拒绝采用

保留连续 latent，累积渲染梯度而不是每步从硬解重置，可在五个种子、较小
曲率下到达 F=.072。但它不单调；更重要的是，对弱细节、高 lambda 的反例，
它会不断累积图像梯度直到强行跨过码率门槛，激活不值得的复杂结构。

8 点交替位移 +/- .125，Q=.125、lambda=.1，初始不分裂目标 .2625，朴素
shadow 100 步中达到 7.340625。已加入确定性反例测试。不能因前一组漂亮
结果就选它，也不能将无条件 shadow 累积包装成完整的 RD 优化。

## 最近工作与可主张范围

- [经典自适应基/树剪枝](https://www.ee.columbia.edu/~jrsmith/html/pubs/sawpic/node27.html)：
  率失真树动态规划本身是已有思想，不能作为我们的新发明。
- [TreeSplat](https://papers.nips.cc/paper_files/paper/2025/hash/c868aa7437dc9b29e674cd2e25689021-Abstract-Conference.html)：
  论文摘要明确层级随 Gaussian densification 生长，路径运动可在推理前合并。
  当前仅据摘要比较这一机制，未声称完整方法查重结束。
- [HEIR](https://arxiv.org/html/2510.26786v1)：已学习父子运动关系；方法使用
  图注意力与 Gumbel-Softmax，并以运动重建和残差 L1 等约束学习层级。
  因此不能宣称第一次学习运动层级。我们的目标不同：在线渲染 RD 下的
  有限计算、真实码流与局部复杂度选择，而非通用语义/运动依赖图恢复。
- [RDO-Gaussian](https://arxiv.org/html/2406.01597v2)：已有可学习 mask、RD 与
  熵约束量化。仅把分裂写成 sigmoid loss 不是充分区别。
- [CDGS](https://arxiv.org/html/2602.03538v1)：以可微数量控制及静动态分配约束
  Gaussian 总量；不能把“loss 决定容量”作为笼统首创。
- QuARC-GS、S²GS、SC-GS 等 Drive 阅读记录见 `core_method_candidates.md`。

潜在贡献应具体到：**从渲染反传信号出发，联合选择可编码运动差异与非均匀
层级，避免逐层准入和每节点短训练，并保持明确的码率/计算闭环。** 这仍是
待证研究假设，不是已经确认达到论文创新标准的结论。

### B. 从最优可编码结构导出一个真正的 loss

对连续运动提案 x，定义：

    E_tree(x) = min_(T,q) [0.5*sum rho*(x-decode(T,q))^2 + lambda*R_payload(T,q)]

上述 DP 给出精确最小值及可解码运动 z*。在最优解唯一且未跨决策边界时：

    gradient_x E_tree = rho*(x-z*)

这就是一个候选“细分/共享 loss”：用同一个真实编码目标决定树，然后
把当前连续运动与可编码运动的差异反传给模型。不需要单独的细分标签，
不需要学习任意幅度 gate，也不会为了减少一个 p 而放大 d。不同树有相同
代价的边界处不可微；实现返回所选分支的梯度，不声称处处光滑。

新增 `tree_rate_envelope`，已通过 float64 autograd gradcheck 和显式梯度
等式检查。在弱细节反例中，将它加入 shadow 的更新后，latent 被约束，
最终可编码结构不再强开，J 始终为 .2625。

但是：若渲染前使用 `z_ST = x + stop_gradient(z*-x)`，图像梯度仍是 STE
估计，整个图像训练目标不因此成为精确可微目标。若使用未量化 x 渲染，
则存在训练/传输失配。必须将这两种选择的利弊说清，不能用 E_tree 的
正确梯度替代整个训练过程的证明。初步临时耦合观测测试也显示 rho 敏感，
尚未选定完整训练算法。

### C. 曲率不一定要在所有点上相同：一个值得继续的改进

当前实现是在点空间定义对角二次代理，故依靠等点权重与正交差异来分解。
另一条不需要向解码端传曲率的方法，是直接在固定候选树的**差异系数空间**
定义对角代理：根和每个潜在差异各有 h_nc 与提案值 v_nc，停止节点的代价
就是其整棵子树所有被省略差异的二次代价之和。仍可做同样的 DP，编码
基底继续由人数权重确定。h 只用于编码端优化，不属于解码参数。

未激活节点的梯度可以由逐 Gaussian 图像梯度的正负加权和得到；因此可
为所有深度维护梯度统计，而不必先激活父层。h 可参考系数级优化器的
尺度统计，但此时不是已验证的图像曲率上界；仍需真实接受检查或明确
STE 训练假设。该版本尚未实现，不将它记作已验证性质。

## 最近补充查阅的来源

- [ProxQuant](https://arxiv.org/abs/1810.00861)：量化训练与近端优化有既有研究，
  不能把使用 proximal operator 本身算作新贡献。
- [Deep Unrolling of Sparsity-Induced RDO](https://arxiv.org/html/2509.08685v1)：
  已有多分辨率点云属性的 RD 投影/优化展开。阅读到的目标与本项目运动
  层级不同，但进一步限制了泛称“多尺度＋近端码率优化”的创新主张。
- [Rate-distortion optimization of hierarchical displacement fields (1998)](https://doi.org/10.1109/76.660825)：
  IEEE公开摘要已明确用树剪枝选择变深度运动场，受码率或失真约束。
  因而连“RD选择非均匀运动层级”本身也不是新思想；潜在区别必须落到
  无运动真值的可微渲染优化、未激活自由度的梯度信息和编码/训练联合机制。
  当前只核对摘要，不声称全文检索或充分新颖性证明。
- [DeepRAHT](https://arxiv.org/html/2601.12255v1)：已核对方法中的可微Haar变换、
  预测和码率代理。我们的共同/差异表示与加权Haar思想相关，不宣称首创。
  区别候选是渲染任务驱动的可变运动树选择，而非已知点云属性的变换预测。
